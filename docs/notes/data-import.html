1 데이터 가져오기

R 패키지에서 제공하는 데이터로 작업하는 것은 데이터 과학 도구를 배우는 훌륭한 방법이지만, 어느 시점에는 여러분이 배운 내용을 여러분 자신의 데이터에 적용하고 싶을 것입니다. 이 장에서는 데이터 파일을 R로 읽어오는 기본적인 방법을 배웁니다.

구체적으로 일반 텍스트(plain-text)로 구성된 정형 데이터(rectangular) 파일을 읽는 데 중점을 둡니다. 열 이름, 유형 및 누락된 데이터와 같은 특징(features)을 처리하기 위한 실용적인 조언으로 시작하겠습니다. 그런 다음 한 번에 여러 파일에서 데이터를 읽고 R에서 파일로 데이터를 쓰는 방법에 대해 배울 것입니다. 마지막으로 R에서 직접 손으로 데이터 프레임을 만드는(handcraft) 방법을 배울 것입니다.

이 장에서는 tidyverse의 일부인 readr 패키지를 사용하여 평면 파일(flat files)을 R로 로드하는 방법을 알아봅니다.

library(tidyverse)

1.1 파일에서 데이터 읽기

먼저 쉼표로 구분된 값(comma-separated values)의 줄임말인 CSV라는 가장 일반적인 직사각형 데이터 파일 형식에 초점을 맞추겠습니다. 간단한 CSV 파일은 다음과 같습니다. 일반적으로 헤더 행(header row)이라고 하는 첫 번째 행은 열 이름을 제공하고 이어지는 6개의 행은 데이터를 제공합니다. 열은 쉼표로 구분됩니다(또는 구분 기호가 표시됩니다(delimited)).

Student ID,Full Name,favourite.food,mealPlan,AGE
1,Sunil Huffmann,Strawberry yoghurt,Lunch only,4
2,Barclay Lynn,French fries,Lunch only,5
3,Jayendra Lyne,N/A,Breakfast and lunch,7
4,Leon Rossini,Anchovies,Lunch only,
5,Chidiegwu Dunkel,Pizza,Breakfast and lunch,five
6,Güvenç Attila,Ice cream,Lunch only,6

Table 1은 동일한 데이터를 표 형태로 보여줍니다.

read_csv()를 사용하여 이 파일을 R로 읽어올 수 있습니다. 가장 중요한 첫 번째 인수는 파일 경로입니다. 경로를 파일의 주소로 생각할 수 있습니다. 파일 이름은 students.csv이고 data 폴더에 있습니다.

students <- read_csv("../data/students.csv")

Delimiter: ","
chr (4): Full Name, favourite.food, mealPlan, AGE
dbl (1): Student ID

ℹ Use `spec()` to retrieve the full column specification for this data.
ℹ Specify the column types or set `show_col_types = FALSE` to quiet this message.

프로젝트의 data 폴더에 students.csv 파일이 있으면 위 코드가 작동합니다. https://example.com/students.csv와 같이 웹에서 직접 읽어올 수 있습니다.

students <- read_csv("https://nobody.com/students.csv")

read_csv()를 실행하면 데이터의 행과 열 수, 사용된 구분 기호(delimiter) 및 열 사양(column specifications)(열에 포함된 데이터 유형별로 구성된 열 이름)을 알려주는 메시지가 인쇄됩니다. 또한 전체 열 사양을 검색하는 방법과 이 메시지를 숨기는 방법에 대한 정보도 인쇄합니다. 이 메시지는 readr의 필수적인 부분이며, 눈여겨 살펴보는 것이 좋습니다.

1.1.1 실용적인 조언

데이터를 읽어오고 나면 첫 번째 단계는 분석의 나머지 부분에서 더 쉽게 작업할 수 있도록 데이터를 어떤 식으로든 변환하는(transforming) 것이 보통입니다. 이를 염두에 두고 students 데이터를 다시 살펴보겠습니다.

students

1            1 Sunil Huffmann   Strawberry yoghurt Lunch only          4    
2            2 Barclay Lynn     French fries       Lunch only          5

favourite.food 열에는 여러 음식 항목이 있고 문자열 N/A가 있는데, 이것은 R이 “사용할 수 없음(not available)”으로 인식할 수 있는 진짜 NA였어야 합니다. 이것은 우리가 na 인수를 사용하여 해결할 수 있는 문제입니다. 기본적으로 read_csv()는 이 데이터셋의 빈 문자열("")만 NA로 인식하며, 우리는 이 함수가 문자열 "N/A"도 인식하도록 만들고자 합니다.

students <- read_csv("../data/students.csv", na = c("N/A", ""))

students |>

데이터를 읽어온 후 자주 하는 또 다른 작업은 변수 유형을 고려하는 것입니다. 예를 들어 meal_plan은 가능한 값들의 집합(set of possible values)이 알려진 범주형(categorical) 변수이므로 R에서는 팩터(factor)로 표현되어야 합니다.

students |>
    janitor::clean_names() |>
    mutate(meal_plan = factor(meal_plan))

meal_plan 변수의 값은 동일하게 유지되었지만 변수 이름 아래에 표시된 변수 유형이 문자(<chr>)에서 팩터(<fct>)로 변경된 것에 유의하세요.

이 데이터를 분석하기 전에 아마도 age 열을 고치고 싶을 것입니다. 관측치 중 하나가 숫자 5 대신 five로 입력되었기 때문에 현재 age는 문자 변수입니다.

students <- students |>
    janitor::clean_names() |>
    mutate(
        meal_plan = factor(meal_plan),
        age = parse_number(if_else(age == "five", "5", age))
    )

여기에 나오는 새로운 함수는 세 개의 인수가 있는 if_else()입니다. 첫 번째 인수 test는 논리 벡터여야 합니다. 결과에는 test가 TRUE일 때 두 번째 인수 yes의 값이 포함되고 FALSE일 때 세 번째 인수 no의 값이 포함됩니다. 여기서는 age가 문자열 "five"이면 "5"로 만들고, 그렇지 않으면 age 그대로 두라는 의미입니다.

1.1.2 다른 인수들 (Other arguments)

우리가 언급해야 할 두 가지 다른 중요한 인수가 있는데, 먼저 여러분에게 유용한 요령을 보여드리면 설명하기 더 쉬워질 것입니다. read_csv()는 여러분이 작성하고 CSV 파일처럼 서식을 지정한 텍스트 문자열도 읽을 수 있습니다.

read_csv(
    "a,b,c
  1,2,3
  4,5,6"
)
Warning: The `file` argument of `read_csv()` should use `I()` for literal data as of
readr 2.2.0.
  
  # Bad (for example):
  read_csv("x,y\n1,2")
  
  # Good:
  read_csv(I("x,y\n1,2"))
# A tibble: 2 × 3
      a     b     c
  <dbl> <dbl> <dbl>
1     1     2     3
2     4     5     6

일반적으로 read_csv()는 데이터의 첫 번째 줄을 열 이름으로 사용하며 이는 매우 흔한 관례(convention)입니다. 그러나 파일 상단에 몇 줄의 메타데이터가 포함되는 것은 드문 일이 아닙니다. skip = n을 사용하여 처음 n줄을 건너뛰거나 comment = "#"을 사용하여 #로 시작하는 모든 줄을 삭제할 수 있습니다.

read_csv(
    "The first line of metadata
  The second line of metadata
  x,y,z
  1,2,3",
    skip = 2
)
# A tibble: 1 × 3
      x     y     z
  <dbl> <dbl> <dbl>
1     1     2     3
read_csv(
    "# 건너뛰고 싶은 주석
  x,y,z
  1,2,3",
    comment = "#"
)
# A tibble: 1 × 3
      x     y     z
  <dbl> <dbl> <dbl>
1     1     2     3

다른 경우 데이터에 열 이름이 없을 수도 있습니다. col_names = FALSE를 사용하여 첫 번째 행을 제목(headings)으로 취급하지 말고 대신 순서대로 X1에서 Xn까지 라벨을 지정하도록 read_csv()에 지시할 수 있습니다.

read_csv(
    "1,2,3
  4,5,6",
    col_names = FALSE
)
# A tibble: 2 × 3
     X1    X2    X3
  <dbl> <dbl> <dbl>
1     1     2     3
2     4     5     6

대안으로 col_names에 열 이름으로 사용될 문자 벡터를 전달할 수 있습니다.

read_csv(
    "1,2,3
  4,5,6",
    col_names = c("x", "y", "z")
)
# A tibble: 2 × 3
      x     y     z
  <dbl> <dbl> <dbl>
1     1     2     3
2     4     5     6

이 인수들은 여러분이 실제 상황에서 만나게 될 대부분의 CSV 파일을 읽는 데 알아야 할 전부입니다. (나머지는 .csv 파일을 주의 깊게 검사하고 read_csv()의 다른 많은 인수에 대한 문서를 읽어야 합니다.)

1.1.3 다른 파일 형식들 (Other file types)

read_csv()를 마스터하고 나면 readr의 다른 함수를 사용하는 것은 간단합니다. 어떤 함수를 써야 할지 알기만 하면 됩니다.

  1. read_csv2()는 세미콜론(;)으로 구분된 파일을 읽습니다. 이들은 필드를 구분하기 위해 , 대신 ;을 사용하며 ,를 소수점 표시로 사용하는 국가에서 일반적입니다.
  2. read_tsv()는 탭으로 구분된 파일(tab-delimited files)을 읽습니다.
  3. read_delim()은 임의의 구분 기호가 있는 파일을 읽으며 구분 기호를 지정하지 않으면 자동으로 구분 기호를 추측하려고 시도합니다.
  4. read_fwf()는 고정 너비(fixed-width) 파일을 읽습니다. fwf_widths()를 사용하여 너비로 필드를 지정하거나 fwf_positions()를 사용하여 위치로 필드를 지정할 수 있습니다.
  5. read_table()은 열이 공백(white space)으로 구분되는 고정 너비 파일의 일반적인 변형을 읽습니다.
  6. read_log()는 Apache 스타일 로그 파일을 읽습니다.

1.2 열 유형 제어

CSV 파일에는 각 변수의 유형(즉, 논리형인지, 숫자인지, 문자열인지 등)에 대한 정보가 포함되어 있지 않으므로 readr이 유형을 추측하려고 시도합니다. 이 섹션에서는 추측 과정이 어떻게 작동하는지, 추측을 실패하게 만드는 몇 가지 일반적인 문제를 어떻게 해결하는지, 필요한 경우 열 유형을 직접 제공하는 방법에 대해 설명합니다. 마지막으로 readr이 치명적으로 실패하여 파일 구조에 대한 더 깊은 통찰력이 필요할 때 유용한 몇 가지 일반적인 전략을 언급할 것입니다.

1.2.1 유형 추측 (Guessing types)

readr은 열 유형을 파악하기 위해 휴리스틱을 사용합니다. 각 열에 대해 결측값을 무시하고 첫 번째 행부터 마지막 행까지 균일한 간격으로 1,000행2의 값을 가져옵니다.그런 다음 다음 질문을 통해 작업합니다.

  1. F, T, FALSE 또는 TRUE만 포함되어 있나요(대소문자 무시)? 그렇다면 논리형(logical)입니다.
  2. 숫자만 포함되어 있나요(1, -4.5, 5e6, Inf)? 그렇다면 숫자(number)입니다.
  3. ISO8601 표준과 일치하나요? 그렇다면 날짜(date) 또는 날짜-시간(date-time)입니다.
  4. 그 외의 경우라면 문자열(string)이어야 합니다.

다음 간단한 예에서 작동하는 동작을 볼 수 있습니다.

read_csv(
    "
  logical,numeric,date,string
  TRUE,1,2021-01-15,abc
  false,4.5,2021-02-15,def
  T,Inf,2021-02-16,ghi
"
)
# A tibble: 3 × 4
  logical numeric date       string
  <lgl>     <dbl> <date>     <chr> 
1 TRUE        1   2021-01-15 abc   
2 FALSE       4.5 2021-02-15 def   
3 TRUE      Inf   2021-02-16 ghi

이 휴리스틱은 깔끔한 데이터셋을 가지고 있다면 잘 작동하지만 실제 상황에서는 이상하고 아름다운 다양한 실패들을 만나게 될 것입니다.

1.2.2 결측값, 열 유형, 그리고 문제

열 탐지가 실패하는 가장 흔한 경우는 열에 예상치 못한 값이 포함되어 있어 더 구체적인 유형 대신 문자 열(character column)을 얻게 되는 경우입니다. 이것의 가장 흔한 원인 중 하나는 결측값인데, readr이 예상하는 NA가 아닌 다른 것으로 기록되어 있는 경우입니다.

이 간단한 1열 CSV 파일을 예로 들어 보겠습니다.

simple_csv <- "
  x
  10
  .
  20
  30"

추가 인수 없이 읽으면 x는 문자 열이 됩니다.

read_csv(simple_csv)
# A tibble: 4 × 1
  x    
  <chr>
1 10   
2 .    
3 20   
4 30

df <- read_csv(

1.2.3 열 유형

readr은 여러분이 사용할 수 있는 총 9개의 열 유형을 제공합니다.

  1. col_logical()과 col_double()은 논리형과 실수를 읽습니다. (위의 경우를 제외하고는) readr이 대개 대신 추측해 주므로 상대적으로 거의 필요하지 않습니다.

  2. col_integer()는 정수를 읽습니다. 정수와 double은 기능적으로 동일하기 때문에 이 책에서는 정수와 double을 거의 구별하지 않지만 정수는 double의 절반의 메모리를 차지하므로 명시적으로 정수를 읽는 것이 가끔 유용할 수 있습니다.

  3. col_character()는 문자열을 읽습니다. 이는 객체를 식별하지만 수학적 연산을 적용하는 것은 의미가 없는 긴 숫자 시리즈인 숫자 식별자 열이 있을 때 명시적으로 지정하는 데 유용할 수 있습니다. 전화번호, 주민등록번호, 신용카드 번호 등이 그 예입니다.

  4. col_factor(), col_date(), col_datetime()은 각각 팩터, 날짜, 날짜-시간을 생성합니다.

  5. col_number()는 숫자가 아닌 구성 요소를 무시하는 허용적인 숫자 파서이며 통화에 특히 유용합니다.

  6. col_skip()은 열을 건너뛰어 결과에 포함되지 않도록 합니다. 대용량 CSV 파일이 있고 일부 열만 사용하려는 경우 데이터 읽기 속도를 높이는 데 유용할 수 있습니다.

list()에서 cols()로 전환하고 .default를 지정하여 유형을 추측하는 기본 휴리스틱을 무효화할 수도 있습니다.

another_csv <- "
x,y,z
1,2,3"

read_csv(
    another_csv,
    col_types = cols(.default = col_character())
)
# A tibble: 1 × 3
  x     y     z    
  <chr> <chr> <chr>
1 1     2     3

또 다른 유용한 헬퍼는 지정한 열만 읽어 들이는 cols_only()입니다.

read_csv(
    another_csv,
    col_types = cols_only(x = col_character())
)
# A tibble: 1 × 1
  x    
  <chr>
1 1

1.3 여러 파일에서 데이터 읽기

때로는 데이터가 단일 파일에 포함되지 않고 여러 파일에 나뉘어 있을 수 있습니다. 예를 들어 1월은 01-sales.csv, 2월은 02-sales.csv, 3월은 03-sales.csv와 같이 각 달의 데이터가 별도의 파일에 있는 여러 달의 판매 데이터가 있을 수 있습니다. read_csv()를 사용하면 이 데이터를 한 번에 읽어서 단일 데이터 프레임에 차곡차곡 쌓을 수 있습니다.

1.5 데이터 입력

때로는 R 스크립트에서 작은 데이터를 입력하여 “수작업으로(by hand)” 티블을 조립(assemble)해야 할 때가 있습니다. 이 작업을 돕기 위한 두 가지 유용한 함수가 있는데, 티블을 열로 레이아웃(layout)할지 행으로 레이아웃할지에 따라 다릅니다. tibble()은 열별로 작동합니다.

tibble(
    x = c(1, 2, 5),
    y = c("h", "m", "g"),
    z = c(0.08, 0.83, 0.60)
)
# A tibble: 3 × 3
      x y         z
  <dbl> <chr> <dbl>
1     1 h      0.08
2     2 m      0.83
3     5 g      0.6

열별로 데이터를 레이아웃하면 행들이 어떻게 관련되어 있는지 보기 어려울 수 있으므로 대안으로 데이터를 행별로 레이아웃할 수 있게 해주는 transposed tibble의 줄임말인 tribble()이 있습니다. tribble()은 코드 내의 데이터 입력에 최적화되어 있습니다. 열 제목은 ~로 시작하고 항목(entries)은 쉼표로 구분됩니다. 이렇게 하면 적은 양의 데이터를 읽기 쉬운 형태로 레이아웃할 수 있습니다.

tribble(
    ~x , ~y  , ~z   ,
     1 , "h" , 0.08 ,
     2 , "m" , 0.83 ,
     5 , "g" , 0.60
)
# A tibble: 3 × 3
      x y         z
  <dbl> <chr> <dbl>
1     1 h      0.08
2     2 m      0.83
3     5 g      0.6
