톺아보기

이 장에서는 데이터 과학의 주요 도구인 가져오기(importing), 깔끔하게 만들기(tidying), 변환하기(transforming), 데이터 시각화(visualizing data)에 대한 빠른 개요를 제공합니다. 데이터 과학의 “전체 과정(whole game)”을 보여주고 모든 주요 조각들을 충분히 제공하여, 비록 간단하더라도 실제 데이터셋을 다룰 수 있도록 돕고자 합니다.

  1. 데이터를 변환하고 시각화하기 위해서는 먼저 데이터를 R로 가져와야 합니다. 일단 .csv 파일을 R로 가져오는 기본 사항을 배울 것입니다. 좀 더 나아가서 SQL을 함께 활용하는 방법도 소개합니다.

  2. 일관된 데이터 저장 방식인 깔끔한 데이터(tidy data)에 대해 배웁니다. 데이터를 다루는 기본 원칙과 데이터를 깔끔한 형태로 만드는 원칙을 논의합니다.

  3. 시각화만으로는 충분하지 않으므로 중요한 변수를 선택하고, 핵심 변수를 기준으로 데이터를 재구성하고, 새로운 변수를 생성하고, 요약 통계량을 계산할 수 있게 해주는 주요 방법과 연산을 연습합니다.

  4. 시각화는 R 프로그래밍을 시작하기에 좋은 출발점입니다. 데이터를 이해하는 데 도움이 되는 시각화 방법을 배울 수 있습니다. 우리는 ggplot2 플롯의 기본 구조와 데이터를 시각화는 과정을 학습합니다.

시작해보죠!
