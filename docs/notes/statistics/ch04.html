데이터 추출

우리는 모집단의 목록인 표집 틀(Sampling frame)에서 무작위 표본(Random sample)을 선택하는 기법에 초점을 맞추겠습니다. 이를 원활하게 수행하기 위해서는 먼저 몇 가지 핵심적인 R 프로그래밍 기술을 익혀야 합니다. 우선 벡터(Vector)와 데이터 프레임(Dataframe)에서 원하는 부분만을 추출하는 서브세팅(Subsetting) 방법을 살펴보고, 이어서 R이 컴퓨터 내부적으로 난수(Random number)를 생성하는 원리를 간략히 알아보겠습니다. 마지막으로 특정 개수의 표본을 무작위로 뽑아주는 sample.int() 함수를 학습하고, 이 모든 지식을 종합하여 방대한 표집 틀에서 실제 분석에 사용할 무작위 표본을 직접 추출해 보겠습니다.

1 서브셋

R 환경에서 대규모 데이터를 다룰 때, 우리는 데이터 전체를 한 번에 분석하기보다는 조건에 맞는 특정한 부분 집합, 즉 서브셋(Subset)만을 추출하여 살펴보는 경우가 많습니다. 데이터를 정확히 서브세팅하는 능력은 이후의 모든 분석 단계에서 기본기가 됩니다. 먼저 1차원 데이터인 벡터의 서브셋을 선택하는 방법부터 알아보겠습니다. 아래와 같이 정의된 hours 벡터가 있다고 가정해 주십시오.

hours <- c(8.84, 3.26, 2.81, 0.64, 0.60, 0.53, 0.37, 0.35, 0.31, 0.24)
hours
 [1] 8.84 3.26 2.81 0.64 0.60 0.53 0.37 0.35 0.31 0.24

R은 변수명 바로 뒤에 대괄호 []를 붙여서 데이터의 특정 부분을 추출합니다. 대괄호 안에는 벡터의 인덱스(위치 번호)를 넣거나, 참/거짓을 판별하는 논리문(Logical statement)을 넣을 수 있습니다. 예를 들어, hours 벡터의 첫 번째 요소 값을 확인하고 싶다면 다음과 같이 코드를 작성하십시오.

hours[1]
[1] 8.84

그리고 Enter 키를 누르면, R은 8.84라는 값을 반환합니다. 이는 하루 중 많은 시간이 할애되는 ’수면 시간’의 평균값입니다. 이러한 원리를 바탕으로, hours 벡터의 여덟 번째 항목을 찾아보려면 어떻게 해야 하겠습니까? 대괄호 안에 8을 넣어 hours[8]을 입력하시면 됩니다.

단 한 줄의 코드로 벡터에서 여러 개의 항목을 동시에 불러오는 것도 가능합니다. 대괄호 안에 단일 숫자를 넣는 대신, 원하는 위치 번호들을 모아둔 벡터를 통째로 전달하면 됩니다. 가령 첫 번째, 세 번째, 아홉 번째 활동에 소비된 평균 시간을 한 번에 추출하려면 다음 코드를 사용하십시오.

hours[c(1, 3, 9)]
[1] 8.84 2.81 0.31

또 다른 예를 살펴보겠습니다. 역대 미국 대통령들의 취임 당시 나이가 순서대로 age라는 벡터에 저장되어 있다고 가정해 보겠습니다. 2대 대통령인 존 애덤스와 6대 대통령인 존 퀸시 애덤스 부자의 취임 나이를 동시에 확인하려면, 다음과 같이 그들의 순서(2와 6)를 함께 지정해 주시면 됩니다.

age <- c(57, 61, 57, 57, 58, 57, 61, 54, 68, 51, 49, 64, 50, 48, 65, 52, 56, 46, 54, 49, 51, 47, 55, 55, 54, 42, 51)
age[c(2, 6)]
[1] 61 57

마지막으로, 숫자 인덱스 대신 논리문에 근거하여 벡터의 특정 값을 추출할 수 있습니다. 이는 특정 기준(크거나 작음, 같음 등)을 충족하는 항목들만 솎아내는 매우 강력한 기능입니다. 예를 들어, 평균 소비 시간이 1시간(1.0)보다 명확히 큰 활동들만 걸러내고 싶다면 다음 코드를 사용하십시오.

hours[hours > 1]
[1] 8.84 3.26 2.81

이 코드를 실행하면 8.84, 3.26, 2.81이 반환됩니다. hours 벡터 내에서 1보다 큰 값은 오직 이 세 가지뿐이기 때문입니다. 이러한 논리문을 자유자재로 다루려면 R이 인식하는 기본 논리 연산자(Logical operator)를 숙지해야 합니다.

기호 논리 연산 의미
> ~보다 큼 (초과)
>= ~보다 크거나 같음 (이상)
< ~보다 작음 (미만)
<= ~보다 작거나 같음 (이하)
== ~와 정확히 같음
!= ~와 같지 않음
& 그리고 (And, 두 조건을 모두 만족)
\| 또는 (Or, 두 조건 중 하나라도 만족)

특히 표의 마지막 두 연산자(&, |)는 여러 조건을 결합하여 복잡한 서브세팅을 수행할 때 유용합니다. 예를 들어, 소비 시간이 30분에서 45분 사이(즉, 0.5시간 이상 ‘그리고’ 0.75시간 이하)인 데이터만 추출하고자 한다면 다음과 같이 작성하십시오.

hours[hours >= 0.5 & hours <= 0.75]
[1] 0.64 0.60 0.53

반대로 15분 미만이거나 4시간을 초과하는(0.25와 4는 포함하지 않는) 극단적인 시간대만 선택하려면 다음 코드를 사용합니다.

hours[hours < 0.25 | hours > 4]
[1] 8.84 0.24

그렇다면 이를 응용하여, 15분에서 30분 사이(양 끝점 포함)의 시간을 추출하려면 어떤 코드를 작성해야 하겠습니까? 정확히 0.6과 같거나 2보다 큰(2는 미포함) 시간을 찾는 조건은 무엇입니까? 전자는 hours[hours >= 0.25 & hours <= 0.5]이며, 후자는 hours[hours == 0.6 | hours > 2]가 될 것입니다.

1.1 데이터 프레임

데이터 프레임을 서브세팅하는 원리는 벡터와 거의 동일하지만 결정적인 차이점이 하나 존재합니다. 벡터는 1차원 데이터 구조이지만, 데이터 프레임은 행(Row)과 열(Column)로 이루어진 2차원 표 구조입니다. 따라서 대괄호 안에 단순히 인덱스 하나만 넣는 것이 아니라, 행 인덱스와 열 인덱스를 쉼표로 구분하여 함께 지정해야 합니다. 행과 열을 모두 지정하는 방식부터 시작하여, 행만 필터링하는 방법, 그리고 마지막으로 열의 이름으로 열만 추출하는 방법 순으로 알아보겠습니다. 이해를 돕기 위해, 앞서 다룬 벡터들을 하나로 묶어 일상 활동 10가지의 이름, 평균 시간, 범주를 담은 Activities 데이터 프레임을 생성해 보겠습니다.

이름 (Name) 평균 시간 (AverageHours) 범주 (Category)
Sleeping 8.84 Personal Care
Working 3.26 Work-Related
Watching Television 2.81 Leisure
Socializing 0.64 Leisure
Food Preparation 0.60 Household
Housework 0.53 Household
Childcare 0.37 Caring for Household
Consumer Goods Purchase 0.35 Purchasing
Participating in Recreation 0.31 Leisure
Attending Class 0.24 Education 
Activities <- data.frame(
  Name = c("Sleeping", "Working", "Watching Television", "Socializing", "Food Preparation", "Housework", "Childcare", "Consumer Goods Purchase", "Participating in Recreation", "Attending Class"),
  AverageHours = c(8.84, 3.26, 2.81, 0.64, 0.60, 0.53, 0.37, 0.35, 0.31, 0.24),
  Category = c("Personal Care", "Work-Related", "Leisure", "Leisure", "Household", "Household", "Caring for Household", "Purchasing", "Leisure", "Education")
)

이제 이 데이터 프레임은 행렬과 같은 2차원 속성을 지니므로, 대괄호 안에 [행, 열] 형태의 좌표를 입력하여 특정 값을 콕 집어낼 수 있습니다. 가령 ’Food Preparation’의 범주(Category)가 무엇인지 확인하고 싶다면, 해당 데이터가 위치한 다섯 번째 행과 세 번째 열을 선택하시면 됩니다.

Activities[5, 3]
[1] "Household"

그렇다면 아홉 번째 활동의 ’이름’을 알고 싶다면 어떻게 코드를 작성하시겠습니까? 정답은 다음과 같습니다.

Activities[9, 1]
[1] "Participating in Recreation"

특정 요소 하나만이 아니라, 데이터 프레임에서 특정 ‘행’ 전체를 온전히 추출할 수도 있습니다. 대괄호 안의 쉼표 뒤(열 인덱스 자리)를 비워두기만 하면 됩니다. 이렇게 작성하면 R은 지정된 행의 모든 열 데이터를 반환합니다. 예를 들어, 열 번째 행인 ’Attending Class’와 관련된 전체 정보를 보려면 다음 코드를 사용하십시오.

Activities[10, ]
              Name AverageHours  Category
10 Attending Class         0.24 Education

실행 결과, 다음과 같은 정보가 반환됩니다.

"Attending Class" 0.24 "Education"

물론 앞서 배운 벡터 기법을 결합하여 여러 개의 행을 동시에 추출할 수도 있습니다. 예를 들어 1행(Sleeping), 4행(Socializing), 7행(Childcare)의 정보를 한 번에 모아보고 싶다면 코드는 다음과 같이 작성됩니다.

Activities[c(1, 4, 7), ]
         Name AverageHours             Category
1    Sleeping         8.84        Personal Care
4 Socializing         0.64              Leisure
7   Childcare         0.37 Caring for Household

반환되는 결과는 다음과 같습니다.

           Name AverageHours                 Category
1      Sleeping         8.84            Personal Care
4     Socializing         0.64                   Leisure
7       Childcare         0.37 Caring for Household

이러한 패턴을 이해하셨다면, ‘Watching Television’(3행)과 ‘Housework’(6행)의 정보를 추출하는 코드 역시 Activities[c(3, 6), ]로 자연스럽게 도출하실 수 있을 것입니다.

지금까지는 주로 ’행’을 기준으로 서브세팅을 수행했습니다. 하지만 데이터 프레임에서는 특정 ’열(변수)’만을 떼어내어 다루는 작업도 매우 빈번하게 발생합니다. 데이터 프레임은 결국 동일한 길이를 가진 여러 벡터들의 묶음입니다. 가령 Activities 데이터 프레임은 Name, AverageHours, Category라는 세 개의 벡터 기둥으로 구성되어 있습니다. 특정 열에만 집중하고 싶을 때는 어떻게 해야 하겠습니까? R에서는 달러 기호($) 연산자를 사용하여 데이터 프레임 내부의 특정 열 벡터를 직접 호출할 수 있습니다. 문법은 다음과 같습니다.

데이터프레임이름$변수이름

따라서 10가지 활동의 ‘범주’ 데이터만 쭉 뽑아보고 싶다면 다음과 같이 작성하십시오.

Activities$Category
 [1] "Personal Care"        "Work-Related"         "Leisure"             
 [4] "Leisure"              "Household"            "Household"           
 [7] "Caring for Household" "Purchasing"           "Leisure"             
[10] "Education"

이 코드를 실행하면 Personal Care, Work-Related, Leisure 등의 문자열 벡터가 출력됩니다. 각 활동에 소비된 ‘평균 시간’ 벡터만 필요할 때는 Activities$AverageHours를 호출하시면 됩니다.

이 $ 연산자는 앞서 다룬 논리문을 데이터 프레임 행 필터링에 적용할 때 빛을 발합니다. 예를 들어, 평균 소비 시간이 1시간을 넘는 활동들의 ’모든 정보(행 전체)’를 조회하고 싶다면 다음과 같이 작성해 주십시오. 쉼표 뒤를 비워두어 해당 조건을 만족하는 모든 열을 가져온다는 점을 유의하십시오.

Activities[Activities$AverageHours > 1, ]
                 Name AverageHours      Category
1            Sleeping         8.84 Personal Care
2             Working         3.26  Work-Related
3 Watching Television         2.81       Leisure

실행 결과는 다음과 같습니다.

                  Name AverageHours      Category
1            Sleeping         8.84 Personal Care
2             Working         3.26  Work-Related
3 Watching Television         2.81       Leisure

범주가 Leisure(여가)가 ‘아닌’ 모든 활동의 정보를 필터링하려면 어떻게 해야 하겠습니까? Activities[Activities$Category != "Leisure", ]라고 작성하시면 됩니다. 이때 Leisure는 문자형 데이터이므로 반드시 따옴표로 감싸주어야 합니다.

2 R의 난수

이제 무작위 표본을 추출하는 본론으로 들어가기에 앞서, R이 어떻게 난수를 생성하는지 짚고 넘어가겠습니다. R을 비롯한 거의 모든 컴퓨터 프로그램이 생성하는 난수는 진정한 의미의 ’자연적 무작위(True random)’가 아닙니다. 컴퓨터는 수학적 알고리즘을 통해 이전의 입력값을 바탕으로 다음 숫자를 계산하여 무작위처럼 보이는 숫자를 출력합니다. R은 기본적으로 메르센 트위스터(Mersenne Twister)라는 검증된 알고리즘을 사용합니다. 이를 유사 난수(Pseudo-random number)라고 부릅니다.

이러한 유사 난수를 학술 연구의 기준으로 신뢰할 수 있는 이유는 무엇이겠습니까? 핵심은 이 알고리즘이 생성하는 숫자의 패턴이 ’자주 반복되지 않는다’는 데 있습니다. 메르센 트위스터 알고리즘은 무려 \(2^{19937}-1\)번을 실행해야 비로소 초기 패턴이 반복됩니다. 이는 인류가 수행할 수 있는 어떠한 초대형 데이터 분석에서도 결코 난수 패턴이 중복되지 않음을 수학적으로 보장하는 천문학적인 수치입니다.

이처럼 알고리즘이 연쇄적인 계산을 통해 다음 난수를 만들어낸다면, 맨 처음 계산을 시작하기 위한 ’최초의 입력값’이 반드시 필요합니다. 이 시작 값을 씨앗이라는 의미로 시드(Seed)라고 부릅니다. 하나의 씨앗에서 정해진 난수열이 자라나듯, 같은 시드를 지정하면 언제나 똑같은 난수열이 재현됩니다. 시드를 지정하지 않으면 R은 컴퓨터의 현재 시각 데이터를 가져와 매번 다른 시드를 자동 설정합니다. 하지만 분석의 재현성(Reproducibility)을 위해 고정된 시드를 부여해야 할 때는 다음 코드를 사용하십시오.

set.seed(2026)

괄호 안에 원하는 숫자를 시드로 지정해 주시면 됩니다. 고정된 시드를 제공하면 컴퓨터는 난수 알고리즘의 출발점을 동일하게 맞추게 되므로, 이후 실행되는 난수 생성 함수는 언제나 100% 동일한 숫자의 나열을 반환합니다. 이는 무작위성이 개입된 분석을 동료 연구자가 그대로 재현하고 검증할 수 있게 해주는 필수적인 장치입니다.

2.1 무작위 표본 선택

난수 생성 원리를 이해하셨으니 이제 방대한 표집 틀에서 무작위 표본의 위치(행 번호)를 선택해 보겠습니다. R에는 지정된 범위 안에서 정수 형태의 난수를 중복 없이 뽑아주는 sample.int라는 유용한 함수가 있습니다. 참고로 범용 함수인 sample()은 벡터의 원소를 직접 섞거나 뽑을 때 쓰이며, sample.int()는 그중 “1부터 n까지의 정수”를 뽑는 데 특화된 형태라고 이해하시면 됩니다. sample.int 함수에는 크게 두 가지 핵심 인자(입력값)가 필요합니다. 하나는 표집 틀의 전체 대상 수(n)이고, 다른 하나는 추출하고자 하는 표본의 수(size)입니다. 기본적인 형태는 다음과 같습니다.

sample_rows <- sample.int(n = 전체_데이터_크기, size = 원하는_표본_크기)

이 함수는 무작위로 선택된 행 번호들을 담은 벡터를 반환합니다. 실전 예제를 들어보겠습니다. 현대 야구 데이터 분석에서 빼놓을 수 없는 방대한 데이터셋 중 하나가 바로 투구 궤적 시스템인 PitchF/x 데이터입니다. 이 안에는 구속, 회전수, 투구 유형, 스트라이크존 통과 좌표 등 2007년부터 누적된 수많은 투구 정보가 기록되어 있으며, 2019년 시즌 종료 기준으로 무려 8,812,107개의 행을 가지고 있습니다. 이 어마어마한 데이터를 한 번에 모델링하면 연산 과부하가 걸리기 쉬우므로, 무작위로 1,000개의 투구만을 추출하여 소규모 테스트 모델을 만들어보고자 합니다. 880만 개 중 1,000개의 행 번호를 무작위로 뽑으려면 다음 코드를 실행하십시오.

이때 R에서는 천 단위나 백만 단위를 표시하는 쉼표(,)를 숫자에 포함해서는 안 된다는 점을 명심해 주십시오. 하지만 하드코딩으로 8812107이라는 숫자를 직접 입력하는 것은 위험한 코딩 습관입니다. 실제 실무에서는 데이터의 행이 실시간으로 변할 수 있으므로, 해당 데이터 프레임이 pitch라는 이름으로 저장되어 있다면 nrow(pitch) 함수를 사용하여 R이 스스로 전체 행 수를 계산하게 만드는 것이 안전합니다.

sample.int는 단지 1,000개의 ’행 번호’만 알려줄 뿐입니다. 우리가 진정으로 원하는 것은 그 번호에 해당하는 실제 ’데이터 기록’을 가져와 새 데이터 프레임으로 떼어내는 것입니다. 앞서 배운 대괄호 행 서브세팅을 응용하여, 난수로 반환된 행 번호 벡터를 데이터 프레임의 행 인덱스 자리에 통째로 밀어 넣으면 됩니다.

pitch[sample.int(n = nrow(pitch), size = 1000), ]

위 코드를 실행하면 무작위로 선택된 1,000개의 투구 데이터가 화면에 쏟아져 나옵니다. 이를 향후 분석에 활용하기 위해서는 새로운 객체로 저장해 두어야 합니다. 화살표 연산자를 사용하여 깔끔하게 저장해 보겠습니다.

pitch_sample <- pitch[sample.int(n = nrow(pitch), size = 1000), ]

이제 여러분은 완벽하게 편향이 배제된 1,000개의 무작위 투구 데이터를 pitch_sample이라는 새로운 데이터 프레임에 성공적으로 확보하게 되었습니다. 만일 5,000개의 표본이 필요하다면 size = 5000으로 인자만 수정해 주시면 됩니다.

3 R에서 도움말 얻기

방대한 데이터 분석 프로젝트를 수행하다 보면, 불가피하게 코드에 에러가 발생하거나 함수의 정확한 문법이 기억나지 않는 순간이 찾아옵니다. 혹은 다른 사람의 코드에서 마주친 낯선 함수가 과연 어떤 기능을 하는지 직접 확인해야 할 때도 있습니다. 목적은 뚜렷하지만 이를 구현할 R 코드를 모르겠거나 알 수 없는 에러 코드에 직면했다면, 구글이나 스택 오버플로(Stack Overflow) 같은 개발자 커뮤니티를 적극적으로 검색해 보십시오. 전 세계 R 사용자 커뮤니티는 여러분이 상상하는 거의 모든 문제에 대한 해답을 이미 축적해 두고 있습니다.

만약 특정한 R 내장 함수나 패키지 함수의 세부 인자와 작동 방식이 궁금하다면, 굳이 웹 브라우저를 열 필요 없이 R 내부의 help 함수나 단축 기호인 ?를 활용하는 빠르고 확실한 방법이 있습니다. 가령 앞서 배운 sample.int 함수의 공식 매뉴얼을 열람하고 싶으시다면 콘솔창에 다음 중 하나를 입력하십시오.

help(sample.int)
?sample.int

이 명령어를 실행하면 RStudio 하단의 Help 패널에 해당 함수의 상세한 설명, 입력 인자의 제약 조건, 반환되는 출력값의 형태가 표시됩니다. 공식 문서의 맨 아랫부분에는 연구자들이 직관적으로 따라 해 볼 수 있는 예제 코드(Examples)들이 수록되어 있으므로, 반드시 이를 복사하여 직접 실행해 보시기를 권장합니다.

5 tidyverse로 서브세팅과 표본 추출을 읽기 쉽게 쓰기

대괄호를 이용한 베이스 R의 서브세팅은 핵심 원리를 관통하는 근본 문법이므로 반드시 그 메커니즘을 숙지해야 합니다. 그러나 실무 분석 스크립트에서는 행을 거르는 조건과 열을 선택하는 의도를 더 직관적으로 표현하기 위해 dplyr 패키지의 문법을 널리 사용합니다. 다음 코드는 파이프 연산자(|>)를 활용하여, 하루 평균 소비 시간이 1시간을 넘는 활동만 남긴 뒤 우리가 분석에 사용할 특정 열만을 깔끔하게 골라내는 과정을 보여줍니다.

무작위 표본 추출 역시 dplyr의 세련된 함수로 대체할 수 있습니다. sample.int()는 난수 인덱스의 생성 원리를 이해하거나 복잡한 행 번호 연산이 필요할 때 유용하지만, slice_sample() 함수를 사용하면 데이터 프레임에서 곧바로 지정된 수의 무작위 행을 곧바로 뽑아낼 수 있습니다. 다른 연구자가 여러분의 결과를 검증할 수 있도록, 표본 추출 직전에 set.seed()를 선언하는 습관을 들이시기 바랍니다.

set.seed(2026)

activities |>
  slice_sample(n = 2)
# A tibble: 2 × 3
  name        average_hours category     
  <chr>               <dbl> <chr>        
1 Sleeping             8.84 Personal Care
2 Socializing          0.64 Leisure

거듭 강조하지만, set.seed()는 데이터의 내재된 무작위성을 인위적으로 훼손하는 명령어가 결코 아닙니다. 이는 오히려 데이터 추출의 출발점을 투명하게 고정함으로써, 수업 자료, 논문, 그리고 머신러닝의 검증 과정에서 독자가 여러분과 완벽히 동일한 표본을 독립적으로 재현해 낼 수 있도록 돕는 과학적인 기록 장치입니다. 실제 연구 현장에서는 표본 추출의 명확한 절차와 시드 고정 여부를 기록으로 남겨, 분석자가 무작위성이라는 변수를 얼마나 엄격하게 통제했는지 분명히 증명해야 합니다.
