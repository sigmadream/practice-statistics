시각화: 계층

그래픽의 레이어 문법(layered grammar of graphics)을 배우며 기초를 확장합니다. 먼저 시각 속성(aesthetic mappings), 도형(geometric objects), 분할(facets)을 더 깊이 알아보겠습니다.

막대 그래프의 막대 높이나 상자 그림의 중앙값처럼 그래프할 새 값을 계산하는 과정은 필수적입니다. 그래프에 도형(geoms)이 표시되는 방식을 수정하는 위치 조정(position adjustments)도 필요합니다. 이 장에서는 이런 시각화 정보를 다루는 방법을 소개합니다.

library(tidyverse)

1 시각 속성

“그림의 큰 가치는 전혀 기대하지 않았던 것을 보게 만들 때 나타난다.” - 존 튜키(John Tukey)

ggplot2 패키지와 함께 제공되는 mpg 데이터 프레임에 38개 자동차 모델의 관측치 234개가 포함되어 있다는 점을 기억하세요.

mpg
#> # A tibble: 234 × 11
#>   manufacturer model displ  year   cyl trans      drv     cty   hwy fl   
#>   <chr>        <chr> <dbl> <int> <int> <chr>      <chr> <int> <int> <chr>
#> 1 audi         a4      1.8  1999     4 auto(l5)   f        18    29 p    
#> 2 audi         a4      1.8  1999     4 manual(m5) f        21    29 p    
#> 3 audi         a4      2    2008     4 manual(m6) f        20    31 p    
#> 4 audi         a4      2    2008     4 auto(av)   f        21    30 p    
#> 5 audi         a4      2.8  1999     6 auto(l5)   f        16    26 p    
#> 6 audi         a4      2.8  1999     6 manual(m5) f        18    26 p    
#> # ℹ 228 more rows
#> # ℹ 1 more variable: class <chr>

mpg의 변수 중에는 다음이 있습니다.

  1. displ: 자동차의 엔진 크기(리터), 숫자형(numerical) 변수입니다.

  2. hwy: 고속도로에서의 자동차 연료 효율(mpg, 갤런당 마일), 연료 효율이 낮은 자동차는 같은 거리를 주행할 때 연료 효율이 높은 자동차보다 더 많은 연료를 소비합니다. 숫자형 변수입니다.

  3. class: 자동차의 유형, 범주형(categorical) 변수입니다.

여러 class의 자동차에서 displ과 hwy의 관계를 시각화하며 시작하겠습니다.

숫자형 변수는 x와 y 시각 속성에, 범주형 변수는 color나 shape 같은 시각 속성에 매핑(Aesthetic mappings)한 산점도를 사용합니다.

# Left
ggplot(mpg, aes(x = displ, y = hwy, color = class)) +
  geom_point()

# Right
ggplot(mpg, aes(x = displ, y = hwy, shape = class)) +
  geom_point()
#> Warning: The shape palette can deal with a maximum of 6 discrete values because more
#> than 6 becomes difficult to discriminate
#> ℹ you have requested 7 values. Consider specifying shapes manually if you
#>   need that many of them.
#> Warning: Removed 62 rows containing missing values or values outside the scale range
#> (`geom_point()`).

class가 shape에 매핑되면 두 가지 경고가 표시됩니다.

1: The shape palette can deal with a maximum of 6 discrete values because more than 6 becomes difficult to discriminate; you have 7. Consider specifying shapes manually if you must have them.
2: Removed 62 rows containing missing values (`geom_point()`).

ggplot2는 기본적으로 한 번에 모양을 6개만 사용하므로 추가 그룹은 그래프되지 않습니다. 데이터셋의 모든 데이터가 그래프에 표현되지 않습니다.

class를 size나 alpha 시각 속성에 매핑할 수도 있습니다. 각각 점의 크기와 투명도를 제어합니다.

# Left
ggplot(mpg, aes(x = displ, y = hwy, size = class)) +
  geom_point()
#> Warning: Using size for a discrete variable is not advised.

# Right
ggplot(mpg, aes(x = displ, y = hwy, alpha = class)) +
  geom_point()
#> Warning: Using alpha for a discrete variable is not advised.

이 두 가지 모두 경고를 생성합니다.

Using alpha for a discrete variable is not advised.

순서가 없는 이산형(범주형) 변수(class)를 순서가 있는 시각 속성(size 또는 alpha)에 매핑하면 실제로 존재하지 않는 순위(ranking)를 암시하므로 바람직하지 않습니다.

시각 속성을 매핑하면 나머지는 ggplot2가 처리합니다. 알맞은 스케일(scale)을 선택하고 수준(levels)과 값(values)의 매핑을 설명하는 범례(legend)를 구성합니다. x와 y 시각 속성에는 범례 대신 눈금 마크(tick marks)와 라벨이 있는 축 선(axis line)을 만듭니다. 축 선은 범례처럼 위치와 값의 매핑을 설명합니다.

변수 매핑에 의존하지 않고 aes() 밖에서 도형 함수의 인수로 시각적 속성을 직접 설정할 수도 있습니다. 예를 들어 그래프의 모든 점을 파란색으로 만듭니다.

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point(color = "blue")

여기서 색상은 변수 정보를 전달하지 않고 그래프의 모양만 바꿉니다. 해당 시각 속성에 알맞은 값을 선택해야 합니다.

  • 문자열로 된 색상 이름(color = "blue")
  • mm 단위의 점 크기(size = 1)
  • 숫자로 된 점 모양(shape = 1)

Figure 1에서 점 객체를 매핑하거나 설정할 수 있는 시각 속성을 살펴봤습니다. 가능한 모든 시각 속성은 https://ggplot2.tidyverse.org/articles/ggplot2-specs.html의 시각 속성 사양 비넷(aesthetic specifications vignette, 관련 문서)에서 확인하세요.

그래프에서 쓸 수 있는 시각 속성은 데이터를 나타내는 도형에 따라 다릅니다.

2 도형

이 두 그래프은 어떻게 비슷한가요?

두 그래프은 동일한 x 변수와 y 변수를 포함하며 같은 데이터를 설명합니다. 하지만 서로 같은 그래프은 아닙니다. 데이터를 나타내는 양식(geometric object), 즉 도형(geom)이 다릅니다. 왼쪽 그래프은 점 도형을, 오른쪽 그래프은 데이터에 적합된(fitted) 매끄러운(smooth) 선 도형을 사용합니다.

그래프의 도형을 바꾸려면 ggplot()의 도형 함수를 변경하세요.

# Left
ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point()

# Right
ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_smooth()
#> `geom_smooth()` using method = 'loess' and formula = 'y ~ x'

ggplot2의 모든 도형 함수는 mapping 인수를 사용합니다. 이 인수는 도형 레이어에 정의하거나 ggplot() 레이어에 전역으로 정의합니다. 다만 모든 시각 속성이 모든 도형에서 작동하지는 않습니다.

점의 모양은 설정하지만 선의 “모양(shape)”은 설정하지 못합니다. 시도해도 ggplot2는 해당 시각 속성을 조용히 무시합니다. 반면 선종류(linetype)는 설정할 수 있습니다.

geom_smooth()는 선종류에 매핑한 변수의 고유 값마다 다른 선을 그립니다.

# Left
ggplot(mpg, aes(x = displ, y = hwy, shape = drv)) +
  geom_smooth()

# Right
ggplot(mpg, aes(x = displ, y = hwy, linetype = drv)) +
  geom_smooth()

geom_smooth()는 자동차의 구동계(drive train)를 나타내는 drv 값에 따라 자동차를 세 선으로 나눕니다. 각 선은 각각 4, f, r 값을 가진 모든 점을 설명합니다.

여기서 4는 4륜 구동(four-wheel drive), f는 전륜 구동(front-wheel drive), r은 후륜 구동(rear-wheel drive)을 의미합니다.

이 설명이 낯설다면 원시 데이터(raw data) 위에 선을 오버레이(overlaying)하고 drv에 따라 모두 색칠하면 더 명확해집니다.

ggplot(mpg, aes(x = displ, y = hwy, color = drv)) +
  geom_point() +
  geom_smooth(aes(linetype = drv))

이 그래프에는 한 그래프에 도형이 두 개 들어 있다는 점에 유의하세요.

geom_smooth()와 같은 많은 도형은 여러 데이터 행을 단일 도형로 표시합니다. 여러 객체를 그리려면 범주형 변수에 group 시각 속성을 설정합니다. ggplot2는 그룹화 변수의 고유 값마다 별도의 객체를 그립니다. 이산형 변수를 시각 속성에 매핑하면 위의 linetype 예제처럼 이러한 도형의 데이터를 자동으로 그룹화합니다. group 시각 속성 자체는 도형에 범례나 구별되는 특징(distinguishing features)을 추가하지 않으므로 이 기능을 활용하기 편리합니다.

# Left
ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_smooth()

# Middle
ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_smooth(aes(group = drv))

# Right
ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_smooth(aes(color = drv), show.legend = FALSE)

도형 함수를 배치하면 ggplot2는 이를 해당 레이어의 지역 매핑으로 취급합니다. 지역 매핑은 그 레이어에서는 전역 매핑을 확장하거나 덮어씁니다(overwrite). 따라서 레이어마다 서로 다른 시각 속성을 표시합니다.

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point(aes(color = class)) +
  geom_smooth()

같은 방식으로 각 레이어에 서로 다른 data를 지정할 수도 있습니다. 여기서는 2인승(two-seater) 자동차를 강조하려고 빨간색 점과 속이 빈 원을 사용합니다. geom_point()의 로컬 데이터 인수는 해당 레이어에서만 ggplot()의 전역 데이터를 무효화(overrides)합니다.

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  geom_point(
    data = mpg |> filter(class == "2seater"),
    color = "red"
  ) +
  geom_point(
    data = mpg |> filter(class == "2seater"),
    shape = "circle open", size = 3, color = "red"
  )

도형은 ggplot2의 기본 구성 요소(building blocks)입니다. 도형을 바꾸면 그래프의 모양(look)이 완전히 달라지고 데이터의 다른 특징이 드러납니다.

아래의 히스토그램과 밀도 그래프(density plot)에서는 고속도로 주행 거리(highway mileage)의 분포가 쌍봉형(bimodal)이고 오른쪽으로 꼬리가 긴 형태(right skewed)입니다. 상자 그림(boxplot)에는 잠재적인 이상치(outliers)가 두 개 나타납니다.

# Left
ggplot(mpg, aes(x = hwy)) +
  geom_histogram(binwidth = 2)

# Middle
ggplot(mpg, aes(x = hwy)) +
  geom_density()

# Right
ggplot(mpg, aes(x = hwy)) +
  geom_boxplot()

다른 도형이 필요하면 먼저 확장 패키지(extension packages)부터 찾아보세요(샘플링은 https://exts.ggplot2.tidyverse.org/gallery/ 참조).

예를 들어 ggridges 패키지(https://wilkelab.org/ggridges)는 릿지라인 그래프(ridgeline plots)을 만듭니다. 이 그래프은 범주형 변수의 여러 수준에서 숫자형 변수의 밀도를 시각화할 때 유용합니다.

다음 그래프에서는 새로운 도형(geom_density_ridges())을 사용합니다. 동일한 변수 drv를 y, fill, color에 매핑하고 밀도 곡선을 투명하게 하려고 alpha = 0.5도 설정했습니다.

library(ggridges)

ggplot(mpg, aes(x = hwy, y = drv, fill = drv, color = drv)) +
  geom_density_ridges(alpha = 0.5, show.legend = FALSE)
#> Picking joint bandwidth of 1.28

ggplot2의 모든 도형과 패키지 함수를 포괄적으로 보려면 참조 페이지 https://ggplot2.tidyverse.org/reference를 이용하세요. 단일 도형은 도움말(?geom_smooth)에서 자세히 알아볼 수 있습니다.

3 분할

facet_wrap()을 사용한 분할(faceting)은 범주형 변수를 기준으로 그래프을 하위 그래프(subplots)으로 나눕니다. 각 하위 그래프은 데이터의 부분 집합(subset) 하나를 표시합니다.

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  facet_wrap(~cyl)

두 변수의 조합(combination)으로 그래프을 분할 처리하려면 facet_wrap() 대신 facet_grid()를 사용하세요. facet_grid()의 첫 번째 인수도 공식(formula)이지만 이번에는 rows ~ cols 형태의 양면(double sided) 공식입니다.

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  facet_grid(drv ~ cyl)

기본적으로 모든 분할은 x축과 y축의 스케일과 범위를 공유합니다. 분할 전체의 데이터를 비교할 때는 유용하지만 각 분할 안의 관계를 시각화할 때는 제약이 될 수 있습니다.

분할 함수의 scales 인수를 "free_x"로 설정하면 열마다 x축 스케일이 달라집니다. "free_y"는 행마다 y축 스케일을 다르게 하고 "free"는 둘 다 허용합니다.

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  facet_grid(drv ~ cyl, scales = "free")

  geom_point(aes(x = drv, y = cyl))

4 통계적 변환

geom_bar() 또는 geom_col()로 그려진 기본적인 막대 차트를 고려해 보세요. 다음 차트는 cut별로 그룹화된 diamonds 데이터셋의 총 다이아몬드 수를 표시합니다. diamonds 데이터셋은 ggplot2 패키지에 있으며 각 다이아몬드의 price, carat, color, clarity, cut을 포함하여 약 54,000개의 다이아몬드에 대한 정보가 들어 있습니다.

차트를 보면 저품질 컷보다 고품질 컷 다이아몬드가 더 많습니다.

ggplot(diamonds, aes(x = cut)) +
  geom_bar()

x축에는 diamonds의 변수인 cut이 표시됩니다. y축에는 개수(count)가 표시되지만 개수는 diamonds의 변수가 아닙니다! 어디에서 온 값일까요? 산점도처럼 데이터셋의 원시 값(raw values)을 그래프하는 그래프가 많지만 막대 차트처럼 새 값을 계산하는 그래프도 있습니다.

  1. 막대 차트, 히스토그램 및 빈도 다각형(frequency polygons)은 데이터를 구간(bin)으로 나누고 각 구간에 속하는 점의 수인 구간 개수를 그래프합니다.

  2. 스무더(Smoothers)는 데이터에 모델을 적합시킨(fit a model) 다음 모델의 예측값을 그래프합니다.

  3. 상자 그림(Boxplots)은 분포의 5가지 요약 수치(five-number summary)를 계산한 다음 그 요약을 특별한 형식의 상자로 표시합니다.

그래프의 새 값을 계산하는 알고리즘을 통계적 변환(statistical transformation)의 줄임말인 stat이라고 합니다. 다음은 이 과정이 geom_bar()에서 작동하는 방식입니다.

도형이 사용하는 stat은 stat 인수의 기본값에서 확인합니다. 예를 들어 ?geom_bar를 보면 stat의 기본값은 “count”입니다. 곧 geom_bar()가 stat_count()를 사용한다는 뜻입니다.

stat_count()는 geom_bar()와 같은 페이지에 문서화되어 있습니다. 아래로 스크롤하면 “Computed variables(계산된 변수)” 섹션에서 새 변수 count와 prop을 계산한다고 설명합니다.

모든 도형에는 기본(default) stat이 있으며 모든 stat에는 기본 도형이 있습니다. 따라서 일반적으로 기본 통계적 변환을 따로 신경 쓰지 않고 도형을 사용합니다.

하지만 stat을 명시적으로 사용해야 하는 이유가 세 가지 있습니다.

  1. 기본 stat을 재정의(override)할 때입니다. 아래 코드에서는 geom_bar()의 stat을 개수(count)(기본값)에서 항등(identity)으로 바꿉니다. 그러면 막대 높이를 y 변수의 원시 값에 매핑합니다.
diamonds |>
  count(cut) |>
  ggplot(aes(x = cut, y = n)) +
  geom_bar(stat = "identity")
  1. 변환된 변수와 시각 속성의 기본 매핑을 재정의할 때입니다. 예를 들어 개수 대신 비율(proportions) 막대 차트를 표시합니다. stat이 계산하는 변수는 geom_bar() 도움말의 “computed variables” 섹션에서 찾으세요.
ggplot(diamonds, aes(x = cut, y = after_stat(prop), group = 1)) +
  geom_bar()
  1. 코드에서 통계적 변환을 강조할 때입니다. 예를 들어 고유한 각 x 값의 y 값을 요약하는 stat_summary()를 사용하면 계산할 요약 수치가 눈에 띕니다.
ggplot(diamonds) +
  stat_summary(
    aes(x = cut, y = depth),
    fun.min = min,
    fun.max = max,
    fun = median
  )

ggplot2에는 stat이 20개 이상 있습니다. 각 stat은 함수이므로 일반적인 방법(?stat_bin)으로 도움말을 볼 수 있습니다.

5 위치 조정

막대 차트에는 또 다른 마법이 있습니다. color 시각 속성이나 더 유용한 fill 시각 속성으로 막대 차트에 색을 입힙니다.

# Left
ggplot(mpg, aes(x = drv, color = drv)) +
  geom_bar()

# Right
ggplot(mpg, aes(x = drv, fill = drv)) +
  geom_bar()

fill 시각 속성을 class 같은 다른 변수에 매핑하면 막대가 자동으로 누적(stacked)됩니다. 각 색상 사각형은 drv와 class의 조합을 나타냅니다.

ggplot(mpg, aes(x = drv, fill = class)) +
  geom_bar()

누적(stacking)은 position 인수로 지정한 위치 조정(position adjustment)에 따라 자동으로 이루어집니다. 누적 막대 차트를 원하지 않으면 "identity", "dodge", "fill" 가운데 하나를 사용합니다.

  1. position = "identity"는 각 객체를 그래프의 원래 위치에 정확히 배치합니다. 막대가 겹치므로 막대 차트에는 그다지 유용하지 않습니다. 겹침을 보려면 alpha를 작은 값으로 설정해 막대를 약간 투명하게 하거나 fill = NA로 완전히 투명하게 만들어야 합니다. 항등(identity) 위치 조정은 이를 기본값으로 쓰는 점(points) 같은 2차원 도형에 더 유용합니다.
# Left
ggplot(mpg, aes(x = drv, fill = class)) +
  geom_bar(alpha = 1/5, position = "identity")

# Right
ggplot(mpg, aes(x = drv, color = class)) +
  geom_bar(fill = NA, position = "identity")

  1. position = "fill"은 누적처럼 작동하지만 각 누적 막대 세트의 높이를 같게 만듭니다. 그러면 그룹 간 비율을 쉽게 비교합니다.

  2. position = "dodge"는 겹치는 객체를 나란히 배치합니다. 그러면 개별 값을 쉽게 비교합니다.

# Left
ggplot(mpg, aes(x = drv, fill = class)) +
  geom_bar(position = "fill")

# Right
ggplot(mpg, aes(x = drv, fill = class)) +
  geom_bar(position = "dodge")

막대 차트에는 유용하지 않지만 산점도에는 매우 유용한 조정도 있습니다. 첫 번째 산점도를 다시 떠올려보세요. 데이터셋에는 관측치가 234개인데 그래프에는 점이 126개만 표시됩니다.

기저(underlying)의 hwy와 displ 값이 반올림되어 점들이 그리드(grid)에 나타나고 서로 많이 겹칩니다. 이 문제를 오버플로팅(overplotting)이라고 합니다.

이러한 배치(arrangement)는 데이터 분포를 파악하기 어렵게 만듭니다. 데이터 포인트가 그래프 전체에 고르게 퍼져 있나요, 아니면 hwy와 displ의 특정 조합에 값 109개가 몰려 있나요?

위치 조정을 “jitter”로 설정하면 이 그리딩(gridding)을 피합니다. position = "jitter"는 각 점에 소량의 임의 노이즈(random noise)를 더합니다. 두 점이 같은 양의 노이즈를 받을 가능성이 거의 없어 점들이 넓게 퍼집니다.

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point(position = "jitter")

무작위성(randomness)을 추가해 그래프을 개선한다는 말이 이상하게 들릴 수 있습니다. 소규모에서는 그래프의 정확성이 떨어지지만 대규모에서는 그래프가 더 많은 것을 드러냅니다(revealing).

이 작업은 매우 유용해서 ggplot2가 geom_point(position = "jitter")의 약어인 geom_jitter()를 제공합니다.

위치 조정은 각 조정의 도움말 페이지(?position_dodge, ?position_fill, ?position_identity, ?position_jitter, ?position_stack)에서 자세히 알아보세요.

6 좌표계

좌표계(Coordinate systems)는 ggplot2에서 다소 복잡한 부분입니다. 기본값은 x 위치와 y 위치가 독립적으로 작용해 각 점의 위치를 정하는 데카르트 좌표계(Cartesian coordinate system)입니다. 이 밖에 유용한 좌표계가 두 가지 있습니다.

  1. coord_quickmap()은 지리 지도(geographic maps)의 가로세로 비율(aspect ratio)을 올바르게 설정합니다. ggplot2로 공간 데이터(spatial data)를 그래프할 때 매우 중요합니다.
nz <- map_data("nz")

ggplot(nz, aes(x = long, y = lat, group = group)) +
  geom_polygon(fill = "white", color = "black")

ggplot(nz, aes(x = long, y = lat, group = group)) +
  geom_polygon(fill = "white", color = "black") +
  coord_quickmap()

  1. coord_polar()는 극좌표(polar coordinates)를 사용합니다. 극좌표에서는 막대 차트와 콕스콤 차트(Coxcomb chart, 나이팅게일의 장미 다이어그램)의 흥미로운 연관성이 드러납니다.
bar <- ggplot(data = diamonds) +
  geom_bar(
    mapping = aes(x = clarity, fill = clarity),
    show.legend = FALSE,
    width = 1
  ) +
  theme(aspect.ratio = 1)

bar + coord_flip()
bar + coord_polar()

7 그래픽의 레이어 문법

그래프 작성 템플릿에 위치 조정, stats, 좌표계, 분할 처리를 더하면 다음처럼 확장됩니다.

ggplot(data = <DATA>) +
  <GEOM_FUNCTION>(
     mapping = aes(<MAPPINGS>),
     stat = <STAT>,
     position = <POSITION>
  ) +
  <COORDINATE_FUNCTION> +
  <FACET_FUNCTION>

새 템플릿은 대괄호로 묶인 단어 7개를 매개변수로 받습니다. 실제로 ggplot2는 데이터, 매핑, 도형 함수를 제외한 모든 항목에 유용한 기본값을 둡니다. 따라서 그래프를 만들 때 매개변수 7개를 모두 지정하는 경우는 거의 없습니다.

템플릿의 매개변수 7개는 그래프을 구축하는 형식적 시스템(formal system), 즉 그래픽의 문법(grammar of graphics)을 구성합니다. 그래픽의 문법은 어떤 그래프이든 데이터셋, 도형, 매핑 집합, stat, 위치 조정, 좌표계, 분할 체계(faceting scheme), 테마(theme)의 조합으로 고유하게 설명된다는 통찰(insight)에 기반합니다.

작동 방식을 이해하려면 기본적인 그래프을 처음부터 만드는 과정을 생각해 보세요. 데이터셋에서 시작해 표시할 정보로 변환합니다(stat 사용).

다음으로 변환된 데이터의 각 관측치를 나타낼 도형를 선택합니다. 도형의 시각 속성 속성으로 데이터의 변수를 나타내며 각 변수의 값을 시각 속성의 수준(levels)에 매핑합니다.

그 후에는 객체의 위치(그 자체로 시각 속성 속성임)로 x와 y 변수의 값을 표시할 좌표계를 선택합니다.

이제 완전한 그래프가 만들어집니다. 여기에 좌표계 안에서 도형의 위치를 더 조정하거나(위치 조정) 그래프를 하위 그래프으로 나눌 수도 있습니다(분할). 데이터셋, 도형, 매핑 집합, stat, 위치 조정을 사용하는 레이어를 하나 이상 더해 그래프을 확장할 수도 있습니다.

상상하는 어떤 그래프이든 이 방법으로 만들 수 있습니다. 다시 말해 이 장에서 배운 코드 템플릿으로 수십만 개의 고유한 그래프을 만들 수 있습니다.
