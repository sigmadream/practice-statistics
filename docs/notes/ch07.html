1. R을 이용한 탐색적 데이터 분석(EDA)

R을 이용한 탐색적 데이터 분석(EDA)

서론

이전 R 튜토리얼에서는 R에서 사용할 수 있는 라이브러리를 활용하거나 readr::read_csv()를 사용하여 csv 파일을 작업 공간(Workspace)에 로드하는 방법에 대해 알아보았습니다. 본 튜토리얼에서는 요약 수치를 계산하는 방법과 데이터를 시각화하는 데 사용되는 다양한 그래프를 생성하는 방법에 대해 설명합니다. R 4.6 실습에서는 기본 R 함수의 원리를 먼저 확인하되, 그래프와 파이프라인 예제는 ggplot2와 dplyr을 포함한 tidyverse 문법으로 작성하겠습니다.

library(tidyverse)
library(MASS)
library(Ecdat)

R에서의 빈도표 및 분할표

범주형 변수를 다룰 때 탐색적 분석의 주요 형태는 빈도표(하나의 변수일 경우) 또는 분할표(Contingency table, 두 개의 변수일 경우)입니다. 이 표들로부터 표본 비율(Sample proportion)을 계산하는 것은 간단합니다. R에서는 table 함수 하나로 이 두 가지 유형의 표를 모두 생성할 수 있습니다. 빈도표를 생성하기 위한 table 함수의 코드는 다음과 같습니다.

table(variable)

위 코드를 입력한 후 Enter를 누릅니다. 여기서 “Variable”은 입력된 벡터(Vector)의 이름이거나, $ 기호를 사용하여 더 큰 데이터 프레임(Data frame)에서 선택한 변수일 수 있습니다. 그러면 R은 table 문에 지정한 변수의 빈도표를 반환합니다. MASS 라이브러리에 포함된 quine 데이터셋을 살펴보겠습니다. 이 데이터는 호주 학생들의 결석에 대한 조사 결과로, 각 학생의 인종(원주민 또는 비원주민), 성별(남성 또는 여성), 학습 능력(평균 학습자 또는 느린 학습자) 등의 데이터가 포함되어 있습니다. 설문에서 정의된 인종별 분포를 알고 싶다면(quine 데이터 프레임의 Eth 변수), 아래 코드를 사용하여 원주민 학생이 69명, 비원주민 학생이 77명임을 확인할 수 있습니다.

table(quine$Eth)

분할표의 경우, 표에 변수가 하나가 아니라 두 개가 들어간다는 점을 제외하면 코드는 거의 동일하며 다음과 같이 바뀝니다.

table(variable1, variable2)

마찬가지로, 이 변수들은 입력된 벡터이거나 더 큰 데이터 프레임에서 선택된 변수일 수 있습니다. 동일한 quine 데이터셋을 사용하여 학생의 인종(quine 데이터 프레임의 Eth 변수)과 학습 능력(quine 데이터 프레임의 Lrn 변수)에 대한 분할표를 살펴볼 수 있습니다. 코드는 다음과 같습니다.

table(quine$Eth, quine$Lrn)

이 코드를 실행하면 아래와 같은 분할표를 얻을 수 있습니다.

평균 학습자 느린 학습자
원주민 40 29
비원주민 43 34

R은 행이나 열의 주변 합계(Marginal total) 또는 표의 전체 합계를 기본적으로 제공하지 않는다는 점에 유의해 주세요. 이러한 값들은 필요에 따라 적절한 행과 열을 더하거나, addmargins와 같은 R의 다른 함수를 활용하여 구할 수 있습니다.

R에서의 수치적 탐색 분석

이 섹션에서는 R에서 양적 변수의 요약 수치를 계산하는 방법을 살펴보겠습니다. 따라서 단일 양적 변수의 중심(Center)과 산포(Spread)에 대한 요약 수치를 구하는 것과 두 양적 변수 간의 상관관계(Correlation)를 구하는 것에 집중할 것입니다. 시각적 요약은 이후 섹션에서 다루겠습니다.

변수의 중심 경향 요약

먼저, 이전에 학습한 변수의 중심을 나타내는 두 가지 주요 요약 수치인 표본 평균(Sample mean)과 표본 중앙값(Sample median)을 상기해 보겠습니다. R에서는 벡터에 저장된 변수에 대해 이러한 수치들을 쉽게 계산할 수 있습니다. 평균을 계산하는 코드는 다음과 같습니다.

mean(variable, na.rm = TRUE)

그리고 중앙값을 계산하는 코드는 다음과 같습니다.

median(variable, na.rm = TRUE)

두 경우 모두 “Variable”은 직접 입력한 벡터에 저장되어 있거나 데이터 프레임 내에 저장되어 있을 수 있습니다. 예를 들어, Ecdat 라이브러리의 Housing 데이터셋[12,29]을 살펴보겠습니다. 이 데이터셋은 윈저(Windsor)시의 주택 특성과 판매 가격을 다루겠습니다. 주택 판매 가격(price 변수)의 평균을 구하고 싶다면 다음을 사용합니다.

mean(Housing$price, na.rm = TRUE)

중앙값의 경우 다음과 같습니다.

median(Housing$price, na.rm = TRUE)

실행 결과 평균 판매 가격은 68,121.6이고 중앙값은 62,000임을 알 수 있습니다. 또한 mean 및 median 함수를 벡터 서브세팅(Subsetting)과 함께 사용하여 여러 그룹의 평균과 중앙값을 비교할 수도 있습니다. 예를 들어, 선호 지역(prefarea 변수, “yes” 또는 “no” 값을 가짐)에 따른 주택의 평균 판매 가격을 비교하고 싶다면 다음과 같이 입력하시면 됩니다.

mean(Housing$price[Housing$prefarea == "yes"], na.rm = TRUE)
mean(Housing$price[Housing$prefarea == "no"], na.rm = TRUE)

결과를 통해 선호 지역의 평균 판매 가격은 83,986.37이고, 비선호 지역은 63,263.49임을 확인할 수 있습니다. 중앙값을 비교할 때도 mean 함수 대신 median 함수를 사용하면 코드는 유사합니다.

변수의 산포 요약

변수의 산포를 살펴볼 때 우리는 범위(Range), 분산(Variance), 표준 편차(Standard deviation), 사분위수 범위(Interquartile range, IQR)라는 네 가지 요약 수치에 집중했습니다. 이러한 각 요약 수치는 R에서 단 한 줄의 코드로 각각 계산할 수 있습니다. 범위와 사분위수 범위부터 시작하겠습니다. 복습하자면, 범위는 최댓값에서 최솟값을 뺀 값이고, 사분위수 범위는 제3사분위수(Q3)에서 제1사분위수(Q1)를 뺀 값입니다. 이 네 가지 값에 중앙값을 더하면 변수의 다섯 수치 요약(Five-number summary)이 됩니다. 따라서 다섯 수치 요약을 구할 수 있다면 이 두 가지 요약 수치를 모두 얻을 수 있습니다. R에서 직접 입력한 벡터나 데이터 프레임에 저장된 변수의 다섯 수치 요약은 다음 코드로 구할 수 있습니다.

summary(Variable)

이 코드는 변수의 최솟값, 제1사분위수, 중앙값, 제3사분위수, 최댓값에 더해 평균까지 제공합니다. 이를 통해 범위와 IQR을 계산할 수 있습니다. 또는 range 함수를 사용하여 변수의 최솟값과 최댓값을 구하거나, IQR 함수를 사용하여 IQR을 직접 계산할 수도 있습니다.

range(variable, na.rm = TRUE)
IQR(variable, na.rm = TRUE)

summary 함수에는 분산이나 표준 편차가 포함되어 있지 않지만, 두 가지 모두 R을 사용하여 간단히 계산할 수 있습니다. 분산은 var 함수를 사용하여 다음과 같이 구할 수 있습니다.

var(variable, na.rm = TRUE)

표준 편차는 sd 함수를 사용하여 다음과 같이 구합니다.

sd(variable, na.rm = TRUE)

이러한 모든 옵션을 설명하기 위해 MASS 라이브러리의 Pima.te 데이터셋[10,30]을 살펴볼 수 있습니다. 이 데이터는 피마(Pima) 인디언 부족 여성들의 당뇨병 지표를 다루겠습니다. 예를 들어, 혈장 포도당 수치(glu 변수)의 범위와 IQR을 구하고 싶다면, 먼저 다음 코드를 사용하여 다섯 수치 요약을 구합니다.

summary(Pima.te$glu)

이 변수의 다섯 수치 요약은 다음과 같습니다.

최솟값 Q1 중앙값 Q3 최댓값
65 96 112 136.2 197

이를 통해 범위는 197−65=132이고 IQR은 136.2−96=40.2임을 알 수 있습니다. 범위와 IQR은 다음 코드를 사용하여 확인할 수 있습니다.

range(Pima.te$glu)
IQR(Pima.te$glu)

분산을 구하려면 다음과 같이 입력하시면 됩니다.

var(Pima.te$glu)

그 결과 s2=930.32임을 확인할 수 있고, 표준 편차를 구하려면 다음을 사용합니다.

sd(Pima.te$glu)

결과로 s=30.5를 얻습니다. s는 분산과 표준 편차의 정의에 따라 s2의 제곱근이라는 점에 유의해 주세요.

두 양적 변수 간의 연관성 요약

두 양적 변수 간의 연관성을 나타내는 하나의 수치 요약은 상관관계입니다. 수작업으로 상관관계를 계산하는 것은 여러 단계의 복잡한 절차와 많은 잠재적 오류가 따르는 과정입니다. R에서는 cor 함수를 사용하여 다음과 같은 코드로 상관관계를 계산합니다.

cor(Variable1, Variable2)

여기서 두 변수는 모두 입력된 벡터이거나 데이터 프레임에 저장된 것일 수 있습니다. 예시로 R 기본 환경에 저장된 cars 데이터셋을 살펴보겠습니다. 이 데이터셋은 1920년대 자동차의 속도와 그에 따른 제동 거리 사이의 관계를 다루겠습니다. 속도(speed 변수에 저장됨)와 제동 거리(dist에 저장됨) 사이의 상관관계를 계산하려면 다음과 같이 입력하시면 됩니다.

cor(cars$speed, cars$dist)

상관관계 r=0.8069를 얻을 수 있으며, 이는 속도와 제동 거리 사이에 직관적으로 강한 양의 관계가 있음을 나타냅니다. 변수의 순서가 바뀌어도 상관관계는 동일하게 유지된다는 점에 유의해 주세요. 또한, 상관관계는 두 변수 사이의 관계가 선형일 때만 해석이 가능하다는 점을 상기해 보겠습니다. 이는 산점도를 통해 시각적으로 확인할 수 있습니다. 다음 섹션에서는 데이터로부터 정보를 얻기 위해 사용할 수 있는 다양한 도표와 시각화 방법에 대해 알아보겠습니다.

결측 데이터

사용 중인 데이터셋에 따라 평균, 중앙값 또는 기타 수치 요약 결과가 NA로 반환되는 경우를 발견할 수 있습니다. 이는 해당 변수의 일부 값이 어떤 이유로 누락되었기 때문입니다. 응답자가 질문에 답하지 않았거나, 데이터가 손실되었거나, 기타 여러 가능성이 있을 수 있습니다. 수작업으로 계산할 때는 보통 누락되지 않은 다른 데이터 값들만으로 원하는 요약 수치를 계산하겠지만, R은 이를 스스로 수행하지 않습니다. 대신, 결측값을 무시하도록 R에 지시해야 합니다.

위에서 언급한 많은 함수를 포함하여 R의 대부분의 함수는 na.rm 옵션을 사용할 수 있도록 허용합니다. 이는 계산 시 NA 값을 무시하도록 R에 지시하는 TRUE/FALSE 옵션입니다. 예를 들어, NA 값이 포함된 것을 알고 있는 변수의 평균을 구하려는 경우 다음과 같은 코드를 사용합니다.

mean(variable, na.rm = TRUE)

이 과정은 median, var, sd를 포함한 다른 많은 함수에서도 유사합니다. 한 가지 주목할 만한 차이점은 cor 함수입니다. 이 함수에는 두 개의 변수가 관여하므로, 결측값이 없는 관측치, 즉 완전한 관측치(Complete observation)만 사용하고자 합니다. 이 경우 cor 함수에 use = “complete.obs”를 추가하며, 결과는 다음과 같습니다.

cor(variable1, variable2, use = "complete.obs")

na.rm 및 use 옵션은 mean이나 cor의 모든 인스턴스에 포함될 수 있지만, 결측된 관측치가 없는 경우에는 이러한 옵션이 결과 계산에 아무런 영향을 미치지 않는다는 점에 유의해 주시면 좋습니다.

  4. 주택 판매 가격(price)과 침실 수(bedrooms) 사이의 상관관계를 구해 보세요.

R에서의 시각적 탐색 분석

통계학에서 탐색적 분석을 시작하는 간단하고 일반적인 방법 중 하나는 어떤 형태의 그래프를 통하는 것입니다. 지난 장에서 산점도, 상자 그림, 히스토그램이라는 세 가지 그래프에 대해 이야기했습니다. R에서 이 세 가지 도표는 모두 생성하기 간단하며, 각 함수에는 필요에 따라 도표를 수정할 수 있는 여러 옵션이 있습니다.

산점도

산점도는 두 양적 변수 사이의 관계를 결정하는 데 사용됩니다. 이는 앞서 언급한 상관관계 해석에 필요한 선형 관계를 식별하는 것을 포함하여 여러 가지 이유로 중요합니다. 두 변수에 대한 산점도를 생성하는 데 사용하는 기본 코드는 다음과 같습니다.

ggplot(data, aes(x = x_variable, y = y_variable)) +
  geom_point()

여기서 “X-variable”은 x축을 따라 플로팅하려는 변수이고, “Y-variable”은 y축을 따라 플로팅하려는 변수입니다. 예를 들어, cars 데이터셋에서 속도와 제동 거리 사이의 관계의 선형성을 확인하고 싶다고 가정해 보겠습니다. 사용할 코드는 다음과 같습니다.

cars |>
  ggplot(aes(x = speed, y = dist)) +
  geom_point()

이 코드는 왼쪽 도표를 생성합니다. 보시다시피 소박한 도표이며 읽기가 다소 어렵습니다. ggplot2에서는 도표의 모양과 가독성을 개선하기 위해 층과 옵션을 명시적으로 더합니다.

  • labs(x = ..., y = ..., title = ...): x축, y축, 제목을 지정합니다.
  • geom_point(shape = ...): 점의 모양을 지정합니다. 기본 점 모양은 16이며, 필요하면 1부터 25까지의 숫자 중 하나를 사용할 수 있습니다.
  • color: 플로팅된 점의 색상입니다. 이 값은 문자열("red")이나 HTML 16진수 코드("#8B1F41")로 입력할 수 있습니다.
  • size, alpha: 각각 점의 크기와 투명도를 지정합니다. 많은 점이 겹칠 때 alpha를 낮추면 밀집 정도를 더 쉽게 볼 수 있습니다.
  • coord_cartesian(xlim = ..., ylim = ...): 각각 x축과 y축의 표시 범위를 지정합니다. 데이터를 잘라내지 않고 화면에 보이는 범위만 조정할 때 유용합니다.

이 모든 옵션을 사용하여 속도 및 제동 거리 도표를 개선해 보겠습니다. 결과는 오른쪽 도표에서 볼 수 있습니다. 보시다시피 속도와 제동 거리 사이의 선형성 가정이 데이터를 고려할 때 타당해 보입니다.

cars |>
  ggplot(aes(x = speed, y = dist)) +
  geom_point(size = 2, alpha = 0.8) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    x = "Speed",
    y = "Stopping Distance",
    title = "Speed vs. Stopping Distance"
  )

히스토그램

히스토그램은 데이터의 형태(Shape)를 설명하는 데 도움을 주기 위해 사용됩니다. R 4.6 실습에서는 ggplot2::geom_histogram()을 사용하여 히스토그램을 생성하며 기본 코드는 다음과 같습니다.

ggplot(data, aes(x = variable)) +
  geom_histogram()

예를 들어, R의 MASS 패키지에 있는 geyser 데이터셋을 살펴볼 수 있습니다. 이 데이터셋은 지난 장에서 다룬 올드 페이스풀(Old Faithful) 간헐천의 분출 대기 시간과 지속 시간입니다. 분출 사이의 대기 시간(geyser 데이터 프레임의 wait 변수)에 대한 히스토그램을 생성하려면 다음과 같이 입력하시면 됩니다.

geyser |>
  ggplot(aes(x = wait)) +
  geom_histogram(binwidth = 5, color = "white")

대기 시간 변수는 봉우리가 두 개인 이봉형(Bimodal)이고 대칭이며 70을 중심으로 분포하는 것으로 보입니다. 산점도와 마찬가지로 히스토그램에도 히스토그램의 모양이나 가독성에 영향을 줄 수 있는 여러 옵션이 있습니다.

  • bins, binwidth: 막대의 개수 또는 막대 하나의 폭을 지정합니다. 두 옵션 중 하나만 명시하면 충분합니다.
  • labs(x = ..., y = ..., title = ...): x축, y축, 제목을 지정합니다.
  • fill, color: 각각 막대 내부 색상과 테두리 색상을 지정합니다. 문자열("red")이나 HTML 16진수 코드("#8B1F41")를 사용할 수 있습니다.
  • coord_cartesian(xlim = ..., ylim = ...): x축과 y축의 표시 범위를 조정합니다.

이러한 히스토그램 옵션을 사용하여 기본 히스토그램을 다음 코드로 개선할 수 있으며, 그 결과는 동일한 그림의 오른쪽 히스토그램과 같습니다.

geyser |>
  ggplot(aes(x = wait)) +
  geom_histogram(bins = 20, color = "white") +
  labs(
    x = "Wait Time",
    y = "Count",
    title = "Histogram of Time Between Eruptions"
  )

상자 그림

상자 그림을 사용할 때, 단일 변수에 대한 상자 그림을 만들거나 범주형 예측 변수(Predictor)와 양적 반응 변수(Response) 사이의 연관성을 탐색하는 병렬 상자 그림(Side-by-side boxplot)을 만들 수 있습니다. 이 두 가지 목표는 ggplot2::geom_boxplot()으로 모두 달성할 수 있습니다. 단일 변수에 대한 상자 그림을 생성하는 기본 코드는 다음과 같습니다.

ggplot(data, aes(y = variable)) +
  geom_boxplot()

예를 들어, R의 MASS 패키지에 있는 birthwt 데이터셋을 살펴볼 수 있습니다. 이 데이터셋은 신생아의 저체중을 나타낼 수 있는 몇 가지 가능한 지표를 살펴보고 있습니다. 이 피험자들의 출생 체중(birthwt 데이터 프레임의 bwt 변수)만 보고 싶다면 코드는 다음과 같습니다.

birthwt |>
  ggplot(aes(y = bwt)) +
  geom_boxplot()

이전 도표들과 마찬가지로 상자 그림에도 도표를 개선할 수 있는 여러 옵션이 있습니다.

  • outlier.shape: 이상점(Outlier)의 점 모양을 지정합니다.
  • labs(x = ..., y = ..., title = ...): x축, y축, 제목을 지정합니다.
  • coord_cartesian(xlim = ..., ylim = ...): x축과 y축의 표시 범위를 조정합니다.
  • fill, color: 상자 내부 색상과 테두리 색상을 지정합니다.

이러한 옵션을 사용하여 다음 코드로 기본 히스토그램을 수정할 수 있습니다. 결과는 동일한 그림의 오른쪽 상자 그림이 될 것입니다.

birthwt |>
  ggplot(aes(y = bwt)) +
  geom_boxplot(outlier.shape = 16) +
  labs(y = "Birth Weight")

양적 반응 변수와 범주형 예측 변수 사이의 관계를 평가하기 위해, x축에 범주형 예측 변수를 추가합니다.

ggplot(data, aes(x = predictor, y = response)) +
  geom_boxplot()

여기서 “Response”는 반응 변수이고 “Predictor”는 예측 변수입니다. 예를 들어, 어머니의 흡연 여부(birthwt 데이터 프레임의 smoke 변수)가 자녀의 출생 체중에 미치는 영향을 살펴보고 싶다면 코드는 다음과 같습니다.

birthwt |>
  ggplot(aes(x = factor(smoke), y = bwt)) +
  geom_boxplot()

상자 그림의 기본 코드는 단일 변수 상자 그림과 동일한 옵션으로 수정할 수 있습니다. 또한 범주의 표시 이름을 바꾸고 싶다면 원자료의 값을 먼저 의미 있는 팩터(factor)로 변환하는 편이 좋습니다. 이름을 도표 함수 안에서 임시로 바꾸기보다, 분석 데이터에 smoke_status처럼 해석 가능한 변수를 남겨 두면 이후 표와 그래프에서 같은 이름을 재사용할 수 있습니다.

이러한 옵션을 사용하여 기본 상자 그림을 수정할 수 있으며, 그 결과는 동일한 그림의 오른쪽 상자 그림과 같습니다. names 인수에 입력한 “Nonsmoker”와 “Smoker”라는 값이 smoke 변수의 0과 1 값에 해당하도록 순서를 맞추었음에 유의해 주세요.

birthwt |>
  mutate(smoke_status = factor(smoke, labels = c("Nonsmoker", "Smoker"))) |>
  ggplot(aes(x = smoke_status, y = bwt)) +
  geom_boxplot(outlier.shape = 16) +
  labs(
    x = "Mother's Smoking Status",
    y = "Birth Weight"
  )

tidyverse로 EDA 파이프라인 구성하기

앞에서 소개한 table(), mean(), hist(), boxplot()은 R의 기본 원리를 이해하는 데 좋습니다. 실제 프로젝트에서는 같은 분석을 데이터 불러오기, 전처리, 요약, 시각화가 이어지는 파이프라인으로 작성하면 더 읽기 쉽습니다. 예를 들어 quine 데이터셋의 인종과 학습 수준 분할표는 다음처럼 만들 수 있습니다.

library(tidyverse)
library(MASS)

quine |>
  count(Eth, Lrn) |>
  group_by(Eth) |>
  mutate(prop_within_eth = n / sum(n)) |>
  ungroup()

수치형 변수의 요약도 summarise()와 .by를 사용하면 집단 기준을 코드 안에서 직접 드러낼 수 있습니다. dplyr 1.1 이상에서는 .by를 사용할 수 있으므로, 한 번의 요약을 위해 별도의 group_by()와 ungroup()을 길게 유지하지 않아도 됩니다.

Housing |>
  summarise(
    mean_price = mean(price, na.rm = TRUE),
    median_price = median(price, na.rm = TRUE),
    iqr_price = IQR(price, na.rm = TRUE),
    .by = prefarea
  )

그래프는 ggplot2를 사용하면 산점도, 히스토그램, 상자 그림을 같은 문법으로 연결할 수 있습니다.

cars |>
  ggplot(aes(x = speed, y = dist)) +
  geom_point() +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    x = "속도",
    y = "정지 거리",
    title = "속도와 정지 거리의 관계"
  )

이 파이프라인은 계산 결과를 바꾸기 위한 장식이 아닙니다. 표본을 어떤 기준으로 나누었는지, 결측값을 어떻게 처리했는지, 어떤 변수로 그래프를 만들었는지를 코드가 그대로 설명하게 만드는 방식입니다.

결론

이번 장에서 배운 탐색적 분석을 통해 우리는 데이터를 이해하고 시각화하는 데 도움이 되는 많은 도구를 갖추게 되었습니다. 이것들이 통계학이나 R에서 사용할 수 있는 유일한 옵션은 아니지만, 일반적인 것들을 나타냅니다. 다음에 다시 R로 돌아올 때는 통계적 추론(Statistical inference) 도구들을 갖추게 될 것이며, 따라서 이러한 기법들을 R에서 구현하는 데 집중하게 될 것입니다.
