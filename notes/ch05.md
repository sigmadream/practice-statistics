## 서론

데이터를 수집하고 나면, 통계 프로세스의 다음 단계는 탐색적 데이터 분석(exploratory data analyses)을 통해 데이터를 분석하기 시작하는 것입니다. 대규모 데이터셋은 수작업으로 계산하는 것이 불가능하지는 않더라도 지루하기 때문에, 수작업으로 데이터를 분석할 수 있는 경우는 거의 없습니다. 따라서 프로그램의 함수와 컴퓨팅 능력을 활용하기 위해 데이터를 R로 불러올 수 있어야 합니다. 이 장에서는 분석을 더 쉽게 만드는 데 도움이 되는 특정 함수와 데이터를 보관하는 R의 라이브러리(library)—와, 라이브러리 또는 csv 파일에서 R로 데이터를 불러오는 방법에 초점을 맞추겠습니다.

## R의 라이브러리

R은 전적으로 오픈 소스 소프트웨어이기 때문에, 누구나 분석을 더 쉽게 할 수 있도록 사용자 정의 함수 패키지를 만들 수 있습니다. 이러한 패키지를 라이브러리라고 하며 대부분 CRAN에 저장됩니다. 이러한 라이브러리는 R에서 다운로드하여 설치할 수 있으며 언제든지 호출하여 사용할 수 있습니다.

라이브러리를 설치하는 첫 번째 단계는 라이브러리를 다운로드하고 설치하는 것이며, 구체적으로 MASS 패키지를 R에 설치하는 과정을 통해 이를 시연합니다. 이 다운로드 및 설치 과정은 윈도우(Windows) PC와 맥(Mac)에서 다르므로(맥의 과정이 훨씬 더 쉽습니다), 여기서는 윈도우 PC부터 시작하여 두 과정을 모두 자세히 설명할 것입니다.

예전에는 운영 체제 메뉴에서 패키지를 설치하는 절차를 길게 따라가는 방식이 흔했습니다. R 4.6 수업 노트에서는 같은 분석 환경을 다시 만들 수 있도록 패키지 설치와 로드를 코드로 남기는 방식을 우선합니다. 윈도우에서 시스템 라이브러리에 설치 권한이 없을 때만 관리자 권한 실행이 필요할 수 있으며, 보통은 사용자 라이브러리에 설치하면 충분합니다.

그 후 R이 열리면 상단 메뉴의 "Packages" 탭을 클릭하고 드롭다운 메뉴에서 "Install Packages"를 선택합니다.

그 다음으로 CRAN 미러(mirror)를 선택해야 합니다. 기본적으로 이것은 지속적으로 업데이트되는 CRAN의 어떤 저장된 버전을 사용할지 정의하는 것입니다. CRAN 미러 선택은 대개 패키지 설치에 아무런 영향을 미치지 않습니다.

이 작업이 끝나면 R에서 사용할 수 있는 라이브러리의 전체 알파벳순 목록이 표시됩니다. 아래로 스크롤하여 MASS를 선택하고 확인(okay)을 클릭합니다. 패키지가 설치되며 사용자가 필요할 때마다 호출할 수 있습니다.

라이브러리—와 그 함수 및 데이터셋—를 호출하여 R에서 사용하려면 `library` 명령을 사용합니다. 이에 대한 코드는 다음과 같습니다.

```r
library(package_name)
```

그런 다음 `Enter` 키를 누릅니다. 코드에 오류가 없는 한 R은 빈 줄만 표시하며, 그 후 라이브러리에 저장된 모든 함수나 데이터셋을 사용할 수 있습니다. 따라서 MASS 라이브러리의 함수를 호출하려면 다음과 같이 MASS 라이브러리를 로드합니다.

```r
library(MASS)
```

맥(Mac) 운영 체제의 경우 과정이 더 간단합니다. 시작하려면 R 애플리케이션을 일반적인 방식으로 열고 상단의 Packages & Data 탭을 클릭합니다. 드롭다운 메뉴에서 Package Installer를 선택합니다.

검색창에 패키지 이름(이 경우 MASS)을 입력하고 Get List를 클릭합니다. 그러면 검색한 문자열이 포함된 이름을 가진 모든 패키지가 반환됩니다. 설치하려는 패키지를 클릭하고 Install Selected를 클릭하기 전에 Install Dependencies 상자를 체크합니다. 일부 R 라이브러리는 작동을 위해 다른 라이브러리에 의존하므로, 이 마지막 단계를 통해 다른 모든 의존 패키지도 함께 설치되도록 보장합니다.

이 시점부터 절차는 위에서 나열한 윈도우의 경우와 동일합니다. 라이브러리—와 그 함수 및 데이터셋—를 호출하여 R에서 사용하려면 `library` 명령을 사용합니다. 이에 대한 코드는 다음과 같습니다.

```r
library(package_name)
```

그런 다음 `Enter` 키를 누릅니다. 코드에 오류가 없는 한 R은 빈 줄만 표시하며, 그 후 라이브러리에 저장된 모든 함수나 데이터셋을 사용할 수 있습니다. 따라서 MASS 라이브러리의 함수를 호출하려면 다음과 같이 사용합니다.

```r
library(MASS)
```

## 라이브러리에 저장된 데이터셋 불러오기

라이브러리에는 분석을 위한 다양한 함수와 데이터셋이 들어 있습니다. 데이터셋의 이름만 알면 이러한 데이터셋을 R 작업 공간(workspace)으로 불러오는 것은 간단합니다. R의 `data` 함수는 다음 코드를 사용하여 데이터셋을 작업 공간으로 호출합니다.

```r
data(dataset_name, package = "package_name")
```

그런 다음 `Enter` 키를 누릅니다. 예로 MASS 라이브러리의 nlschools 데이터셋을 살펴보겠습니다. 이 데이터셋은 네덜란드의 중학교 2학년 학생 2,000명 이상의 시험 점수입니다. 이를 불러오기 위해 다음 코드를 사용합니다.

```r
data(nlschools, package = "MASS")
```

그런 다음 `Enter` 키를 누릅니다. 이제 작업 공간에는 분석에 사용할 수 있는 nlschools라는 이름의 데이터 프레임이 존재합니다.

## csv 파일을 R로 불러오기

라이브러리에 저장된 데이터셋 외에도 csv 파일에 저장된 데이터셋을 R로 불러올 수도 있습니다. 기본 R의 `read.csv()`도 사용할 수 있지만, 이 장의 R 4.6 실습에서는 열 유형을 더 명확히 확인할 수 있는 `readr::read_csv()`를 기본 예시로 사용하겠습니다. 이 함수는 다음 코드처럼 실행합니다.

```r
readr::read_csv("data/file_name.csv", show_col_types = FALSE)
```

파일 위치(file location)는 때때로 찾기 어려울 수 있으며, 위치를 알고 있더라도 함수에 파일 경로(file pathway)를 입력할 때 실수할 가능성이 있습니다. 초기 학습 단계에서는 `file.choose()`로 파일을 직접 고를 수도 있지만, 재현 가능한 수업 노트에서는 프로젝트 내부의 상대 경로를 명시하는 편이 좋습니다. 코드는 다음과 같을 수 있습니다.

```r
my_data <- readr::read_csv("data/my_data.csv", show_col_types = FALSE)
```

이 방식은 어떤 파일을 읽었는지가 코드에 남습니다. 불러온 데이터 프레임은 반드시 `my_data`처럼 의미 있는 이름의 객체로 저장해 주십시오. 그렇지 않으면 파일 내용이 화면에 출력되더라도 이후 분석 단계에서 재사용하기 어렵습니다.

## 패키지와 데이터 불러오기의 현대적 기준

R 4.6을 기준으로 하면 패키지 설치는 가능하면 코드로 남기는 편이 좋습니다. 메뉴를 눌러 설치하는 방식은 처음 학습할 때 직관적이지만, 나중에 같은 분석 환경을 다시 만들기 어렵습니다. 따라서 수업 자료나 분석 노트에는 다음처럼 필요한 패키지를 명시해 두는 습관을 권합니다.

```r
install.packages(c("tidyverse", "MASS"))
library(tidyverse)
library(MASS)
```

CSV 파일을 불러올 때도 기본 R의 `read.csv()`는 여전히 사용할 수 있지만, tidyverse 환경에서는 `readr::read_csv()`를 기본 선택지로 삼을 수 있습니다. `read_csv()`는 열 유형을 더 일관되게 추정하고, 결과를 tibble로 반환하며, 큰 파일을 다룰 때도 편리합니다.

```r
students <- readr::read_csv(
  file = "data/students.csv",
  show_col_types = FALSE
)

students |>
  glimpse()
```

`file.choose()`는 개인 컴퓨터에서 빠르게 파일을 고를 때 유용하지만, 재현 가능한 분석에는 적합하지 않습니다. 다른 사람이 같은 코드를 실행할 때 어떤 파일을 골랐는지 알 수 없기 때문입니다. 따라서 교재의 예제와 과제에서는 프로젝트 폴더 안에 `data/` 같은 하위 폴더를 만들고, 상대 경로를 사용해 파일을 불러오는 방식을 우선합니다.

```r
nlschools_tbl <- MASS::nlschools |>
  as_tibble()

nlschools_tbl |>
  select(lang, IQ, class) |>
  slice_head(n = 5)
```

이 방식은 패키지 데이터셋과 외부 파일을 같은 원칙으로 다루게 해 줍니다. 데이터가 어디서 왔는지, 어떤 객체 이름으로 저장되었는지, 처음 확인한 구조가 무엇인지가 코드에 남기 때문에 이후의 탐색적 분석과 추론이 더 안전해집니다.

## 결론

지금까지 R에서 작업하고자 하는 모든 데이터는 우리 자신이 직접 입력해야 했습니다. 이는 데이터셋이 커질수록 지루한 과정이 될 것입니다. 라이브러리와 read.csv 함수의 사용을 통해 우리는 데이터셋을 R 작업 공간으로 쉽게 불러올 수 있습니다. 덧붙여 말하자면 R은 작업할 수 있는 데이터의 형태가 유연합니다. 적절한 함수와 지식이 있다면 R은 PDF 파일, 텍스트 파일, 웹 페이지에서 데이터를 가져올 수 있습니다.

이제 R로 데이터를 불러오고 데이터를 그룹으로 하위 집합(subset)화하는 방법을 알았으므로, 사람들이 이 주제를 논의할 때 떠올리는 통계 부분인 데이터 분석으로 넘어갈 수 있습니다. R에서 그렇게 하면 다양한 함수와 그래프를 활용할 수 있게 되어, 우리의 데이터를 이해하기 쉬운 용어로 더 잘 표현할 수 있게 될 것입니다.
