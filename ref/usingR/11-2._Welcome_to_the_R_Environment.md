## Abstract

This chapter introduces readers to setting up R for statistical analysis, beginning with downloading and installing R base, the core engine for R, and RStudio, a versatile user interface that simplifies statistical analyses and programming tasks. The chapter then guides readers in creating an RMarkdown file to organize and save code for practice exercises throughout the book. Additionally, it provides an overview of R’s Packages and Libraries, essential tools for extending R’s functionality, and concludes by highlighting one of R’s most valuable resources: the supportive community of users who share knowledge and assist with troubleshooting. This chapter equips readers with the foundational tools and understanding needed to begin applying R for statistical tasks efficiently.

1. 1.

2. 2.  
**Synchronization**: Mirrors are regularly updated to reflect the latest versions from the main CRAN repository.
3. 3.  
**Reliability**: If one mirror is temporarily unavailable, R can automatically switch to another, ensuring uninterrupted access.

## 2.2 Downloading RStudio Desktop

You need to download Base R before downloading and installing RStudio desktop because RStudio is an Integrated Development Environment (IDE) for R, it does not include R itself. RStudio is a “helper” application that provides a user-friendly interface for coding in R, but it relies on the underlying R software to perform computations and run scripts. RStudio is dependent on Base R to do all the actual “work” behind the scenes. When you install RStudio, it automatically detects the Base R installation on your system. If Base R is not installed, RStudio will not function and may prompt you to install R first.

Once you download base R, download RStudio to provide you with a very powerful user interface and programming tool that allows you to save your code, program dashboards, generate presentations, and a host of other features. ## 2.4 RMarkdown

RMarkdown (Allaire et al., [2020](A668427_1_En_2_Chapter)) is a feature of RStudio that allows users to produce outputs utilizing text, programming language, and output. Its main feature is the ability to code in chunks. Code chunks enable you to divide a coding project into logical, manageable sections and run each section separately. Later, we will get into chunking. RMarkdown also allows for dynamic output of the code beneath the chunk, which automatically includes the results of only what was coded in the chunk below it. RMarkdown also comes with a syntax that allows you to publish reports and code in various formats such as HTML, PDF, .doc, and even as presentations. For this book, we will stick with using RMarkdown for programming. Thus, RMarkdown is perfect for data science and statistical workflows as it allows the user to combine data analysis and reporting. For example, you will notice that many of the supplementary materials for this book are published on RPubs and were programmed on RMarkdown.

This book does not go over publishing RMarkdown documents, but you can refer to its documentation to learn how to do so (Allaire et al., [2020](A668427_1_En_2_Chapter)). You can also program emphases, lists, links, images, and block quotes. None of these are necessary for this book, but for more information you can find documentation with a Google search. The most important feature of RMarkdown includes “chunks.” Chunks are where you code statistics, plots, tables, and other outputs you want for your research. Chunks are useful because you can divide your code into sections that make sense to you. For example, if you want a section on descriptive statistics, you may chunk that and then have a chunk for t-test. A code chunk starts with triple backticks “\`\`\`” (this is the key on many keyboards below the escape key and to the left of the “1” key). The backticks are followed by an opening curly bracket “{“, followed by the language you want to use (e.g. R, python, etc.), followed by a name you want to give the chunk, followed by some commands, then a closing bracket “}”. The coding example below tells RMarkdown to run R programming language, call it “libraries” (for the next section), to not include messages (message = FALSE) or warnings (warning = FALSE) in the published output, but to include the code (echo = TRUE). Below that, we program our code and close the chunk with three more triple backticks. You can then run each chunk separately by clicking on the arrow in the upper right corner of the chunk: ![A dark interface with a gear icon on the left and a green play button on the right, indicating settings and play functions.](./images/668427_1_En_2_Figa_HTML.gif)

## 2.5 About Libraries and Packages

To run statistical analyses and other processes in R, we need to load libraries and packages. In R, a package is a collection of functions, data, and documentation bundled that process the commands you give R. When you download R, you already have several bundles by default. However, other functions such as sharp plots and graphs require separate packages.

A library is simply an installed package that you must “call” before programming the functions that library does. For example, there is a package called _ggplot2_ (Kassambara, [2023a](A668427_1_En_2_Chapter)). This package allows you to produce sharp-looking graphs and plots. To use its functions in your code, you must install it. When you install a package, R stores it in your default hard drive. We typically install packages like this in the R console:

 _install.packages(‘ggplot2’)._

Note that we put the name of the package in a single quote. (Double quotes also work.) Here R connects to the CRAN mirror you selected and downloads the package to your directory. Once installed, you now need to call the library from the package installed on your computer. You do this by typing something like:

 _library(ggplot2)._

Notice that you did not put it in quotes to load the package’s library. You can call your library right in your RMarkdown file. Figure [2.12](A668427_1_En_2_Chapter) shows how to install all the packages in the console. Figure [2.13](A668427_1_En_2_Chapter) shows how I typically load the libraries in RMarkdown. If you get an error that says something like “no package called \_\_\_\_\_ exists,” then check your spelling or make sure you installed it correctly. Once you run the chunk, output will appear below the code in white (if you have a black background) as shown in Fig. [2.13](A668427_1_En_2_Chapter). Some packages come with other packages within them, and this output will list them. The first bit of code shows how to install all the packages elegantly in the console. It names something “packages” and lists them. Then it installs them in one go. Notice the nuances of the code. For example the “c” before the list of packages, or how they are separated by commas in the parenthetical expression (Augie, [2017](A668427_1_En_2_Chapter); Bates, [2014](A668427_1_En_2_Chapter); Dinno, [2024](A668427_1_En_2_Chapter); Ianne & Roy, [2024](A668427_1_En_2_Chapter); Kassambara, [2023b](A668427_1_En_2_Chapter); Kleiber & Zeileis, [2008](A668427_1_En_2_Chapter); Lawrence, [2016](A668427_1_En_2_Chapter); Meyer et al., [2006](A668427_1_En_2_Chapter); Ooms, [2025](A668427_1_En_2_Chapter); Pdersen, [2025](A668427_1_En_2_Chapter); Pinheiro et al., [2000](A668427_1_En_2_Chapter); Pruim et al., [2023](A668427_1_En_2_Chapter); R Core Team, [2020](A668427_1_En_2_Chapter); Revelle, [2020](A668427_1_En_2_Chapter); Robinson et al., [2024](A668427_1_En_2_Chapter); Sanford Weisberg, [2019](A668427_1_En_2_Chapter); Stanley, [2010](A668427_1_En_2_Chapter); Torchiano, [2020](A668427_1_En_2_Chapter); Venables, [2021](A668427_1_En_2_Chapter); Venables & Ripley, [2002](A668427_1_En_2_Chapter); Wickham, [2016](A668427_1_En_2_Chapter), [2023](A668427_1_En_2_Chapter); Wickham et al., [2021](A668427_1_En_2_Chapter), [2025](A668427_1_En_2_Chapter)).

## 2.6 The R Community

At the time I am writing this book, R language is about 31 years old and was developed by Ross Ihaka and Robert Gentleman at the university of Aukland (Ihaka, [n.d.](A668427_1_En_2_Chapter)). Since its initial development, it has grown to become one of the most vibrant and supportive communities in programming and data science. Unlike many other statistical tools, R is open source and free (though some advanced options are offered for fees). As a result, over the past three decades developers have created thousands of packages for various project goals such as statistics, data science, web scraping, user interface (UI) dashboards, data munging and management, and others (_R: The R Project for Statistical Computing_, [2025](A668427_1_En_2_Chapter)). Developers and users continually create tutorials and answer questions about programming puzzles and problems on communities such as the Posit Community, Stack Overflow, GitHub, R-Bloggers, R-Help Mailing List, Kaggle Discussions and Reddit:r/Rlanguage (_GitHub · Build and Ship Software on a Single, Collaborative Platform_, [2025](A668427_1_En_2_Chapter); _Machine Learning and Data Science Forum Discussions | Kaggle_, [n.d.](A668427_1_En_2_Chapter); _Posit Community_, [n.d.](A668427_1_En_2_Chapter); _R Programming Language_, [n.d.](A668427_1_En_2_Chapter); _R-Bloggers_, [n.d.](A668427_1_En_2_Chapter); _R-Help Info Page_, [2025](A668427_1_En_2_Chapter); _Stack Overflow—Where Developers Learn, Share, and Build Careers_, [n.d.](A668427_1_En_2_Chapter)).

I have personally benefitted from R-Bloggers, GitHub, Stack Overflow and RStudio Community by simply Google searching my problem and reading Q&A posts that solve similar issues that other users are having. I have also posted questions and got satisfactory answers. Many sites ask for reproducible examples so that the community can run and test the code. There are also tutorials on YouTube that I have found useful just by searching the topic and browsing the various videos that have been posted until one fits my needs.

R has an underlying ethic and philosophy of education and accessibility. Many courses online are free. There are open-source resources available online as well. R also hosts events and conferences. These often require registration and travel expenses. As a member of the R community, you join a network of willing and helpful R users.
