## 4.3 Calculating Descriptive Statistics by Category Using R

The last section covered how to generate overall descriptive statistics. However, it is often desirable to calculate descriptive statistics by category. In our CPS85 dataset, there is a nominal variable called “sector.” This variable provides information about the employment sector of everyone in the sample. This is a nominal, or categorical variable. (The method in this section is also acceptable for ordinal variables). Here, we want to calculate the descriptive statistics in the _psych_ package (e.g., mean, standard deviation, median, etc.), for each of the sectors. First, I am curious as to what sectors are present in the database. So, in my console, I am going to type the following and then hit “enter.”

 unique(CPS85$sector)

The result is a list of each of the sectors in the console beneath our code.

 \[1\] const sales clerical service manuf prof other manag

 Levels: clerical const manag manuf other prof sales service

If I wanted to know how many sectors there were I would type the following code in the console.

 n\_distinct(CPS85$sector)

The result is 8 different categories. Spelled out these include: (a) Construction, (b) Sales, (c) Clerical Service, (d) Manufacturing, (e) Professional, (f) management, and (g) Other. Therefore, the objective is to program a chunk in R that will provide us will the descriptive statistics in each category.

Figure [4.3](A668427_1_En_4_Chapter) gives the code chunk in RMarkdown, and Fig. [4.4](A668427_1_En_4_Chapter) provides the results. Below this paragraph, after explaining the code, I also type it out. The code below shows how to calculate and display descriptive statistics for the variable wage grouped by the categorical variable sector in the dataset CPS85\. It uses the **describeBy** function from the _psych_ package, which generates detailed descriptive summaries, such as the mean, standard deviation, median, skewness, and kurtosis for each level of the grouping variable. By specifying **mat = TRUE**, the function returns the output as a matrix, allowing for a seamless conversion to a data frame using the **as.data.frame** function. This ensures the results are in a tidy, tabular format that can be easily manipulated or incorporated into subsequent analyses and visualizations. Notice that we named our descriptives by category as “descriptives\_sector.” We can now write the data into a spreadsheet such as Excel and copy and paste it into tables for our research papers. We do that with the **write.csv** command. This will result in a comma separated values (CSV) file called “descriptives\_sector.csv” waiting for us in the same folder as our RMarkdown file.

 \# Get descriptive statistics by sector

 descriptives\_sector <- psych::describeBy(CPS85$wage, group = CPS85$sector, mat = TRUE)

 \# Convert the matrix into a data frame

 descriptives\_sector<- as.data.frame(descriptives\_sector)

 write.csv(descriptives\_sector, "descriptives\_sector.csv")

The following code creates a plot for the overall wage distribution using the _CPS85_ dataset. The _ggplot_ function is used first, followed by the dataset (_CPS85_) and the specification of the variable to be plotted (wage) using aes(x = wage). This sets the x-axis to represent the wage data. The line then ends with a closing parenthesis) and a + to indicate more commands will follow. The second line uses _geom\_histogram_() to create a histogram, specifying the y-axis to represent density (aes(y = ..density..)) instead of raw counts. It also defines the bin width (binwidth = 1), the color of the bars (color = “black”), the fill color of the bars (fill = “skyblue”), and the transparency level (alpha = 0.7). The third line adds a density curve to the plot using geom\_density(), with the curve’s color and fill set to red (color = “red”, fill = “red”) and the transparency (alpha = 0.3) making the curve semi-transparent.  ggplot(CPS85, aes(x = wage)) +

 geom\_histogram(aes(y = ..density..), binwidth = 1, fill = "skyblue",

 color = "black", alpha = 0.7) +

 geom\_density(color = "red", fill = "red", alpha = 0.3) +

 theme\_minimal() +

 labs(title = "Overall Wage Distribution", x = "Wage", y = "Density")

Most of what we observe is explained in the descriptive statistics. However, we can also observe some nuance from these plots. First, we can see that the highest wage comes from the management sector. We could see this on the descriptive statistics table by sector, but this visualizes how different those wages are than the rest of the wages. We also see differently shaped curves by sector. For example, the construction distribution is the most normally distributed sector while management is normally distributed but platykurtic with some outliers.

Many statistical tests require the researcher to examine normality overall and at “every level” of the dependent variable. In this case, if we wanted to know if there was a difference in wage by sector, we would run descriptives and histograms overall and by sector. The histograms would allow us to visually check and the descriptive statistics would give us precise numbers to help us better understand our overlying data and make decisions on what tests to run. This is because normal distributions are a common statistical assumption, meaning that the statistical test is not as accurate if distributions are not normal.

What happens if my dependent variable is not normally distributed? Great question! When the dependent variable does not follow a normal distribution, parametric tests (or tests assume that the data follows a specific, known pattern) may not give accurate results. In these cases, we can use non-parametric tests, which do not rely on the assumption that the data is normal. Non-parametric tests (or tests that do not assume anything about the data’s shape or distribution, so they can be used in a wider range of situations) such as the Mann-Whitney U test or the Kruskal-Wallis test (which is a non-parametric alternative to ANOVA), can be used when the data is skewed, has outliers, or is not normally distributed. These tests are more flexible but may be less powerful when data meets the assumptions of parametric tests. We will get into ways to transform data or run other tests later in the book. For now, we need to explore ways to calculate frequencies and percentages by category to complete this chapter.

## 4.5 Calculating Frequencies and Proportions on R

When variables are categorical, it is often useful to determine the number of observations within each category. For example, to find out how many individuals are married in the _CPS85_ dataset, you could use the following R code:

 table(CPS85$married)

If we wanted to know how many people are married by union status, we could type it with the following code:

 table(CPS85$married, CPS85$union)

However, it is often desirable to know the proportion and not just the count. To calculate the proportion of people who are married we would type the following code:

 prop.table(table(CPS85$married))

If we wanted to know the proportion of people who are married by union status, we would type the following code:

 prop.table((table(CPS85$married, CPS85$union)))

It is often useful to have all this information in one table. The following code, which uses the _tidyverse_ package (Wickham et al., [2019](A668427_1_En_4_Chapter)), helps us achieve this. While it may seem complex, the code is reusable and can be applied to other variables. It starts with creating a contingency table of counts and converting it into a tidy data frame with renamed columns for clarity. Proportions are then calculated within each union category by dividing the counts by the total for that category. Additionally, a summary row is generated for each marital status, aggregating counts and proportions across all union categories and labeled as ‘Total.’ The final table combines the detailed data and summary rows, offering an easy-to-read summary of counts and proportions by marital and union status.

 count\_table <- table(CPS85$married, CPS85$union)

 df\_count <- as.data.frame(count\_table)

 df\_count <- df\_count %>%

 rename(Married = Var1, Union = Var2, Count = Freq)

 df\_count <- df\_count %>%

 group\_by(Union) %>%

 mutate(Proportion = Count / sum(Count))

 df\_total <- df\_count %>%

 group\_by(Married) %>%

 summarise(Count = sum(Count), Proportion = sum(Proportion)) %>%

 mutate(Union = "Total")

 final\_table <- bind\_rows(df\_count, df\_total)

Finally, it may be desirable to count on all the categorical variables in your data set. In this case, we have race, sex, Hispanic, south, married, union, and sector. The following code first generates a new dataset to only include those variables and then generates a table with frequencies for each category The code begins by selecting the relevant variables and reshaping the data into a long format, where each row represents a variable and its corresponding category. It then groups the data by variable and category and calculates the frequency of each category within its respective variable. Finally, the results are arranged by variable and descending frequency for clarity. As shown in Table [4.2](A668427_1_En_4_Chapter) in the example write-up, the output is a clean, organized table with four columns: the variable name, the category within that variable, the frequency of occurrences for each category, and the proportion. This approach allows for a concise summary of categorical data across multiple variables in a single table.

 frequency\_table <- CPS85 %>%

 dplyr::select(race, sex, hispanic, south, married, union, sector) %>%

 pivot\_longer(cols = everything(), names\_to = "Variable", values\_to = "Category") %>%

 group\_by(Variable, Category) %>%

 summarise(Frequency = n(), .groups = "drop") %>%

 group\_by(Variable) %>%

 mutate(Proportion = Frequency / sum(Frequency)) %>%

 arrange(Variable, desc(Frequency))

We can use this table to generate a plot of proportion by category. Figure [4.7](A668427_1_En_4_Chapter) shows the results of this code, which visualizes both the frequency and proportion of categories across multiple variables in the CPS85 dataset. It first calculates the frequency and proportion for each category within each variable, ensuring that proportions sum to 1 per variable. The plot uses bar charts (geom\_bar) to display frequencies, while text labels (geom\_text) show the proportions as percentages above each bar for clarity. The visualization is faceted (facet\_wrap) so that each variable has its own subplot, with free scales to accommodate differing ranges of frequencies. The plot is styled with a minimal theme (theme\_minimal) and angled x-axis labels for readability, making it an effective tool for summarizing categorical data with both absolute and relative insights.

 ggplot(frequency\_table, aes(x = Category, y = Frequency, fill = Category)) +

 geom\_bar(stat = "identity", show.legend = FALSE) +

 geom\_text(

 aes(label = scales::percent(Proportion, accuracy = 0.1)),

 position = position\_stack(vjust = 0.5),

 size = 3, color = "black"

 ) +

 facet\_wrap(\~Variable, scales = "free", ncol = 2) +

 theme\_minimal() +

 theme(

 axis.text.x = element\_text(angle = 45, hjust = 1),

 strip.text = element\_text(size = 10, face = "bold")

 ) +

 labs(

 title = "Frequency and Proportion of Categories by Variable",

 x = "Category",

 y = "Frequency" )
