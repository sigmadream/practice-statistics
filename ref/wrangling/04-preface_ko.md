# 서문 (Preface)

데이터 과학(Data Science)은 광범위한 학문 분야입니다. 배울 것이 아주 많으며, 매일매일 더 많은 내용이 쌓이고 있습니다. 우리가 데이터를 분석하고 더 나은 결정을 내리기 위한 기반이 되는 인사이트를 추출하는 방식은 확실히 매력적입니다. 대기업들은 데이터가 비즈니스 성과를 다음 단계로 이끌어 줄 수 있다는 것을 깨달았고, 강력한 데이터 과학 팀을 구축하여 앞장서고 있습니다.

하지만 데이터 그 자체만으로는 해답이 될 수 없습니다. 데이터는 원유와 같습니다. 원유에서 많은 것을 만들어낼 수 있지만, 땅에서 갓 뽑아낸 검은 액체 자체는 우리에게 큰 도움이 되지 않습니다. 따라서 원시 데이터(Raw data)도 중요하지만, 이를 정제(clean), 변환(transform), 분석할 때 비로소 데이터를 정보로 탈바꿈시키게 되며, 이는 우리가 더 나은 결정을 내릴 수 있는 힘을 가져다줍니다.

이 책에서는 비즈니스를 위한 지식으로 데이터를 변환하는 방법을 배우는 데이터 랭글링(Data Wrangling)의 여러 측면을 살펴볼 것입니다. 우리가 선택한 프로그래밍 언어는 통계 프로그램으로 처음 만들어졌으나 그 이상으로 발전한 놀라운 소프트웨어인 R입니다. 우리가 성취하고자 하는 바를 알고 있다면, 목적지에 도달하는 것은 알맞은 도구를 찾는 문제일 뿐입니다. 그 도구들 중 많은 것들이 이 책에 담겨 있습니다.

# 이 책의 독자 대상

이 책은 RStudio와 함께 R 언어를 사용하여 데이터를 랭글링하는 역량을 습득하거나 향상시키고자 하는 학계 및 산업계의 전문가들을 위해 작성되었습니다. 변수 생성, 루프, 함수 등 R의 기본 프로그래밍 개념에 익숙하다고 가정합니다. 이 책은 IDE에 데이터 세트를 로드하는 것부터 시각화 및 모델링을 위한 준비에 이르기까지 데이터 랭글링의 완전한 흐름을 제공합니다. **과학(Science)**, **기술(Technology)**, **공학(Engineering)**, **수학(Math)**(**STEM**) 분야나 데이터 과학 분야의 배경지식이 필수는 아니지만, 지식을 내재화하고 콘텐츠를 최대한 활용하는 데 도움이 될 것입니다.

# 이 책에서 다루는 내용

[_5장_](B18355_05.xhtml#_idTextAnchor099), _숫자 다루기(Working with Numbers)_ 는 수치형 변수의 변환을 포함합니다. 이 장에서는 벡터, 행렬 및 데이터 프레임을 사용한 연산을 다루며, apply 계열 함수와 데이터 세트의 기술 통계(descriptive statistics)를 잘 읽어내는 방법도 다룹니다.

[_6장_](B18355_06.xhtml#_idTextAnchor114), _날짜 및 시간 객체 다루기(Working with Date and Time Objects)_ 에서는 날짜와 시간이라는 이 매력적인 객체 유형에 대해 더 자세히 알아봅니다. 날짜 및 시간 객체를 생성하는 기초적인 개념부터 시작하여 이것이 분석에 어떻게 사용될 수 있는지 보여주는 실용적인 프로젝트까지 소개합니다.

[_7장_](B18355_07.xhtml#_idTextAnchor126), _Base R을 사용한 변환(Transformations with Base R)_ 은 이 책의 핵심으로, 데이터 세트에서 수행해야 할 중요한 변환들을 탐구합니다. 이 장에서는 슬라이싱, 그룹화, 대체, 정렬, 데이터 결합 등의 작업을 다룹니다. 추가 라이브러리를 로드할 필요 없이 내장 함수를 주로 사용하여 많이 사용되는 변환들을 다룹니다.

[_8장_](B18355_08.xhtml#_idTextAnchor142), _tidyverse 라이브러리를 사용한 변환(Transformations with tidyverse Libraries)_ 은 [_7장_](B18355_07.xhtml#_idTextAnchor126)과 동일한 아이디어를 따르지만, 이번에는 데이터 과학에서 매우 많이 사용되는 R 패키지인 **tidyverse**를 사용하여 변환을 수행합니다.

[_9장_](B18355_09.xhtml#_idTextAnchor167), _탐색적 데이터 분석(Exploratory Data Analysis)_ 은 실전에 관한 내용입니다. 다양한 유형의 변수에 대한 많은 변환 함수를 살펴본 후, 습득한 지식을 실습에 적용하여 완전한 탐색적 데이터 분석 프로젝트를 수행해 볼 시간입니다.

\# RStudio에 라이브러리 설치하기 install.packages(“package_name”) \# 세션에 라이브러리 로드하기 library(package_name)

R에서는 다음 두 가지 코드 스니펫을 상기하거나 염두에 두면 유용할 수 있습니다. 첫 번째는 **for** 루프를 작성하는 방법입니다. 주어진 조건에 대해 해당 조건이 더 이상 충족되지 않을 때까지 코드 일부를 실행하도록 작성할 수 있습니다.

for (num in 1:5) { print(num) }

다른 하나는 R 언어로 작성된 함수의 뼈대(skeleton)로, 변수와 해당 변수로 수행할 작업의 코드를 제공하고 결과로 계산값을 반환합니다.

custom_sum_function \<- function(var1, var2) { # 함수 코드 my_sum = sum(var1 + var2) return(my_sum) }

이 책의 디지털 버전을 사용 중인 경우, 복사 및 붙여넣기로 인해 코드가 깨져 발생할 수 있는 잠재적인 오류를 방지하기 위해 코드를 직접 입력하거나 책의 GitHub 리포지토리에서 코드에 접근하는 것을 권장합니다.

이 책 전반에 걸쳐 여러 텍스트 표기 규칙이 사용되었습니다.

**텍스트 내 코드(Code in text)**: 텍스트 내의 코드 단어, 데이터베이스 테이블 이름, 폴더 이름, 파일 이름, 파일 확장자, 경로 이름, 더미 URL, 사용자 입력 및 Twitter 핸들을 나타냅니다. 다음은 그 예시입니다. "다운로드한 **WebStorm-10\*.dmg** 디스크 이미지 파일을 시스템의 다른 디스크로 마운트합니다."

코드 블록은 다음과 같이 설정됩니다.

html, body, \#map { height: 100%; margin: 0; padding: 0 }

코드 블록의 특정 부분에 주의를 환기시키고자 할 때 관련 줄이나 항목을 굵게 표시합니다.

\[default\] exten =\> s,1,Dial(Zap/1\|30) exten =\> s,2,Voicemail(u100) **exten =\> s,102,Voicemail(b100)** exten =\> i,1,Voicemail(s0)

모든 명령줄(command-line) 입력 또는 출력은 다음과 같이 작성됩니다.

\$ mkdir css \$ cd css

**굵게(Bold)**: 새로운 용어, 중요한 단어 또는 화면에 표시되는 단어를 나타냅니다. 예를 들어, 메뉴나 대화 상자에 있는 단어는 **굵게** 표시됩니다. 다음은 그 예시입니다. "**Administration** 패널에서 **System info**를 선택합니다."
