## [제4장 잔여 수명 분포와 생명표(Future Lifetime Distribution and Life Tables)](./08-Content.md#QQ2-1-47)

주요 용어 : 분석적 사망 법칙(Analytical laws of mortality), 발두치 가정(Balducci assumption), 일정한 사망력(Constant force of mortality), 단축 잔여 수명(Curtate future lifetime), 이연 확률(Deferred probabilities), 사망력(Force of mortality), 생명표(Life table), 선택 생명표(Select life table), 선택 기간(Select period), 사망 시점 확률변수(Time until death random variable), 최종 생명표(Ultimate life table), 단위 구간 내 사망의 균등 분포(Uniform distribution of deaths in a unit interval).

### [ 4.1 소개](./08-Content.md#QQ2-1-48)

제3장에서는 위험 회피 성향을 가진 개인이 사망으로 인한 재정적 위험을 보장받기 위해 보험 회사와 계약을 맺는 방법에 대해 살펴보았습니다. 사망 시점은 불확실하므로 1.6절에서 논의한 바와 같이 보험 기간 또한 확률변수입니다. 따라서 어떠한 보험 상품이든 혜택이 지급되는 시점과 보험 회사가 보험료를 받는 기간은 확률변수입니다. 연금 상품의 경우, 연금 수령자가 혜택을 받는 기간이 확률변수입니다. 이러한 모든 상품과 관련된 확률변수는 계약 체결 시점부터 보험금을 지급할 때까지의 시간인 잔여 수명(future lifetime) 확률변수입니다. 다음 절에서는 이 분포를 유도하는 방법에 대해 논의합니다.

### [ 4.2 잔여 수명 확률변수(Future Life Time Random Variable)](./08-Content.md#QQ2-1-49)

사망은 확실한 사건이지만, 개인이 사망할 연령은 예측할 수 없습니다. 따라서 개인의 수명은 확률변수로 모델링됩니다. 신생아의 사망 연령, 즉 개인의 수명을 나타내는 확률변수를 X라고 가정해 보겠습니다. 그러면 X는 연속 확률변수입니다. 수명이므로 X는 음수가 될 수 없으며, 따라서 X는 음수가 아닌 값을 갖는 확률변수입니다. 결과적으로 F가 이 확률변수의 분포 함수(distribution function)를 나타낸다면, x < 0에 대해 그 값은 0입니다. 생존 함수(survival function)를 S(x) = 1 – F(x)라고 가정해 보겠습니다. 이는 신생아가 연령 x에 도달할 확률, 즉 어린이가 최소한 x년 동안 생존할 확률을 지정합니다. 나아가 그의 수명이 연령 x와 z 사이일 확률, 즉 그 사람이 연령 x 이전에는 사망하지 않지만 연령 z 이전에는 사망할 확률은 다음과 같이 주어집니다.

![                                           ∫ z P[x ≤ X ≤ z] = F(z)- F (x ) = S(x)- S (z) =   x f(u) du ](./-act-book121x.png)

f는 X의 확률 밀도 함수(probability density function)입니다. 2.2절에서 분포 함수 F가 특정한 성질들을 만족한다는 것을 확인했습니다. 또한, 이러한 네 가지 성질을 만족하는 임의의 함수 F는 분포 함수가 됨을 증명할 수 있습니다. 마찬가지로 다음 네 가지 성질을 만족하는 임의의 함수 S는 음이 아닌 확률변수의 생존 함수입니다. (i) 0 ≤ S(x) ≤ 1, ∀ x ∈ℝ, (ii) S는 단조 감소(non-increasing) 함수입니다. (iii) S는 우연속(right continuous)이며 (iv) S(0) = 1 및 S(∞) = 0입니다.

다음 예제에서는 어떤 함수를 생존 함수로 부를 수 있는지 확인합니다.

예제 4.2.1\. 다음 중 x ≥ 0에 대한 생존 함수인 것은 무엇입니까?
(a) S(x) = exp(x – 0.7(2x – 1)), (b) S(x) = (1 + x)–2 및 (c) S(x) = exp(–x2).

풀이: (a) S(1) = exp{1 – 0.7(2 – 1)} \= exp(0.3) \> 1이므로 생존 함수로 사용될 수 없다는 점을 관찰합니다. (b) S(0) = 1, S(∞) = 0이며 S가 감소 함수라는 점을 관찰합니다. 또한, 다항식인 (1 + x)2는 연속이므로 S(x) = (1 + x)–2도 연속입니다. 따라서 S는 생존 함수로 사용할 수 있습니다. (c) 이 경우에도 S(0) = 1, S(∞) = 0이며 S는 감소 함수입니다. 또한, 지수 함수이므로 연속이고 따라서 우연속입니다. 따라서 함수가 생존 함수가 되기 위한 네 가지 요구 사항이 모두 만족됩니다. 따라서 이는 생존 함수입니다.

연속 확률변수의 분포는 분포 함수, 생존 함수 또는 확률 밀도 함수의 관점에서 지정될 수 있다고 알려져 있습니다. 보험수리학, 인구학 및 신뢰성 이론에서 자주 사용되는 또 다른 함수가 있는데, 이는 위의 세 가지 함수 모두와 일대일 대응 관계를 갖습니다. 이를 사망력(force of mortality)이라고 합니다. 이 개념에 대해 논의하고 다른 함수들과의 관계를 유도합니다. 연령 x에서의 사망력은 μx로 표시되며 다음과 같이 정의됩니다.

그림 [4.1](id1216)에서 우리는 사망력이 특정 연령까지는 다소 일정하며 60세 이후에는 급격히 증가함을 알 수 있습니다. 실생활에서 사망력은 출생 후 처음 몇 달간, 즉 1세까지 높습니다. 이 특징은 그림에 나타나 있지 않습니다.

보험수리학과 인구학에서 μx는 사망력(force of mortality)이라고 불립니다. 신뢰성 이론에서 μx는 고장률(failure rate) 또는 위험률(hazard rate) 또는 위험률 함수(hazard rate function)로 알려져 있습니다. μx는 본질적으로 개인이 연령 x까지 생존했을 때 연령 x에서 고장이나 사망이 발생하는 비율을 지정합니다. 사망력은 종종 사망 함수(mortality function) 또는 사망 법칙(mortality law)으로 언급되기도 합니다.

예제 4.2.3\. X가 매개변수 μ인 지수 분포를 따른다고 가정합니다. 사망력을 구하십시오.

풀이: 매개변수 μ인 지수 분포의 경우, 확률 밀도 함수는 f(x) = μe–μx, x > 0이고 그 외의 경우에는 0으로 주어집니다. 생존 함수는 x > 0에 대해 S(x) = e–μx로 주어집니다. 따라서, 사망력은 μ ∀ x > 0입니다. 이것이 x에 의존하지 않는다는 점에 유의합니다.

■

참고 4.2.1\. 모든 연속 분포들의 클래스 중에서, 지수 분포는 일정한 사망력을 갖는 유일한 분포이며, 이는 이 분포의 척도 매개변수(scale parameter)입니다. 지수 분포의 경우 10세에서의 사망력은 80세에서의 사망력과 같으며, 이는 인간 수명 확률변수의 경우 비현실적이라는 점에 유의합니다. 결과적으로 지수 분포는 인간 수명에 대한 좋은 모델이 아닙니다.

예제 4.2.4\. (0,100)에 대한 균등 분포의 경우, 사망력을 구하십시오.

풀이: (0,100)에 대한 균등 분포의 경우, 확률 밀도 함수는 f(x) = 1∕100, x ∈ (0,100)으로 주어지고 생존 함수는 다음과 같습니다.

![          (           {     1 ,    if    x < 0 S (x ) =   ( 1 - x ∕100 , if 0 ≤ x < 100                 0 ,    if   x ≥ 100 ](./images/act-book126x.png)

따라서 사망력은 0 ≤ x < 100에 대해 1∕(100 – x)입니다.

인간 수명을 모델링하는 데 흔하게 사용되는 확률 법칙은 (i) 드무아브르의 법칙(De-Moivre's law, 1729), (ii) 곰페르츠의 법칙(Gompertz's law, 1825), (iii) 메이컴의 법칙(Makeham's law, 1860) 및 와이블의 법칙(Weibull law, 1939)입니다. 인류에게 110세를 넘겨 사망한 사례는 거의 관찰되지 않았습니다. 사망은 확실한 사건이므로 연령에 상한이 있다고 가정하는 것이 합리적입니다. x < w에 대해 S(x) \> 0이고 x ≥ w에 대해 S(x) = 0이 되는 연령 w를 한계 연령(limiting age)이라고 합니다.

18세기 초반 인간 생명의 사망 경험을 대수적으로 기술하려는 최초의 시도 중 하나에서 에이브러햄 드무아브르(Abraham De-Moivre)는 인간의 수명을 (0,w) 구간의 균등 분포로 모델링할 수 있다고 제안했습니다. 이때 사망력은 μx \= (w –x)–1이고 생존 함수는 다음과 같습니다.
S(x) = 1 – x∕w, 0 ≤ x ≤ w, 여기서 w는 한계 연령입니다. 이 생존 함수의 형태를 사용하면,

![P [x ≤ X ≤ x +1] = S (x )- S(x+ 1) = 1∕w & P [x ≤ X ≤ x + 10] = 10∕w ](./-act-book127x.png)

단위 구간 (x,x \+ 1) 내의 사망 확률은 x에 의존하지 않는다는 점에 유의합니다. (0,100) 구간의 균등 분포의 경우,

![P [10 ≤ X ≤ 20] = P [80 ≤ X ≤ 90] = 1∕10 ](./-act-book128x.png)

따라서 인간의 수명이 (0,100)의 균등 분포로 모델링되는 경우 (10,20) 연령대에서의 사망 확률은 (80,90) 연령대에서의 사망 확률과 같습니다. 현실적으로 (10,20) 연령대보다 (80,90) 연령대에서 더 많은 사망자가 발생함을 관찰할 수 있으므로, 이는 비현실적입니다. 따라서 균등 분포 역시 인간 수명에 대한 좋은 모델이 아니며 잘 사용되지 않습니다.

런던 연합(Alliance of London)의 보험 계리사였던 벤저민 곰페르츠(Benjamin Gompertz)는 생리학적인 근거를 추론하여 1825년에 연령에 따른 사망률 변화의 수학적 공식을 제안했습니다. 그에 따르면 사망력은 다음과 같이 주어집니다.

![μ = BCx,   B > 0, C > 1, x ≥ 0  x ](./images/act-book129x.png)

이 공식은 나이가 들수록 사망력이 증가함을 암시합니다. 이는 죽음을 견디는 인간 능력의 저하를 나타냅니다. 곰페르츠 법칙의 생존 함수는 다음과 같이 주어집니다.

![S (x) = exp[- m(Cx - 1)], where m  = B∕logeC, B > 0, C > 1, x ≥ 0 ](./-act-book130x.png)

곰페르츠 법칙은 최소한 첫 번째 근사치로서 25세 이상의 연령대에서 꽤 정확한 것으로 종종 밝혀졌으며, C의 값은 보통 1.07과 1.12 사이입니다. C \= 1이면 곰페르츠 법칙은 지수 분포로 단순화되며, 이는 사망력이 일정하다는 사실이 특징입니다.

약 35년 후, 윌리엄 메이컴(William Makeham)은 연령에 관계없이 발생할 수 있는 우연한 사망 원인을 반영하기 위해 곰페르츠가 가정한 사망력의 기하학적 성분에 상수 성분을 추가할 것을 제안했습니다. 예를 들어, 사고로 인한 사망은 어느 나이에서나 발생할 수 있습니다. 메이컴 법칙에 따른 사망력 및 생존 함수는 다음과 같습니다.

![μx = A + BCx and  S(x) = exp[- Ax - m (Cx - 1)], B > 0, A ≥ - B, C > 1, x ≥ 0 ](./-act-book131x.png)

상수 A는 사고 위험을 포착하는 용어로 해석되어 왔습니다. 곰페르츠와 메이컴의 공식 모두 90세 이상의 연령에서 과도하게 높은 사망률을 만들어냅니다.

와이블의 사망 법칙(Weibull's law of mortality)은 다음과 같이 주어집니다.

![μx = kxn and S(x) = exp(- uxn+1), u = k∕(n +1), k > 0, n > 0, x ≥ 0 ](./images/act-book132x.png)

이는 매개변수 조합에 따른 지지 영역(support)이 인간의 수명 범위를 감당하지 못하기 때문에 인간의 사망률을 표현하는 데 있어 곰페르츠나 메이컴의 법칙보다 성공적이지 못한 편입니다. 그림 [4.2](id1216)와 그림 [4.3](id1216)은 이 네 가지 법칙에 해당하는 사망력과 생존 함수를 각각 묘사합니다. 이 네 가지 법칙에 대한 매개변수는 다음과 같습니다. 드무아브르 법칙의 경우 w \= 100, 곰페르츠 법칙의 경우 B \= 0.5 \* 10–4 및 C \= 100.04 ≈ 1.096, 메이컴 법칙의 경우 A \= 0.7 \* 10–3, B \= 0.5 \* 10–4 및 C \= 10.04 ≈ 1.096이며, 와이블 법칙의 경우 k \= 3 및 n \= 2입니다.

연령이 증가함에 따라 사망력이 네 가지 법칙 모두에서 증가하지만, 증가율은 와이블 법칙에서 높은 비율임을 알 수 있습니다. 와이블 법칙의 생존 함수 그래프에서 지정된 매개변수 값에 대해 2세 이후의 생존 가능성이 거의 0임을 알 수 있습니다. 와이블 분포의 다른 매개변수 조합에 대해서도 유사한 결과가 관찰됩니다. 따라서 와이블 법칙은 인간 수명을 모델링하기에 좋은 모델이 아닙니다. 드무아브르 법칙의 생존 함수 그래프에서도 인간 수명에 대한 좋은 모델이 아님이 분명합니다. 곰페르츠 법칙과 메이컴 법칙의 그래프는 다소 비슷하며, 이 두 가지가 인간 수명에 대한 좋은 모델로 밝혀졌습니다.

위에 설명된 확률 법칙은 종종 생존 함수보다 사망 함수로 참조되며 분석적 사망 법칙(analytical laws of mortality)이라고 합니다.

보험 비즈니스에서 보험자는 연령이 x인 사람에 대해 사망할 때까지의 시간에 대한 확률변수에 관심을 가집니다. 기호 (x)는 연령 x의 개인, 또는 보험 용어로는 'x세인 사람(a life aged x)'을 나타내는 데 사용됩니다. T(x)가 (x)의 사망할 때까지의 시간(time until death)을 나타낸다고 가정합니다. 이는 (x)의 잔여 수명(future lifetime) 또는 잔존 수명(residual life 또는 remaining life)으로도 알려져 있습니다. 특히, T(0) ≡ X입니다. T(x)의 분포는 X > x일 때 주어진 X – x의 조건부 분포와 동일하다는 점에 유의해야 합니다. Gx(t)가 T(x)의 분포 함수를 나타낸다면, t ≥ 0에 대해 다음과 같습니다.

### [ 4.3 단축 잔여 수명(Curtate Future Lifetime)](./08-Content.md#QQ2-1-53)

잔여 수명 T(x)와 관련된 이산 확률변수 K(x)는 T(x)보다 작으면서 큰 정수로 정의됩니다. 예를 들어 T(x) = 7.5이면 K(x) = 7이고, T(x) = 8이면 K(x) = 7이며, T(x) = 0.5이면 K(x) = 0이고 T(x) = 1.3이면 K(x) = 1입니다. 따라서 K(x)는 가능한 값이 0,1,2,![⋅⋅⋅](./images/act-book176x.png)인 정수값을 가지는 확률변수이며, (x)의 완전한 잔여 연수를 지정합니다. 이를 연령 x에서의 단축 잔여 수명(curtate future lifetime)이라고 합니다. 이는 연령이 x인 사람의 완료된 연수로 남은 수명을 지정합니다. K(x)의 가능한 값은 음이 아닌 정수이지만 x가 정수일 필요는 없다는 점에 유의해야 합니다. 그러나 이 장과 후속 장의 대부분의 실용적인 사례 및 예제에서 x는 정수로 간주됩니다.

K(x)의 확률 질량 함수는 아래와 같이 T(x)의 분포로부터 얻을 수 있습니다.

![P [K (x) = k] =  P [k < T(x) ≤ k + 1]               =  k+1qx - kqx =   kpx - k+1px = kpx - kpx 1px+k              =   kpx qx+k = (S (x + k)- S(x +k + 1))∕S(x)              =  k|qx ](./-act-book177x.png)

여기서 k|qx는 2절에서 정의된 바와 같은 이연 확률입니다. K(x)의 가능한 값은 T(x)의 값에 의존한다는 점에 유의합니다. 인간의 한계 연령이 w라면 T(x) ≤ w – x이고, K(x)의 정의에 의해 K(x)의 가능한 최댓값은 w – x보다 작으면서 큰 정수입니다. 이것을 w\*라고 표시해 보겠습니다. 따라서 K(x)의 지지 영역(support)은 {0,1,![⋅⋅⋅](./images/act-book178x.png),w\*}입니다. 예를 들어 w \= 100이고 x \= 30이면 w\* \= 69입니다. w \= 100이고 x \= 40.2이면 w\* \= 59입니다. w \= 100이고 x \= 99이면 w\* \= 0입니다. w \= 100이고 x \= 99.3이면 역시 w\* \= 0입니다. K(w – 1)의 가능한 값은 0부터 w – w \+ 1보다 작은 큰 정수까지, 즉 0이라는 것을 관찰합니다. 따라서 K(w – 1)의 분포는 0에서 퇴화(degenerate)됩니다.

K(x)의 기댓값 E(K(x))는 ex로 표시되며 단축 기댓값(curtate expectation)으로 알려져 있는 반면, 2절에서 정의된 ex0는 완전 기댓값(complete expectation)이라고 지칭됩니다. ex는 종종 한 국가의 생활 수준과 의료 관리 기준의 척도로 사용됩니다.

Example 8.3.1\. 사망력(force of mortality)이 $\mu_x = A+BC^x$로 주어지는 메이컴 법칙(Makeham's law)을 따르며, $A = 0.0007$, $B = 0.0001151$, $C = 1.096$이라고 가정합니다. $i = 0.05$라고 가정하고, 동일한 법칙 및 $i$에 대해 $A_{40} = 0.27975$라고 합니다. 1000 단위 급부를 갖는 (30)세 발행 종신 보험에 대해 보험료가 종신 기시급 연금으로 납입될 때, $k = 1$부터 10까지의 장래법 준비금을 계산하십시오.

Solution: $A_{40} = 0.27975$라고 주어져 있습니다. 그러면 우리는 식 5.4.3에서 유도된 후방 점화식(backward recurrence relation) $A_x = v q_x + v p_x A_{x+1}$을 사용하여 $x = 30$부터 39까지의 $A_x$를 찾습니다. $A_x$ 값은 코드 [8.4.5](id1220)의 Part II를 사용하여 얻습니다. 이 값들을 얻고 나면 식 8.3.8에 주어진 장래법 준비금에 대한 공식 ${}_kV_x = (A_{x+k} - A_x)/(1 - A_x)$를 사용합니다. 코드 [8.4.5](id1220)의 Part II를 사용하여 ${}_kV_x$ 값을 구합니다. 표 [8.14](id1220)는 $k = 1$부터 10까지의 준비금 값을 보여줍니다. 등가 원칙(equivalence principle)에 의해 보험료를 계산하므로 $k = 0$에 대해 준비금은 0입니다. 이는 식 8.3.8에서도 명확하게 알 수 있습니다. 또한 $k$가 증가함에 따라 준비금이 증가한다는 점에 유의하세요.

### [ 4.6 선택 및 최종 생명표(Select and Ultimate Life Tables) ](./08-Content.md#QQ2-1-75)

4절에서 연구된 생명표들은 초기 사건인 출생 이후의 연령 또는 시간인 모든 음이 아닌 정수 x 값들에 대해 qx, px, lx, dx와 같은 다양한 함수들을 제시합니다. 이 모든 함수들에서 기본적인 양은 생존 함수 S(t) = P\[X > t\]이며, 여기서 X는 갓 태어난 개인의 수명입니다. 따라서 출생 시의 생존 함수가 생명표를 구성할 때 모든 향후 연령에 적용됩니다. 이러한 표에서 qx는 연령 x만의 함수로 간주되며 확률 qx를 정의할 때 연령 x인 개인에 대한 어떠한 추가적인 정보도 사용되지 않습니다. 그러나 사망 확률은 연령 x와 함께 성별, 건강 상태, 직업 및 개인의 취미와 같은 다른 많은 요인에도 의존합니다. 보다 엄밀하게는, 사망 확률 qx는 두 가지 요인에 의존합니다. 하나는 연령이고 다른 하나는 선택(selection)으로 알려진 특정 사건 이후의 시간(기간)입니다.

선택의 중요한 예시 중 하나는 정상 보험료율로 생명 보험 청약을 인수하는 것입니다. 회사가 개인을 보험에 인수하기 전에, 의료 검진을 통해 그들이 '불량 위험(bad risk)'이 될 정도로 건강 상태가 나쁘지 않은지 확인하려고 합니다. 결과적으로, 정상 요율로 최근 생명 보험에 인수된 생명의 사망률은 일반 인구의 사망률보다 더 낮을 것으로 예상될 수 있습니다.

두 번째 예시는 개인이 x세에 장애를 입었을 수 있다는 것입니다. 이 정보는 그러한 그룹에 속한 개인의 생존 함수가 나머지 인구의 생존 함수와 다를 것이라는 요구로 이어집니다. 따라서 보조 정보를 사용하여 개인 그룹을 비슷한 조건을 가진 동질적인 그룹들로 묶을 수 있습니다. 그러한 그룹을 선택 그룹(select groups)이라고 합니다. 이 그룹 내 개인의 생존 함수는 선택 그룹을 형성하는 보조 정보의 성격에 따라 달라집니다. 이 절에서는 이른바 선택 생명표(select life table)를 얻기 위해 생명표에서 이 추가 정보를 어떻게 보강하는지 자세히 연구합니다.

생존 모델은 보통 두 가지 범주로 나뉩니다. (i) 총괄 모델(aggregate model)과 (ii) 선택 모델(select model). 총괄 모델에서 생존 함수 S(t)는 초기 시간 t \= 0을 정의하는 초기 사건(출생) 이후 t 단위 시간 동안 생존할 확률을 명시합니다. 그런 다음 일반적으로 도달 연령(attained age)에 x를 사용하므로, t \= 0일 때 x \= 0이 됩니다. 따라서 도달 연령과 경과 시간은 정확히 함께 진행됩니다. 이 경우 1차 변수로서 x 또는 t 중 하나를 사용할 수 있으며, 관례적으로는 x를 사용합니다. 이러한 총괄 생존 함수를 사용하여 구성된 생명표를 총괄 생명표(aggregate life table)라고 합니다. 따라서 4절에서 구성된 모든 생명표는 총괄 생명표입니다.

다른 유형의 생명표를 설명하기 위해, 생명보험 회사가 50세 이상의 여성을 위한 보험 상품을 보유하고 있는 상황을 고려해 보겠습니다. 각각 55세인 두 여성 아니타(Anita)와 기타(Geeta)가 동일한 상품에 지원합니다. 아니타는 일반 인구에 속한 반면, 기타는 최근 전체 신체 검사를 통과하여 일반 인구보다 더 건강한 여성 그룹에 속한다고 가정해 보겠습니다. 쟁점은 회사가 아니타와 기타 모두에게 동일한 보험료를 부과할 수 있는지 여부입니다. 여성의 건강 상태를 고려할 때 신체 검사를 통과한 여성 그룹은 동일한 연령의 일반 여성 인구와 비교하여 사망 위험이 적기 때문에 이들에게 더 적은 보험료를 부과하는 것이 합리적인 것으로 보입니다. 이러한 상황은 '선택' 생명표에서 고려됩니다.

선택 생존 모델에서 생존 함수는 두 개의 독립변수 x와 t의 함수입니다. 독립변수 x는 건강 상태, 성별, 직업, 취미의 성격과 같은 일정한 기준에 기초하여 개인이 선택 그룹에 포함될 때의 연령입니다. 독립변수 t는 선택 이후의 시간을 나타내며 주된 관심사가 되는 변수입니다. 이러한 생존 함수는 S(t;x)로 표시됩니다. 선택 모델의 생존 함수를 사용하여 개발된 생명표를 선택 생명표라고 합니다. 전체 구성은 표기법을 제외하고 총괄 생명표의 구성과 병행합니다. 선택의 효과를 허용하는 특별한 표기법이 있습니다. 이 표기법의 필수적인 특징은 선택 연령, 즉 x를 대괄호로 묶는 것입니다. 따라서 우리는 보험 가입이 인수(선택)될 때 개인의 연령을 \[x\]로 표시합니다. 총괄 생명표에서는 x세인 생명을 나타내기 위해 (x) 기호를 사용했습니다. 선택 이후의 시간, 즉 t는 덧셈으로 표시되므로, \[x\] + t는 연령 x에 선택 상태에 진입한 이후 t년이 경과했음을 의미합니다. 이 문맥에서 선택 연령 x는 수반 변수(concomitant variable)라 불리며, 선택 이후 시간 t가 주된 관심 변수가 됩니다. 선택 연령이 유일한 수반 변수는 아니며, 또 다른 중요한 수반 변수는 성별입니다. 이 수반 변수는 남성과 여성에 대해 별도의 생존 모델을 가짐으로써 반영됩니다. 또 다른 예로는 흡연자와 비흡연자가 있을 수 있습니다.

연령 x에서 특정 선택 그룹 내의 개인 수를 나타내는 기수(radix) l\[x\]부터 시작한다고 가정해 봅시다. 그런 다음 후속 함수들은 다음과 같이 얻어집니다.

![l[x]+t = l[x]S(t;x) ](./-act-book263x.png)

![sq[x]+t  =  1- S (t +s;x)∕S(t;x ) = 1- l[x]+ (t+s)∕l[x]+t ](./-act-book264x.png)

표 4.14 선택 생명표

첫 번째 행은 개인이 연령 25에 선택 그룹의 일원일 때 단위 구간에서의 사망 확률을 명시합니다. 따라서 q\[25\]+1은 개인이 연령 25에 선택 그룹에 배정되었을 때 연령 구간 (26, 27)에서의 사망 확률입니다. 반면에 q\[26\]은 동일한 연령 구간 (26, 27)에서의 사망 확률이지만 개인이 연령 26에 선택 그룹에 배정되었을 때를 나타냅니다. 결과적으로 두 확률은 서로 다릅니다.

q\[x\]+1 양들로부터 다양한 다른 생명표 함수들을 계산할 수 있습니다. 예를 들어, 연령 x에서 선택이 이루어질 경우, x \+ 5세에 살아있는 것으로 알려진 사람이 x \+ 7세에서 x \+ 10세 사이에 사망할 조건부 확률은 다음과 같이 주어집니다.

![2|3q[x]+5 = (l[x]+7 - l[x]+10)∕l[x]+5 ](./-act-book297x.png)

선택이 사망까지의 시간 분포에 미치는 영향은 선택 이후 몇 년이 지나면 계속해서 감소합니다. 예를 들어, 두 사람 중 한 사람은 20세에 선택되어 현재 30세이고, 다른 한 사람은 21세에 선택되어 현재 30세라고 가정해 봅시다. 앞으로 n년 동안 생존할 그들의 각각의 조건부 확률은 다음과 같이 주어집니다.

![np[20]+10 = l[20]+10+n∕l[20]+10 &   np[21]+9 = l[21]+9+n∕l[21]+9 ](./-act-book298x.png)

일반적으로 선택은 9년 또는 10년 후에는 큰 영향을 미치지 않으며, 두 확률 모두 도달 연령의 함수인 l30+n ∕ l30과 같아질 수 있음이 관찰됩니다. 모든 t ≥ s에 대해 q\[x\]+t \= qx+t가 성립하거나 q\[x\]+s가 도달 연령의 함수가 되는 최소 정수 s가 존재한다면, 그러한 정수 s를 '선택 기간(select period)'이라고 합니다. 보험계리사회(Society of Actuaries)는 보통 선택 기간으로 s \= 15년을 취합니다. 선택 기간이 s인 선택 생명표의 2차원 배열에서 (s \+ 1)번째 열은 총괄 생명표의 양 qx+s와 거의 동일할 것입니다. 결국 그 차이는 너무 작아져 실용적인 목적상 '선택 그룹'과 '비선택 그룹'을 구별하는 것이 의미가 없게 됩니다. 결과적으로 선택 생명표는 (s \+ 1)번째 열에서 절단될(truncated) 수 있습니다. 선택의 영향이 무시할 수 있을 정도인 기간을 '최종 기간(ultimate period)'이라고 부릅니다. 따라서 이 마지막 열을 최종 생명표(ultimate life table)라고 부르며 전체 표를 선택 및 최종 생명표(select and ultimate life table)라고 부릅니다. 일반적으로 선택 생명표는 처음 s개의 열에 해당하며 최종 생명표는 (s \+ 1)번째 열에 해당합니다. 선택 및 최종 생명표는 최종 생명표부터 왼쪽 방향으로 작성됩니다. 작성 과정은 아래에서 논의합니다.

선택 및 최종 생명표 작성(Construction of Select and Ultimate Life Table): 선택 및 최종 생명표를 나타내기 위해 2차원 배열을 사용합니다. 각 행은 서로 다른 선택 연령을 나타내며 각 열은 선택 이후의 경과 기간을 나타냅니다. 선택 기간이 2년인 경우의 절차를 설명합니다. 이 표의 기본 구성 요소는 qy (y \= 0, 1, 2, ![⋅⋅⋅](./images/act-book299x.png))와 q\[x\]+t (x \= 0, 1, 2, ![⋅⋅⋅](./-act-book300x.png), t \= 0, 1)로 주어지는 사망률입니다. l0가 고정되어 있다고 가정하면, 주어진 qy들로부터 l1, l2, l3, ![⋅⋅⋅](./images/act-book301x.png) 를 찾을 수 있습니다. 선택 기간이 2년이므로 모든 x ≥ 0에 대해 l\[x\]+2 \= lx+2 입니다. 특히 x \= 0이라고 합시다. 그러면 l2 \= l\[0\]+2 \= (l\[0\]+1)(1 – q\[0\]+1)이 됩니다. q\[0\]+1의 값이 주어지므로 다음을 얻습니다.

![l    = l2∕(1- q   ) [0]+1          [0]+1 ](./-act-book302x.png)

![또한,    l[0]+1 = l[0](./._images_1_-_q[0].md), ⇒      l[0] = l[0]+1∕(1- q[0]) ](./-act-book303x.png)

l\[x\]+2 \= lx+2 에서 x \= 1이라고 가정합니다. 그러면,

![l3 = l[1]+2 = l[1]+1(1- q[1]+1) ⇒   l[1]+1 = l3∕(1- q[1]+1) ](./-act-book304x.png)

이와 비슷하게,

![l[1]+1 = l[1](./._images_1_-_q[1].md) ⇒ l[1] = l[1]+1∕(1- q[1]) ](./-act-book305x.png)

이와 같은 방식으로 계속 진행하면 선택 생명표 내의 모든 양들을 구할 수 있습니다.

4절에서 논의된 바와 같이, 사망률 패턴은 대개 특정 지역의 특정 기간에 대한 연령별 사망률로 제공되며, 이로부터 연령 x \= 0부터 어떤 한계 연령까지 qx 값들을 구할 수 있습니다. 우리는 주어진 qx 값들의 집합에 대응하여 4절에서 연구된 생명표를 구성하는 일련의 R 함수들을 아래에 제시합니다.

코드 4.7.3\. 이 코드에서는 주어진 qx 값들의 집합에 대응하는 생명표를 구성하는 R 함수들을 작성하기 위해 식 4.4.1에 주어진 공식 집합을 사용합니다. Siegel과 David [18]가 보고한 qx 값들로 주어진 사망률 패턴을 사용합니다. x \= 0부터 110까지의 qx 값들은 로컬 디스크 F의 텍스트 파일 qx.txt에 저장되어 있습니다. 이 파일을 R로 가져오기 위해 read.table 함수를 사용합니다. qx.txt 파일에서 첫 번째 열은 x로 레이블이 지정되고 두 번째 열은 qx로 레이블이 지정됩니다. 따라서 header=TRUE 인수가 사용됩니다. 이 코드는 표 4.8과 같은 생명표를 생성합니다.

z=read.table("F://qx.txt", header=TRUE)
x=z[,1]; q=z[,2]; p=1-q; w=length(p); l1=10^5;l=c(l1,2:w)
for (i in 2:w)
{
l[i]=l[i-1]*p[i-1]
}
de=l*q;L=c(1:(w-1),.5*l[w])
for (i in 1:(w-1))
{
L[i]=.5*(l[i]+l[i+1])
}
T=c(1:(w-1),L[w])
for (i in 1:(w-1))
{
T[w–i]=T[w–i+1]+L[w–i]
}
ex=T/l; y=round(data.frame(l,de,L,T,ex),2)
y1=data.frame(x,q,p,y); y1 # 표 4.8
