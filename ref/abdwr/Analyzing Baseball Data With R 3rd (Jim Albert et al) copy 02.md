2.3 타이디버스 (The Tidyverse)

R은 모듈식 시스템입니다. 패키지를 설치하고 로드하여 기능을 추가할 수 있습니다(섹션 2.9 참조). R 언어와 일부 핵심 패키지(base, stats, graphics)는 R Core Development Team에서 개발합니다. 하지만 패키지는 누구나 작성할 수 있으며 다양한 기능을 제공할 수 있습니다. 최근 많은 기여자의 대규모 조정된 노력으로 타이디버스(tidyverse)가 개발되었습니다. 타이디버스는 상호 운용성을 위해 의도적으로 설계된 패키지 모음으로, 특히 Posit의 수석 과학자인 해들리 위컴(Hadley Wickham)이 명확히 한 깔끔한 데이터(tidy data) 철학을 중심으로 합니다(Wickham 2014). 타이디버스 패키지 자체는 이 철학을 준수하는 다른 패키지 모음을 로드하는 역할만 주로 수행합니다.

이 책의 2판에서 수행한 주요 작업은 모든 코드를 타이디버스 규정 준수로 가져오는 것이었습니다.

library(tidyverse)

깔끔한 데이터의 핵심 개념은 데이터 프레임의 행이 동일한 관찰 단위에 해당해야 하며 열은 해당 관찰 단위에 대한 변수를 나타내야 한다는 것입니다. 이는 깔끔한 데이터 프레임에는 다른 행을 합산하는 행이 포함되지 않거나 행의 레이블이 변수 대신 행 이름으로 저장되지 않거나 동일한 관찰 단위에 대해 동일한 유형의 정보를 포함하는 두 개의 열이 포함되지 않음을 의미합니다.

타이디버스의 패키지는 data.frame 중심입니다(섹션 2.4 참조). 함수는 대부분 data.frame을 첫 번째 입력으로 받고 작업을 수행한 다음 (수정된 버전을) 반환합니다. 행렬, 벡터, 리스트와 같은 다른 데이터 구조는 타이디버스에서 덜 흔하게 사용됩니다. 티블(tibble)은 data.frame과 유사하지만 일부 추가 기능이 포함될 수 있습니다. 이 책에서는 편리할 때마다 data.frames보다 티블을 선호합니다.

타이디버스에는 많은 패키지가 있지만 몇 가지 패키지는 명시적인 소개가 필요합니다.

2.3.1 dplyr

dplyr 패키지는 데이터 조작(또는 데이터 랭글링)을 위한 포괄적인 도구를 제공합니다. 다섯 가지 주요 "동사"는 다음과 같습니다.

- • select(): 열의 하위 집합 선택
- • filter(): 논리적 기준에 따라 행의 하위 집합 선택
- • arrange(): 열의 값에 따라 행 정렬
- • mutate(): 열의 정의 추가 또는 수정
- • summarize(): 벡터를 단일 값으로 집계하여 데이터 프레임을 (그룹당) 단일 행으로 축소. 종종 group_by()와 함께 사용됩니다.

이 다섯 가지 함수는 해당 값을 일치시켜 두 데이터 프레임을 병합할 수 있는 함수(inner_join(), left_join() 등)와 함께 결합되어 SQL SELECT 쿼리와 동일한 기능을 생성할 수 있습니다(11장 참조). 방대한 데이터 분석 작업은 이러한 함수의 조합(rename(), count(), bind_rows(), pull() 등 dplyr에서 제공하는 몇 가지 다른 동사와 함께)으로 축소될 수 있습니다.

최근 많은 기여자의 대규모 조정된 노력으로 타이디버스(tidyverse)가 개발되었습니다. 타이디버스는 상호 운용성을 위해 의도적으로 설계된 패키지 모음으로, 특히 Posit의 수석 과학자인 해들리 위컴(Hadley Wickham)이 명확히 한 깔끔한 데이터(tidy data) 철학을 중심으로 합니다(Wickham 2014). 타이디버스 패키지 자체는 이 철학을 준수하는 다른 패키지 모음을 로드하는 역할만 주로 수행합니다.

- 2.3.2 파이프 (The pipe)

타이디버스 설계의 주요 구성 요소는 파이프 연산자 |> 의 사용입니다. 파이프 연산자를 사용하면 중첩된 대응 항목보다 읽기 쉬운 함수 파이프라인을 만들 수 있습니다. 파이프는 앞에 오는 것을 첫 번째 인수로서 뒤에 오는 함수에 주입합니다. 따라서 다음 코드 줄은 동일합니다.

outer_function(inner_function(x), y) x |>

inner_function() |> outer_function(y)

후자의 코드 덩어리가 읽기 쉽고 수많은 연속 작업(즉, 파이프라인)으로 더 잘 확장되며 인수를 속한 함수에 더 가깝게 유지한다는 것을 알 수 있습니다. 타이디버스의 많은 함수가 첫 번째 인수로 티블을 받고 티블을 반환하기 때문에, 그것들은 (설계상) "파이프 가능"합니다.

버전 4.1.0부터 R에는 기본 파이프 연산자인 |> 가 포함되었습니다. 이 연산자는 이 책 전체에서 광범위하게 사용되며 magrittr 패키지에서 제공되고 이 책의 2판 전체에서 사용된 레거시 파이프 연산자(%>%)를 대체합니다.

- 2.3.3 ggplot2

- 2.3.4 기타 패키지

2.4.4 데이터 프레임 병합 및 선택

야구 연구에서는 팀에 대한 타격 및 투구 데이터가 포함된 여러 데이터 프레임을 갖는 것이 일반적입니다. 여기에서는 데이터 프레임을 병합하고 주어진 조건을 충족하는 데이터 프레임의 일부를 추출하는 몇 가지 방법을 설명합니다.

2011년 시즌의 모든 내셔널 리그와 아메리칸 리그 팀에 대한 타격 통계가 포함된 R 데이터 프레임 NLbatting 및 ALbatting을 읽어 들인다고 가정합니다. 이러한 데이터 프레임을 새로운 데이터 프레임 batting으로 결합하고자 한다고 가정합니다. 두 데이터 프레임을 수직으로 추가하려면 dplyr 패키지의 bind_rows() 함수를 사용할 수 있습니다.

batting <- bind_rows(NLbatting, ALbatting)

대신에 2011년 시즌 NL 팀에 대한 타격 데이터 NLbatting과 투구 데이터 NLpitching을 읽었고 특정 변수를 키로 사용하여 한 데이터 프레임의 행을 다른 데이터 프레임의 행과 일치시키고자 한다고 가정합니다. 이 경우 병합된 데이터 프레임의 행에는 특정 팀의 타격 및 투구 통계가 포함됩니다. 이 경우 두 데이터 프레임을 지정하고 by 인수가 병합할 공통 변수(Tm)를 나타내는 dplyr 패키지의 inner_join() 함수를 사용합니다.

- 2.4.4 데이터 프레임 병합 및 선택

야구 연구에서는 팀에 대한 타격 및 투구 데이터가 포함된 여러 데이터 프레임을 갖는 것이 일반적입니다. 여기에서는 데이터 프레임을 병합하고 주어진 조건을 충족하는 데이터 프레임의 일부를 추출하는 몇 가지 방법을 설명합니다.

2011년 시즌의 모든 내셔널 리그와 아메리칸 리그 팀에 대한 타격 통계가 포함된 R 데이터 프레임 NLbatting 및 ALbatting을 읽어 들인다고 가정합니다. 이러한 데이터 프레임을 새로운 데이터 프레임 batting으로 결합하고자 한다고 가정합니다. 두 데이터 프레임을 수직으로 추가하려면 dplyr 패키지의 bind_rows() 함수를 사용할 수 있습니다.

batting <- bind_rows(NLbatting, ALbatting)

대신에 2011년 시즌 NL 팀에 대한 타격 데이터 NLbatting과 투구 데이터 NLpitching을 읽었고 특정 변수를 키로 사용하여 한 데이터 프레임의 행을 다른 데이터 프레임의 행과 일치시키고자 전제합니다. 이 경우 병합된 데이터 프레임의 행에는 특정 팀의 타격 및 투구 통계가 포함됩니다. 이 경우 두 데이터 프레임을 지정하고 by 인수가 병합할 공통 변수(Tm)를 나타내는 dplyr 패키지의 inner_join() 함수를 사용합니다.

NL <- inner_join(NLbatting, NLpitching, by = "Tm")

새 데이터 프레임 NL에는 16개의(NL 팀 수) 행과 NLbatting 및 NLpitching 데이터 프레임 모두의 모든 변수가 포함됩니다.

세 번째 유용한 연산은 특정 조건을 충족하는 데이터 프레임의 하위 집합을 선택하는 것입니다. NLbatting 데이터 프레임이 있고 이번 시즌에 150개 이상의 홈런을 친 팀의 타격 통계에만 집중하고자 한다고 가정합니다. filter() 함수를 사용합니다. 인수는 팀이 선택되는 방식을 설명하는 논리적 조건입니다.

###### 2.6 R의 객체 및 컨테이너 (Objects and Containers in R)

R을 사용하여 생성하는 것을 객체라고 합니다. 이러한 객체는 숫자형, 논리형, 문자형 및 정수형과 같이 유형이 다를 수 있습니다. 이전 섹션에서 이미 숫자형 및 논리형 유형의 객체로 작업했습니다. 컨테이너에 여러 객체를 저장합니다. 벡터는 동일한 유형의 객체 여러 개, 예를 들어 모두 숫자형이거나 모두 논리형인 객체를 배치하는 간단한 유형의 컨테이너입니다. 여기에서는 야구 데이터 작업에 유용한 다양한 객체 유형과 컨테이너 중 일부를 설명합니다.

2.6.1 문자 데이터 및 데이터 프레임 (Character data and data frames)

2.7.2 R 함수 (R functions)

몇 가지 R 내장 패키지의 사용을 설명했습니다. R의 매력적인 기능 중 하나는 관심 있는 특정 계산 및 그래프를 구현하기 위해 자신만의 함수를 생성하는 기능입니다.

간단한 예로 여러 시즌 동안 선수의 홈런 비율을 계산하는 함수를 작성하는 데 관심이 있다고 가정해 보겠습니다. 선수 나이 벡터 age, 홈런 수 벡터 hr, 타수 벡터 ab를 입력합니다. 함수가 선수의 홈런 비율(가장 가까운 10분의 1로 반올림된 백분율로)을 계산하고 그래프 작성에 적합한 형식으로 나이와 비율을 출력하기를 원합니다.

다음 hr_rates() 함수는 원하는 계산을 수행합니다. 모든 함수는 name_of_function <- function(arguments) 구문으로 시작하며, 여기서 arguments는 입력 변수 목록입니다.

함수의 모든 작업은 이어지는 중괄호 안에 들어갑니다. 함수의 마지막 줄 결과가 출력으로 반환됩니다. 예제에서 함수 이름은 hr_rates이고 세 개의 벡터 입력 age, hr, ab가 있습니다. round() 함수는 홈런 비율을 계산하는 데 사용됩니다.3 이 함수의 출력은 두 구성 요소가 있는 리스트입니다. x는 나이 벡터이고 y는 홈런 비율 벡터입니다.

hr_rates <- function(age, hr, ab) { rates <- round(100 \* hr / ab, 1) list(x = age, y = rates)

}

이 함수를 사용하려면 먼저 R로 읽어야 합니다. 콘솔 창에 직접 입력하거나 함수를 hr_rates.R과 같은 파일에 저장하고 source() 함수를 통해 R로 읽어서 이 작업을 수행할 수 있습니다. (이 함수는 abdwr3edata 패키지에서도 사용할 수 있습니다.)

###### 2.10 데이터 분할, 적용 및 결합 (Splitting, Applying, and Combining Data)

데이터 과학의 핵심 역량은 입력 시퀀스에 걸쳐 분석 연산을 반복하는 능력입니다. 위의 논의에 따라 이제 야구 역사 전반에 걸쳐 각 십 년마다 가장 많은 홈런을 친 선수를 식별하고자 한다고 가정합니다.

먼저 타격 통계의 데이터 프레임을 가져와서 해당 세트에서 홈런이 가장 많은 선수에 해당하는 한 행을 반환하는 간단한 함수를 작성합니다. 이는 이전 코드를 약간만 수정하면 됩니다.

hr_leader <- function(data) {

data |> group_by(playerID) |> summarize(HR = sum(HR)) |> arrange(desc(HR)) |> slice(1)

}

다음으로 십 년(decade)을 기준으로 Batting 데이터 프레임을 여러 조각으로 분할해야 합니다. 이 정보는 Batting에 저장되어 있지 않으므로 mutate()를 사용하여 yearID의 모든 값에 대해 십 년의 첫해를 계산하는 decade라는 새 변수를 생성합니다. 그런 다음 group_by() 함수를 사용하여 decade의 공통 값을 공유하는 조각으로 Batting을 구성합니다. 그 결과 그룹화된 데이터 프레임이 생성되며 각 그룹은 단일 십 년에 해당합니다.

2.10.2 또 다른 예제 (Another example)

시즌 타격 통계의 동일한 Batting 데이터 프레임을 사용하여 통산 타수가 5000 이상인 야구 역사상 모든 선수의 통산 타수, 통산 홈런, 통산 삼진을 수집하고자 한다고 가정합니다. 선수의 삼진 비율(SO/AB로 정의됨)과 그의 홈런 비율 HR/AB 사이에 어느 정도 연관성이 있을 수 있다고 의심하기 때문에 홈런과 삼진 모두 관심 대상입니다.

이 작업은 두 단계로 수행됩니다. 먼저 모든 타자에 대한 통산 AB, HR, SO로 구성된 새 데이터 프레임을 만듭니다. 둘째, filter() 함수를 사용하여 5000 AB인 선수의 데이터 프레임에서 타격 시즌을 선택합니다.

dplyr 패키지의 summarize() 함수는 첫 번째 작업에 유용합니다. 선수의 경력 시즌 동안 AB의 합계를 계산하고자 합니다. group_by() 함수는 Batting 데이터 프레임을 playerID 변수로 분할하고자 함을 나타내고, tAB = sum(AB, na.rm = TRUE)는 AB의 합계를 계산하여 각 데이터 프레임 "부분"을 요약하고자 함을 나타냅니다. (일부 AB 값은 누락되어 NA로 코딩되며, na.rm = TRUE는 합계를 내기 전에 이러한 누락된 값을 제거합니다.) 새 데이터 프레임 long_careers에는 모든 선수의 통산 AB가 포함되어 있습니다.

long_careers <- Batting |> group_by(playerID) |> summarize(

tAB = sum(AB, na.rm = TRUE), tHR = sum(HR, na.rm = TRUE), tSO = sum(SO, na.rm = TRUE)

)

이제 이 새로운 변수 tAB가 있으므로 filter() 함수를 사용하여 5000 AB인 선수의 시즌 타격 통계만 선택할 수 있습니다.

Batting_5000 <- long_careers |> filter(tAB >= 5000)
