득점 기대값을 이용한 플레이의 가치

- 5.1 득점 기대값 행렬 세이버메트릭스 연구에서 중요한 개념 중 하나는 득점 기대값 행렬입니다.

- 각 루(1루, 2루, 3루)는 비어 있거나 주자가 있을 수 있으므로, 세 루에 주자가 배치될 수 있는 경우는 2 × 2 × 2 = 8가지입니다. 아웃 카운트는 0, 1, 2(세 가지 경우)가 될 수 있으므로, 주자와 아웃 카운트의 조합은 총 8 × 3 = 24가지입니다. 베이스의 주자와 아웃 카운트의 각 조합에 대해, 이닝의 남은 시간 동안 득점하는 평균 점수를 계산하는 데 관심이 있습니다. 이 평균 점수를 주자와 아웃 카운트로 분류된 표로 정리할 때, 이 표를 흔히 득점 기대값 행렬이라고 부릅니다.

R을 사용하여 2016 시즌의 플레이별 데이터에서 이 행렬을 계산합니다. 이 행렬은 타석의 기대 득점 가치(종종 단순히 "득점 가치"라고 함)의 변화를 정의하는 데 사용됩니다. 그런 다음 2016 시즌 모든 타자의 평균 득점 가치 분포를 탐색합니다. 호세 알투베의 득점 가치를 사용하여 선수들 간의 의미를 맥락화하는 데 도움을 줍니다. 타순의 여러 위치에 있는 선수들이 이 기준과 관련하여 어떻게 성과를 내는지 계속해서 탐색합니다. 기대 득점 가치의 개념은 다양한 타격 플레이의 상대적 이점을 이해하는 데 도움이 되며, 홈런과 단타의 가치를 탐색합니다. 마지막으로 득점 기대값 행렬과 득점 가치를 사용하여 도루의 이점과 도루 실패의 비용을 이해함으로써 장을 마무리합니다.

- 5.2 이닝의 남은 시간 동안 득점

먼저 레트로시트에서 다운로드한 2016 시즌 플레이별 데이터를 retro2016으로 R에 읽어옵니다. retro2016.rds 파일을 만드는 방법은 A.1.3절을 참조하시기 바랍니다. (retro2016 데이터셋은 abdwr3edata 패키지에서도 사용할 수 있습니다.)

DOI: 10.1201/9781032668239-5 109

```r
retro2016 <- read_rds(here::here("data/retro2016.rds"))
```

- 주어진 타석에서 득점할 가능성이 있습니다. 분명히 이 가능성은 베이스에 주자가 있을 때, 특히 득점권(2루 또는 3루)에 주자가 있고 아웃 카운트가 적을 때 더 큽니다. 이 득점 가능성은 일정 기간 동안 베이스의 주자와 아웃 카운트의 각 조합에 대해 이닝의 남은 시간 동안 득점한 평균 점수를 계산하여 추정합니다. 물론 평균 득점은 홈 대 원정, 현재 점수, 투수, 수비와 같은 여러 변수에 따라 달라집니다. 그러나 이 득점 가능성은 이닝 동안 일반적인 상황에서 점수를 낼 수 있는 기회를 나타내며, 선수의 기여도를 측정하는 데 유용한 기준선입니다.

이닝의 남은 시간 동안 득점한 점수를 계산하려면 해당 타석 동안 양 팀이 득점한 총 점수와 특정 반 이닝이 끝날 때 팀이 득점한 총 점수를 알아야 합니다. 이닝의 남은 시간 동안 득점한 점수(runs_roi로 표시)는 다음과 같은 차이입니다.

runsroi = runsTotal in Inning − runsSo far in Inning.

mutate() 함수를 사용하여 몇 가지 새로운 변수를 만듭니다. runs_before는 각 타석에서 원정팀의 점수(away_score_ct)와 홈팀의 점수(home_score_ct)의 합과 같으며, half_inning은 paste() 함수를 사용하여 게임 ID, 이닝, 공격 팀을 결합하여 모든 게임의 각 반 이닝에 대한 고유한 식별자를 만듭니다. 또한 각 플레이에서 득점한 점수를 제공하는 새로운 변수 runs_scored를 만듭니다. (변수 bat_dest_id, run1_dest_id, run2_dest_id 및 run3_dest_id는 타자와 각 주자의 목적지 베이스를 제공하며, 목적지 베이스가 3을 초과할 때마다 득점이 기록됩니다.)

```r
retro2016 <- retro2016 |>
  mutate(
    runs_before = away_score_ct + home_score_ct,
    half_inning = paste(game_id, inn_ct, bat_home_id),
    runs_scored = (bat_dest_id > 3) + (run1_dest_id > 3) + (run2_dest_id > 3) + (run3_dest_id > 3)
  )
```

홈팀과 원정팀의 점수를 결합하여 각 반 이닝의 최대 총 점수를 계산하고자 합니다. 이를 위해 half_inning으로 그룹화한 후 summarize() 함수를 사용합니다. summarize() 함수에서 outs_inning은 각 반 이닝의 아웃 카운트, runs_inning은 각 반 이닝에서 득점한 총 점수, runs_start는 반 이닝 시작 시점의 점수, max_runs는 반 이닝의 최대 총 점수이며, 이는 초기 총 점수와 득점한 점수의 합입니다. 이러한 요약 데이터는 새로운 데이터 프레임 half_innings에 저장됩니다.

```r
half_innings <- retro2016 |> group_by(half_inning) |> summarize(
  outs_inning = sum(event_outs_ct),
  runs_inning = sum(runs_scored),
  runs_start = first(runs_before),
  max_runs = runs_inning + runs_start
)
```

inner_join() 함수를 사용하여 데이터 프레임 data2016과 half_innings를 병합합니다. 그런 다음 max_runs와 runs의 차이를 계산하여 이닝의 남은 시간 동안 득점한 점수(새 변수 runs_roi)를 계산할 수 있습니다.

```r
retro2016 <- retro2016 |> inner_join(half_innings, by = "half_inning") |> mutate(runs_roi = max_runs - runs_before)
```

5.3 행렬 생성

이제 각 타석에 대해 이닝의 남은 시간 동안 득점한 점수 변수가 계산되었으므로 득점 기대값 행렬을 간단히 계산할 수 있습니다.

현재 1루, 2루 또는 3루에 각각 있는 주자(있는 경우)의 선수 코드를 포함하는 세 개의 변수 base1_run_id, base2_run_id 및 base3_run_id가 있습니다. 해당 베이스가 각각 비어 있거나 주자가 있는 경우 각 숫자가 0 또는 1인 새로운 세 자리 변수 bases를 만듭니다. state 변수는 bases 변수에 아웃 카운트를 추가합니다. state의 한 특정 값은 "011 2"일 수 있으며, 이는 현재 2아웃에 2루와 3루에 주자가 있음을 나타냅니다. 두 번째 state 값 "100 0"은 무사 1루를 나타냅니다.

```r
retro2016 <- retro2016 |> mutate(
  bases = paste0(
    if_else(base1_run_id == "", 0, 1),
    if_else(base2_run_id == "", 0, 1),
    if_else(base3_run_id == "", 0, 1)
  ),
  state = paste(bases, outs_ct)
)
```

우리는 베이스의 주자, 아웃 카운트 또는 득점에 변화가 있는 데이터 프레임의 플레이만 고려하고자 합니다. 세 개의 새로운 변수 is_runner1, is_runner2, is_runner3을 만들며, 이들은 플레이 후 1루, 2루, 3루에 각각 주자가 있는지를 나타냅니다. (함수 as.numeric()은 논리형 변수를 숫자형 변수로 변환합니다.) 변수 new_outs는 플레이 후 아웃 카운트이고, new_bases는 차지한 베이스를 나타내며, new_state는 플레이 후 각 베이스의 주자와 아웃 카운트를 제공합니다.1

```r
retro2016 <- retro2016 |> mutate(
  is_runner1 = as.numeric(
    run1_dest_id == 1 | bat_dest_id == 1
  ),
  is_runner2 = as.numeric(
    run1_dest_id == 2 | run2_dest_id == 2 | bat_dest_id == 2
  ),
  is_runner3 = as.numeric(
    run1_dest_id == 3 | run2_dest_id == 3 | run3_dest_id == 3 | bat_dest_id == 3
  ),
  new_outs = outs_ct + event_outs_ct,
  new_bases = paste0(is_runner1, is_runner2, is_runner3),
  new_state = paste(new_bases, new_outs)
)
```

filter() 함수를 사용하여 state와 new_state 사이에 변화가 있거나(같지 않음 논리 연산자 !=로 표시) 플레이에서 득점이 발생한 플레이로 주의를 제한합니다.

```r
changes2016 <- retro2016 |> filter(state != new_state | runs_scored > 0)
```

득점 기대값을 계산하기 전에 마지막으로 한 가지 조정이 필요합니다. 플레이별 데이터베이스에는 3아웃 미만으로 결승점이 득점된 게임 후반부의 일부 반 이닝을 포함하여 2016 시즌의 모든 반 이닝에 대한 득점 정보가 포함되어 있습니다. 우리의 계산에서

1현재 및 미래 상태를 계산하는 로직은 abdwr3edata 패키지의 retrosheet_add_states() 함수에 인코딩되어 있습니다. 유사한 기능에 대해서는 baseballr 패키지의 run_expectancy_code() 함수를 참조하시기 바랍니다.


```r
changes2016_complete <- changes2016 |> filter(outs_inning == 3)
```

summarize() 함수를 사용하여 24개의 베이스/아웃 상황 각각에 대해 이닝의 남은 시간 동안 득점할 것으로 예상되는 점수(득점 기대값)를 계산하고, bases 및 outs_ct로 그룹화한 후 mean() 함수를 사용합니다. 결과 데이터 프레임을 erm_2016으로 정의하고 저장합니다.

```r
erm_2016 <- changes2016_complete |> group_by(bases, outs_ct) |> summarize(mean_run_value = mean(runs_roi))
```

득점 기대값을 얻게 됩니다. 타석의 가치, 즉 득점 가치는 이전 상황과 새로운 상황의 득점 기대값의 차이에 특정 플레이에서 득점한 점수를 더하여 추정합니다.

RUN VALUE = RUNSNew state − RUNSOld state + RUNSScored on Play

다음 R 코드를 사용하여 원본 데이터 프레임 retro2016의 모든 플레이에 대한 득점 가치를 계산합니다. 먼저 left_join() 함수를 사용하여 각 타석 시작 시점의 기대 득점 가치를 일치시킵니다. retro2016의 bases 및 outs_ct 변수를 득점 기대값 행렬 erm_2016의 변수와 일치시킴으로써 이를 수행합니다. 이렇게 하면 새로운 변수 mean_run_value가 생성되며, 즉시 rv_start로 이름을 바꿉니다. 다음으로 다시 이 작업을 수행합니다. 이번에는 new_bases 및 new_outs 변수를 득점 기대값 행렬과 일치시켜 변수 rv_end를 만듭니다. 여기서 (inner_join() 대신) left_join()을 사용하는 것이 중요합니다. erm_2016에는 3아웃 상황이 존재하지 않기 때문입니다. 3아웃 상황의 득점 기대값은 당연히 0이므로 replace_na() 함수를 사용하여 이러한 득점 가치를 0으로 설정합니다.

따라서 데이터셋 retro2016에서 변수 rv_start는 현재 상태의 득점 기대값으로 정의되고 변수 rv_end는 새로운 상태의 득점 기대값으로 정의됩니다. 새로운 변수 run_value는 rv_end와 rv_start의 차이에 runs_scored를 더한 값과 같습니다.

```r
retro2016 <- retro2016 |>
  left_join(erm_2016, join_by("bases", "outs_ct")) |>
  rename(rv_start = mean_run_value) |>
  left_join(
    erm_2016, join_by(new_bases == bases, new_outs == outs_ct)
  ) |>
  rename(rv_end = mean_run_value) |>
  replace_na(list(rv_end = 0)) |>
  mutate(run_value = rv_end - rv_start + runs_scored)
```

5.6 모든 타자의 기회와 성공

득점 가치 추정치는 선수들의 타격 효율성을 비교하는 데 사용할 수 있습니다. 타격 플레이에 초점을 맞추므로, 주요 데이터 프레임 retro2016에서 bat_event_fl 변수가 TRUE인 하위 집합인 새로운 데이터 프레임 retro2016_bat을 구성합니다.

```r
retro2016_bat <- retro2016 |> filter(bat_event_fl == TRUE)
```

두 선수의 RE24를 액면 그대로 비교하는 것은 어렵습니다. 왜냐하면 팀을 위해 득점할 수 있는 기회가 다르기 때문입니다. 타순의 중간에 있는 선수는

득점권에 주자가 있고 득점 기회가 좋을 때 타석에 여러 번 들어설 수 있습니다. 타순 아래쪽에 있는 다른 선수들은 베이스에 주자가 있는 상황에서 타석에 들어설 기회를 똑같이 얻지 못할 수 있습니다. 모든 타석에 걸쳐 득점 가능성 상태(변수 rv_start)의 합으로 득점을 창출할 선수의 기회를 측정할 수 있습니다. 선수의 시즌 타격 성과는 총 타석 수, 득점 가능성의 합, 득점 가치의 합으로 요약할 수 있습니다.

R 함수 summarize()는 이러한 요약을 얻는 데 유용합니다. 먼저 타자 ID 변수 bat_id로 데이터 프레임 retro2016_bat을 그룹화하고, 각 타자에 대해 총 득점 가치 RE24, 총 시작 득점 가능성 runs_start, 타석 수 PA를 계산합니다.

```r
run_exp <- retro2016_bat |> group_by(bat_id) |> summarize(
  RE24 = sum(run_value),
  PA = length(run_value),
  runs_start = sum(rv_start)
```

- 5.9 도루의 가치

득점 기대값 행렬은 도루의 이점을 이해하는 데에도 유용합니다. 주자가 도루를 시도할 때 성공하거나 실패(도루자)하는 두 가지 가능성 높은 결과가 있습니다. 전반적으로 도루를 시도하는 데 순이익이 있을까요?

변수 event_cd는 플레이 코드를 제공하며 코드 4와 6은 각각 도루(SB) 또는 도루 실패(CS)에 해당합니다. filter() 함수를 사용하여 도루를 시도하는 플레이로만 구성된 새로운 데이터 프레임 stealing을 만듭니다.

```r
stealing <- retro2016 |> filter(event_cd %in% c(4, 6))
```

summarize() 및 n() 함수를 사용하여 SB 및 CS 결과의 빈도를 찾습니다.

```r
stealing |>
  group_by(event_cd) |> summarize(N = n()) |>
  mutate(pct = N / sum(N))

# A tibble: 2 x 3
  event_cd     N   pct
     <int> <int> <dbl>
1        4  2213 0.756
2        6   713 0.244
```

모든 도루 시도 중 도루 성공 비율은 2213 / (2213 + 713) = 0.756과 같습니다.

도루를 시도하는 일반적인 주자/아웃 상황은 무엇일까요? state 변수에 대한 빈도표를 구성하여 이에 답합니다.

- 5.10 추가 읽을거리 및 소프트웨어

Lindsey(1963)는 이 장에서 설명한 방식으로 플레이별 데이터를 분석한 최초의 연구자였습니다. Lindsey는 1959-60 시즌 동안 아버지가 수집한 데이터를 사용하여 각 주자/아웃 상황에 대해 이닝의 남은 시간 동안의 평균 득점을 제공하는 득점 기대값 행렬을 얻었습니다. Albert와 Bennett(2003)의 7장과 9장에서는 득점 기대값 행렬을 사용하여 다양한 안타의 가치를 측정하고 도루 및 희생번트의 이점을 평가하는 방법을 보여줍니다. Tango, Lichtman 및 Dolphin(2007)은 저서의 Toolshed 장에서 득점 기대값 표를 책 전체에서 사용되는 기본적인 도구 중 하나로 설명합니다. 또한 득점 기대값은 Keri 및 Baseball Prospectus(2007)의 에세이에서 중요한 역할을 합니다.

Benjamin S. Baumer, Jensen 및 Matthews(2015)는 선수에 대한 WAR(대체 선수 대비 승리기여도) 측정값을 계산하는 데 이러한 득점 기대값을 사용합니다. 웹사이트 http://www.fangraphs.com/library/misc/war/ 에서는 선수가 팀에 기여한 총 몫을 요약하는 유용한 방법인 WAR을 소개합니다.
