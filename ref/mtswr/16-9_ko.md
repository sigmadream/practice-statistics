# 시계열 평활화 및 필터링

시계열에서 측정 오차로 인해 발생하는 무작위 변동과 노이즈의 존재는 기본 데이터 생성 프로세스(DGP)를 모호하게 할 수 있습니다. 주요 시계열 구성 요소는 데이터에서 노이즈가 제거될 때까지 측정할 수 없습니다. 시계열 평활화 및 필터링 기술은 이러한 목표를 달성하는 데 도움이 됩니다. 이 기술들은 데이터에서 무작위 노이즈를 줄이고 기본 구조와 구성 요소("신호")를 드러냅니다.

이 장에서는 노이즈를 필터링하거나 평활화를 통해 줄이는 기술을 배웁니다. 이러한 기술은 관찰된 데이터에서 기저의 시계열 특성을 드러내는 데 매우 중요합니다.

- 9.5절: 호드릭-프레스콧(Hodrick-Prescott) 필터
- 9.6절: 칼만(Kalman) 필터

# 9.1 시계열 전처리 기술 비교

시계열 분해 기술(예: STL)은 시계열을 추세, 계절성 및 무작위 변동과 같은 구성 요소로 분리합니다. 분해 기술은 어떤 구성 요소도 제거하지 않고 분리 후 그대로 보존합니다. 시계열 평활화는 기본 패턴을 드러내기 위해 데이터에서 무작위 노이즈를 제거합니다. 시계열 필터링은 주파수 영역 또는 시간 영역 연산으로, 특정 주파수 구성 요소를 선택적으로 감쇠시키거나 제거하면서 다른 구성 요소는 보존합니다.

세 가지 기술 모두 측정 불가능한 복잡성(노이즈)을 줄여 시계열에서 의미 있는 정보를 추출하는 것을 목표로 합니다. 비슷한 결과를 내는 것처럼 보일 수 있지만 실제로는 시계열 분석에서 특정 목적, 용도 및 응용 분야를 가지고 있습니다. 표 9.1은 이러한 기술의 몇 가지 핵심 측면을 요약합니다.

| 측면 | 분해 | 평활화 | 필터링 |
|----|----|----|----|
| 주요 목표 | 시계열을 구성 요소(추세, 계절성, 순환, 불규칙성)로 분리 | 노이즈를 줄여 기본 패턴/추세를 드러냄 | 특정 주파수 구성 요소 제거 또는 분리 |
| 목적 | 진단적 | 설명적 | 무엇을 제거할지에 대한 규범적 |
| 출력 | 다중 구성 요소 시리즈 (T, S, C, R) | 단일 평활화된 시리즈 | 단일 필터링된 시리즈 또는 특정 구성 요소 |
| 접근 방식 | 가법 또는 승법 구성 요소로의 구조적 분해 | 국소적 평균화 | 주파수 선택적 변환 |
| 일반적인 방법 | 고전적 분해, STL, X-12-ARIMA | 가중 이동 평균, 지수 평활화, LOESS, 커널 평활화 | 이동 평균을 사용한 선형 필터링, 호드릭-프레스콧 필터, 칼만 필터 |
| 주파수 선택성 | 구성 요소 기반 (시간적 패턴 유형별 분리) | 비선택적 (모든 고주파수의 영향을 감소시킴) | 고도로 선택적 (특정 주파수 대역을 목표로 함) |
| 가역성 | 예, 구성 요소를 재결합할 수 있음 | 아니오, 평균화로 인한 정보 손실 | 부분적, 필터 유형에 따라 다름 |
| 보존되는 정보 | 식별 가능한 모든 구조적 구성 요소를 개별적으로 보존 | 변동성이 감소된 전체적인 형태 | 지정된 주파수 구성 요소만 보존 |
| 인과성 | 비인과적; 회고적 또는 사후 처리만 가능, 전체 시계열 필요 | 보통 비인과적; 대칭적 연산으로 과거(이전)와 미래(이후) 데이터 포인트 모두 필요; 일부 방법은 실시간 시나리오에 적용 가능 | 인과적일 수 있음(실시간 적용을 위해 과거와 현재 데이터만 사용), 또는 비인과적일 수 있음(대칭 필터를 위해 미래 데이터 포인트 사용) |

| 예시 | 계절이 판매에 미치는 영향 분석 | 연간 판매 검토, 장기 기후 변화 추세 파악, 과거 마케팅 캠페인 분석 | 고주파 거래 알고리즘, GDP에서 비즈니스 사이클 추출, 생체의학 신호 처리(ECG 분석), 이미지 및 모션 처리 |

표 9.1: 시계열 전처리 기술 비교

시계열 컨텍스트에서 평활화와 필터링이라는 용어는 종종 서로 바꿔서 사용됩니다. 필터가 주파수 영역에서 신호 대 잡음비를 분석하는 것을 광범위하게 지칭하는 반면, 평활화는 기저의 추세를 드러내기 위해 데이터에서 노이즈를 줄이는 것만을 의미합니다. 이동 평균에 기반한 방법은 필터링과 평활화 모두에 사용됩니다. 칼만 필터와 같은 고급 필터링 기술은 복잡하고 종종 비선형적인 시계열에서 무작위 노이즈를 필터링하는 데 일반적으로 사용됩니다.

<a href="Chapter_7.xhtml#h1_161" class="chapref">7장</a>에서는 일반적인 분해 및 이동 평균 기반 평활화 방법에 대해 논의했습니다. 이 장에서는 지수 가중 이동 평균 평활화 기술에 대해 논의할 것입니다. 필터링의 경우, 이동 평균을 사용한 선형 필터링, 호드릭-프레스콧 필터 및 칼만 필터를 다룰 것입니다. 그 중에서도 칼만 필터가 가장 진보된 기술입니다. 언급된 모든 기술을 단일 계열에 적용하여 각 방법의 결과를 비교하고 어떻게 작동하는지 분석하며, 이를 통해 무엇을 얻을 수 있는지 이해할 수 있도록 할 것입니다.

다음으로, 품질 관리에서 널리 사용되는 지수 가중 이동 평균 평활화 기술에 대해 논의할 것입니다.

# 9.2 지수 가중 이동 평균법 (EWMA)

7.6.1절과 7.6.2절에서 논의된 이동 평균 평활화는 이웃한 관측치들에 대해 평균을 내어 무작위 노이즈를 줄이는 방법을 보여주었습니다. 이 시나리오에서는 모든 관측치가 평활화되는 관측치와 얼마나 가깝거나 멀리 있는지에 관계없이 동일한 가중치를 부여받았습니다. 이동 평균 방법은 계열의 시작과 끝에서 정보가 손실된다는 점, 그리고 평균을 낼 최적의 관측치 수를 정하는 것이 주관적인 선택에 가깝다는 몇 가지 한계를 가지고 있습니다.

이동 평균은 시간 인덱스 <span class="image placeholder" data-original-image-src="../Images/B21040_09_005.png" data-original-image-title="">B21040_09_005.png</span>을 기준으로 과거(<span class="image placeholder" data-original-image-src="../Images/B21040_09_001.png" data-original-image-title="">B21040_09_001.png</span>,.., <span class="image placeholder" data-original-image-src="../Images/B21040_09_002.png" data-original-image-title="">B21040_09_002.png</span>)와 미래(<span class="image placeholder" data-original-image-src="../Images/B21040_09_003.png" data-original-image-title="">B21040_09_003.png</span>,…, <span class="image placeholder" data-original-image-src="../Images/B21040_09_004.png" data-original-image-title="">B21040_09_004.png</span>) 데이터 포인트 모두가 필요합니다. 이러한 정보가 항상 제공되는 것은 아니며, 특히 특정 기간이 지나자마자 노이즈를 줄여 기저 패턴을 분석하고자 할 때는 더욱 그렇습니다. 지수 가중 이동 평균(EWMA) 방법은 이러한 시나리오에 적용 가능합니다.

EWMA는 시계열에서 무작위 노이즈를 효과적으로 제거하고 변동을 부드럽게 하여 패턴을 드러냅니다. EWMA는 과거 값에 더 적은 가중치를 할당하고 최신 값에 더 높은 가중치를 부여합니다. 이제 다음 코드와 같이 세 가지 다른 평활화 매개변수 <span class="image placeholder" data-original-image-src="../Images/B21040_09_017.png" data-original-image-title="">B21040_09_017.png</span>, <span class="image placeholder" data-original-image-src="../Images/B21040_09_018.png" data-original-image-title="">B21040_09_018.png</span>, <span class="image placeholder" data-original-image-src="../Images/B21040_09_019.png" data-original-image-title="">B21040_09_019.png</span>을 사용하여 나일 데이터에 EWMA를 적용합니다:

```R
smooth_list <- list()
alpha_vec <- c(0.2, 0.4, 0.7)
for (i in seq_along(alpha_vec))
{
  smooth_list[[i]] <- ewmaSmooth(
    x = nile_dt$year,
    y  =nile_dt$flow,
    lambda = alpha_vec[i]
  )$y
}
names(smooth_list) <- paste0("alpha_",alpha_vec)

# 평활화된 계열 결합
nile_ewma <- nile_dt |>
  bind_cols(
    smooth_list |> bind_cols()
  )
```

EWMA는 정보 손실 없이 노이즈 제거하여 근본적인 패턴을 식별하는 데 유용합니다. 고차원 데이터를 다루는 능력 덕분에 EWMA는 알고리즘 트레이딩 신호를 생성하거나 변동성을 모델링하는 데 흔히 사용됩니다. 프로세스 관리 및 품질 관리는 프로세스 또는 제품의 효율성을 측정하기 위해 EWMA가 널리 사용되는 주요 분야입니다.

다음으로 시계열 필터링 기술에 대해 자세히 살펴보겠습니다.

# 9.3 시계열 필터링

일반적으로 필터라는 단어는 원치 않는 물질을 제거하기 위해 액체, 기체, 빛 또는 소리를 장치를 통과시키는 것을 의미합니다. 시계열 컨텍스트에서 필터링은 관찰된 계열을 수학적 연산에 통과시켜 특정 구성 요소를 제거하거나 강조하는 것을 포함합니다. 시계열 필터는 보통 특정 주파수의 패턴을 분리하는 데 사용됩니다.

시계열 필터링은 주파수 영역에서 적용되며 주된 목적은 다양한 주파수 길이에서 발생하는 패턴을 분리하는 것입니다. 예를 들어, 짧은 주파수의 순환(2-4년)에서 5-10년 기간에 걸쳐 발생하는 추세를 분리하는 것입니다. 일반적으로 시계열 필터링은 관찰된 현상을 설명하고 분석하는 데 주로 사용됩니다. 칼만 필터와 같은 일부 고급 필터링 기술은 예측 모델에도 사용되기는 합니다.

시계열 평활화는 단기 변동을 제거하는 데 중점을 두며, 유한 임펄스 응답(FIR) 필터라고도 합니다. 반면 시계열 필터링은 장기 변동을 제거하며 기술적으로 무한한 수의 관측치를 가지고 무한 임펄스 응답(IIR) 필터로 알려져 있습니다.

시계열 필터링은 시간적 의존성이 매개변수를 사용하여 명시적으로 모델링되는 정교한 수학적 연산입니다.

## 9.3.1 나이퀴스트 주파수 및 샘플링 고려 사항

시계열 분석에서 데이터는 일정한 간격(예: 매일, 매월 또는 매 분기)으로 수집됩니다. 이러한 간격을 샘플링 주파수라고 합니다. 주파수 영역 분석에서 시계열로부터 추출할 수 있는 정보는 나이퀴스트 주파수에 의해 제어되며, 이는 샘플링 속도의 절반에 해당합니다.

<span class="image placeholder" data-original-image-src="../Images/B21040_09_023.png" data-original-image-title="">B21040_09_023.png</span>

임의의 이산 시계열에 대해 특정 주파수 주기에서 변동/패턴을 확인하려면 데이터 수집(샘플링) 주파수가 해당 주기의 최소 두 배가 되어야 합니다.

예를 들어, 일일 시계열은 하루 중 사이클을 포착할 수 없으며 그러한 사이클을 감지하려면 최소 이틀의 관측치가 필요합니다. 연간 계열(<span class="image placeholder" data-original-image-src="../Images/B21040_09_024.png" data-original-image-title="">B21040_09_024.png</span>)은 데이터에 분기별 패턴(<span class="image placeholder" data-original-image-src="../Images/B21040_09_025.png" data-original-image-title="">B21040_09_025.png</span>)이 있는 경우 충분한 정보를 제공할 수 없습니다. 연간 계열은 샘플링 속도가 느리기 때문에 분기별 추세를 완전히 놓치게 됩니다. 더 낮은 주파수(<span class="image placeholder" data-original-image-src="../Images/B21040_09_027.png" data-original-image-title="">B21040_09_027.png</span>)에서 발생하는 패턴을 감지하려면 더 높은 주파수(예: <span class="image placeholder" data-original-image-src="../Images/B21040_09_026.png" data-original-image-title="">B21040_09_026.png</span>로 매월)로 샘플링해야 합니다.

이 요구 사항은 신호 처리에서 잘 알려진 문제인 에일리어싱(aliasing)을 제거합니다. 에일리어싱은 신호가 최고 주파수 성분의 두 배보다 낮은 속도로 샘플링될 때 발생하는 신호의 왜곡입니다.

정확한 표현을 보장하기 위해서는, 연구 중인 비즈니스 사이클이나 경제 지표에 존재하는 주기적 동작을 포착할 수 있을 만큼 충분히 높은 샘플링 주파수를 선택하는 것이 필수적입니다. 이러한 동작은 해당 주파수나 사이클 길이에 의해 정의됩니다:

- 낮은 주파수는 일반적으로 추세나 2-5년의 비즈니스 사이클과 같은 장기적인 움직임을 나타냅니다.
- 높은 주파수는 계절성이라고 부르는, 분기별 및 월별 데이터에서 발견되는 연간 사이클과 같이 더 짧고 빠른 움직임을 나타냅니다.

시계열 필터링 기술은 시계열 내의 특정 주파수 범위를 필터링하고 다른 범위는 감쇠시킵니다. 필터의 특성은 다음과 같습니다:

- 저역 통과 필터 (Low-pass filter): 데이터의 더 높은 주파수를 감쇠시키고 더 낮은 주파수만 통과시키는 필터입니다. 추세를 분리하는 데 이상적입니다.
- 고역 통과 필터 (High-pass filter): 낮은 주파수를 감쇠시키고 높은 주파수를 통과시키는 필터로 단기 및 장기 비즈니스 사이클을 분리하는 데 사용됩니다.
- 대역 통과 필터 (Band-pass filter): 특정 주파수 대역 내의 주파수만 통과시키는 필터입니다.

대부분의 시계열 필터는 백색 잡음 항을 최대한 평활화한다는 이동 평균 개념을 기반으로 합니다. 각각의 장단점이 있는 다양한 시계열 필터링 기술을 문헌에서 찾을 수 있습니다. 시계열 분석, 특히 비즈니스 및 경제 시계열 맥락에서 널리 응용되는 다음 세 가지를 포함합니다:

- 이동 평균을 사용한 선형 필터링: 과거의 노이즈를 평활화하여 기저 패턴을 분리하는 유한 임펄스 응답 필터
- 호드릭-프레스콧 필터: 시계열에서 추세와 사이클 및 무작위 노이즈를 분리하는 무한 임펄스 응답 필터의 유한 근사
- 칼만 필터: 관찰된 계열을 참인 기저 데이터 생성 프로세스의 시스템으로 간주하고 여러 소스에서 발생하는 노이즈를 처리할 수 있는 일반적이고 다재다능한 필터

다음 섹션에서 이동 평균을 사용한 선형 필터링부터 시작해 보겠습니다.

# 9.4 이동 평균(MA)을 사용한 선형 필터링

이동 평균(MA) 모델에서는 시계열의 현재 값이 과거의 백색 잡음 또는 오차 항의 선형 조합이라고 가정합니다. MA(<span class="image placeholder" data-original-image-src="../Images/B21040_09_028.png" data-original-image-title="">B21040_09_028.png</span>) 모델은 시계열의 시간적 의존성이 이전 <span class="image placeholder" data-original-image-src="../Images/B21040_09_029.png" data-original-image-title="">B21040_09_029.png</span>개 오차 항에 따라 달라진다고 봅니다.

<span class="image placeholder" data-original-image-src="../Images/B21040_09_030.png" data-original-image-title="">B21040_09_030.png</span>

여기서 <span class="image placeholder" data-original-image-src="../Images/B21040_09_031.png" data-original-image-title="">B21040_09_031.png</span>은 백색 잡음 항이고, <span class="image placeholder" data-original-image-src="../Images/B21040_09_032.png" data-original-image-title="">B21040_09_032.png</span>는 MA 계수입니다.

우리는 이미 시계열 데이터를 평활화하기 위해 MA 기술을 적용한 적이 있습니다. 이 MA 모델이 이전과 어떻게 다를까요? 기술적으로 방정식 (9.2)는 일반적인 버전이며, 여러분이 본 다른 모든 이동 평균은 그 특수한 응용입니다. 예를 들어, <span class="image placeholder" data-original-image-src="../Images/B21040_09_033.png" data-original-image-title="">B21040_09_033.png</span> 이고 <span class="image placeholder" data-original-image-src="../Images/B21040_09_034.png" data-original-image-title="">B21040_09_034.png</span> 인 경우, 이는 동일한 가중치를 갖는 3일 이동 평균과 같습니다.

`stats` 패키지의 `filter()` 함수는 MA 선형 필터링을 수행하는 기능을 제공합니다. `stats` 패키지는 R과 함께 기본으로 로드되는 패키지입니다. 하지만 `dplyr` (또는 `tidyverse`)가 이미 로드된 경우, 동일한 이름의 함수와의 충돌을 피하기 위해 네임스페이스를 통해 호출하는 것이 좋습니다.

`stats::filter()` 함수에서는 계수의 값을 가진 길이 <span class="image placeholder" data-original-image-src="../Images/B21040_09_035.png" data-original-image-title="">B21040_09_035.png</span>인 벡터를 전달해야 합니다. 예를 들어 3개의 <span class="image placeholder" data-original-image-src="../Images/B21040_09_036.png" data-original-image-title="">B21040_09_036.png</span>으로 구성된 벡터는 동일한 가중치로 3-MA를 적용하는 것과 동일합니다. 인수 `method=convolution`은 이동 평균 필터링을 보장하고, `sides`는 과거 관측치(`sides=1`)를 사용할지 양쪽 값(`sides=2`)을 사용할지 제어합니다. 다음 코드에서는 나일 데이터에 MA가 있는 두 개의 선형 필터가 적용됩니다:

- MA(2): <span class="image placeholder" data-original-image-src="../Images/B21040_09_037.png" data-original-image-title="">B21040_09_037.png</span> 이고 가중치가 <span class="image placeholder" data-original-image-src="../Images/B21040_09_038.png" data-original-image-title="">B21040_09_038.png</span> 및 <span class="image placeholder" data-original-image-src="../Images/B21040_09_039.png" data-original-image-title="">B21040_09_039.png</span> 이며 현재 값에서 멀어질수록 오차에 더 작은 가중치가 할당됨
- MA(3): 세 개의 계수 각각에 1/3씩 동일한 가중치 부여.

```R
ma_filter <- nile_dt |>
  mutate(
    "MA(2)" = stats::filter(
      flow,
      filter = c(0.6,0.4),
      method="convolution", sides = 1
    ),
    "MA(3)" = stats::filter(
      flow,
      filter = rep(1/3,3),
      method = "convolution", sides = 1
    )
  )
```

비즈니스 응용 프로그램에서 이동 평균 평활화와 이동 평균 필터링의 차이는 주로 분석 시기에 따라 달라집니다: 오프라인 후향적 분석 대 실시간 진행 상황 모니터링입니다. 데이터 가용성 측면에서 필터링은 순차적으로 도착하는 데이터가 필요하며 신속하게 결정해야 합니다(예: 주식 거래 알고리즘). 평활화의 경우 모든 결과를 관찰할 수 있도록 전체 데이터셋이 제공되어야 합니다(예: 연간 판매 리뷰).

이전에는 시계열을 구성 요소로 분리하기 위해 STL 분해를 사용했습니다. 다음 섹션에서는 시계열에서 추세와 순환을 분리하는 데 사용되는 호드릭-프레스콧 필터에 대해 알아봅니다.

# 9.5 호드릭-프레스콧 필터

시계열 구성 요소 중 추세와 순환은 종종 서로 얽혀 있습니다. 이 두 구성 요소의 실제 발생을 관찰하려면 더 긴 기간이 필요합니다. 비즈니스 사이클은 일반적으로 2-8년 주기로 작동하여 장기적인 추세를 중심으로 변동을 만듭니다. 반면에 추세가 매우 강할 때는 주기적인 패턴을 지배할 수 있어 특정 분해 기술 없이는 감지하기 더 어렵습니다.

호드릭-프레스콧(HP) 필터(Hodrick et al., 1997)는 주파수 영역 분석 개념을 적용하여 관찰된 계열에서 추세와 순환을 분리합니다. 이것은 고역 통과 필터로, 저주파수 움직임을 감쇠시킴으로써 고주파수 구성 요소를 보존한다는 의미입니다. HP 필터는 추정된 추세로부터의 변동을 최소화하여 이를 달성합니다.
