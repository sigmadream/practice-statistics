# 이상 탐지 및 대체 (Anomaly Detection and Imputation)

이상치(Anomalies 또는 outliers)는 일반적으로 짧은 기간 동안 관찰된 체계적인 패턴에서 갑작스러운 편차를 일으키는 시계열의 이벤트입니다. 이는 장비 고장, 기상 이변 또는 전염병과 같은 다양한 원인에서 발생할 수 있습니다. 변화점(Changepoints, <a href="Chapter_16.xhtml#h1_346" class="chapref">Chapter 16</a>에서 논의됨)은 기본 데이터 생성 프로세스에 지속적인 변화를 만듭니다. 반면 이상치는 단일 관측치 또는 일련의 관측치에서 나타나는 갑작스러운 편차이며, 그 이후에는 장기적인 체계적 동작이 변하지 않고 유지됩니다.

특정 상황에서는 이상치를 그럴듯한 값으로 대체하는 것이 더 나은 접근 방식입니다. 특히 통제할 수 없고 반복될 가능성이 없는 알려진 이유로 발생할 때 그렇습니다. 예를 들어, 일회성 데이터베이스 마이그레이션 중 고객 불만이 급증하거나 유명 인사의 음악 투어 중 우정 팔찌 판매가 급증하는 경우가 있습니다.

데이터에서 이상치를 완전히 제거하는 것은 일반적으로 권장되지 않는데, 이는 이상치에 종종 중요한 이벤트나 시스템 실패에 대한 가치 있는 정보가 포함되어 있기 때문입니다. 이를 버리면 의사 결정자가 새로운 위험이나 고유한 기회를 의미할 수 있는 진정한 중단 상황을 파악하지 못하게 될 수 있습니다. 게다가 이러한 관측치를 단순히 제외하면 신중한 방법으로 채우지 않는 한 분석을 어렵게 만드는 시계열 공백이 남게 됩니다. 따라서 이 장에서는 시간적 구조를 보존하기 위해 이상치를 탐지하고 누락된 값을 대체하는 이중의 과제를 탐구합니다.

시계열의 이상 탐지는 횡단면 데이터에 비해 고유한 과제를 제시하는데, 그 이유는 정상(normal) 동작이 추세-주기 및 계절성 패턴을 통해 진화하기 때문입니다. 효과적인 방법은 이러한 예상되는 기준선 변동과 진정한 이상치를 구분할 수 있어야 합니다. 이 장에서는 이러한 과제를 해결하기 위한 다양한 기법을 다루고 각각의 장점과 한계를 강조합니다. 이러한 방법의 개념적 배경을 이해하면 올바른 도구를 선택하여 정보에 입각한 결정을 내리고 복잡한 비즈니스 문제를 해결할 수 있습니다.

# 17.1 시계열의 이상 탐지

시계열의 이상 탐지는 데이터 수집 프로세스의 맥락에서 예상되는 동작이나 정의된 정상(normality)으로부터의 편차를 식별하는 데 중점을 둡니다. 편차는 단일 시점에서 발생하거나 일련의 시점에 걸쳐 지속될 수 있습니다. 이상치 식별은 엄격한 분석에 필수적입니다. 이상치가 존재하면 통계적 측정값을 왜곡하고 추세와 계절성의 추출 및 모델링을 손상시키며 예측 성능을 저하시킬 수 있습니다. 이러한 이상치를 탐지함으로써 분석의 무결성을 보호하고 노이즈를 줄이며 기본 패턴을 더 잘 이해할 수 있습니다. 효율적인 탐지는 부정적인 영향을 통제하고 비즈니스 결정을 강화할 수 있게 하여 이러한 잠재적인 장애물을 전략적 이점으로 변환합니다.

시계열 이상치는 일반적으로 두 가지 주요 범주로 나뉩니다.

- 점 이상치(Point anomalies): 예상 패턴에서 벗어나는 단일하고 고립된 관측치
- 집단 이상치(Collective anomalies): 관찰된 패턴과 비교할 때 함께 비정상적인 동작을 구성하는 일련의 관측치

효과적인 시계열 이상 탐지는 시간적 의존성과 복잡한 기본 패턴을 모두 고려해야 합니다. 이상치를 예상 기준선에서의 편차로 정의하는 것은 본질적으로 어렵습니다. 왜냐하면 기준선 자체도 이상치의 존재로 인해 왜곡될 수 있기 때문입니다. 정상(normal)을 구성하는 것에 대한 맥락이 도메인별 지식을 통해 확립되지 않고 데이터 자체에서만 파생되는 상황에서는 이러한 과제가 더욱 증폭됩니다.

이 장에서는 두 가지 이상 탐지 방법을 다룹니다.

- LOESS를 사용한 계절성-추세 분해(STL) 기반 탐지: 시계열 구성 요소를 분리하여 이상치를 식별하는 분해 접근 방식입니다.
- 고립 숲(Isolation forest): 시계열 이상 탐지에 맞게 조정된 앙상블 머신러닝 방법입니다.

각 방법은 특정 시나리오에 대해 고유한 이점을 제공합니다. 실제 비즈니스 문제에 이상 탐지를 효과적으로 적용하기 위해 기초와 실무적 고려 사항에 대해 배우게 됩니다. 다음 섹션에서는 STL 기반 방법부터 시작하겠습니다.

# 17.2 STL 분해 기반 이상 탐지

STL은 <a href="Chapter_7.xhtml#h1_161" class="chapref">Chapter 7</a>에서 다루었습니다. 추세, 계절성 및 나머지(remainder)와 같은 구성 요소로 시계열을 분리하기 위한 강력한 프레임워크를 제공합니다. 잘 알려진 이 분해 기술은 시계열 이상 탐지에도 사용될 수 있습니다. STL은 기본 모델 가정에서 자유롭고, 어떤 유형의 계절성도 처리할 수 있으며, 시간이 지남에 따라 진화하는 계절성 패턴을 포착할 수 있고, 가장 중요하게는 이상치에 강건합니다. 이 방법은 데이터에서 추출된 기본 패턴을 유지하면서 다양한 구성 요소의 이상치를 식별할 수 있습니다.

이전 장에서는 `fable` 패키지의 STL 구현을 사용했습니다. 그러나 이 장에서는 나중에 이상치를 탐지하는 데 사용할 `anomalize` 패키지에서 채택된 tidy 워크플로우와 일관성을 유지하기 위해 `stats::stl()` 함수를 사용합니다.

계절성 구성 요소는 `s.window = "periodic"` 인수를 사용하여 연도에 걸쳐 동일한 계절성 영향이 있다고 가정하여 추정됩니다. `robust=TRUE` 옵션은 데이터에 이상치가 있더라도 구성 요소가 추출되도록 보장합니다. 다음 코드를 사용하여 가스 데이터에 STL 분해를 피팅하고 분해 플롯을 생성할 수 있습니다.

```r
astsa::gas |>
  stats::stl(s.window = "periodic", robust = TRUE) |>
  autoplot()
```

가스 계열에 이상치가 있는지 조사해 보겠습니다. 먼저 다음 코드 스니펫에 표시된 것처럼 데이터를 `tibble` 형식으로 변환해야 합니다.

```r
gas_tbl <- astsa::gas %>%
  as_tsibble() |>
  mutate(date = as.Date(index)) |>
  as_tibble() |>
  dplyr::select(-index, gas_price = value)
```

다음으로 이상 탐지 프로세스는 다음과 같이 `anomalize` 패키지의 세 가지 함수를 적용하여 진행됩니다.

- `time_decompose()` 함수는 빈도 인수와 함께 원래 시계열을 분해합니다.
- 그런 다음 나머지 항 <span class="image placeholder" data-original-image-src="../Images/B21040_17_021.png" data-original-image-title="">B21040_17_021.png</span>에 대한 이상 탐지는 `anomalize()` 함수에 `method="iqr"` 인수를 설정하여 IQR 기반 방법을 사용하여 수행됩니다.
- 마지막으로 `time_recompose()` 함수는 예상 관측치에서 이상치의 임계값을 분리하는 방식으로 작동하여 각 관측치에 대한 하한과 상한을 만듭니다.

다음 코드 스니펫은 프레임워크가 어떻게 작동하는지 보여줍니다.

```r
gas_anomalies_in_resid <- gas_tbl %>%
  time_decompose(gas_price, frequency = 52) %>%
  anomalize(remainder, method = "iqr", alpha = 0.15/3) |>
  time_recompose()
```

STL 기반 이상 탐지 방법의 장점은 다음과 같습니다.

- 구성 요소를 분리하여 시계열의 자연스러운 구조를 존중합니다.
- 계절성, 추세 또는 나머지 구성 요소에서 개별적으로 이상치를 탐지할 수 있습니다.
- 진화하는 계절성 패턴과 추세에 강건합니다.
- 이상치를 포함하는 구성 요소를 표시하여 해석 가능한 결과를 제공합니다.
- 다른 방법이 고군분투할 수 있는 강력한 계절성 패턴에 잘 작동합니다.

그러나 언급할 만한 이 방법의 몇 가지 한계가 있습니다.

- 사전에 계절성 기간을 지정해야 합니다.
- 다른 빈도를 가진 다중 계절성 패턴으로 인해 고전할 수 있습니다.
- 성능은 STL 분해를 위한 적절한 파라미터 선택에 의존합니다.
- 계절성 주기가 제한된 짧은 시계열의 경우 효과가 떨어집니다.
- 구성 요소 간의 복잡한 상호 의존성을 포착하지 못할 수 있습니다.

다음으로 이상 탐지를 위한 머신러닝 기반 접근 방식에 대해 배울 것입니다.

# 17.3 고립 숲(Isolation forest) 기반 이상 탐지

고립 숲(Liu et al., 2008)은 이상치가 종종 비정상적이지 않은 관측치보다 격리하기 더 쉽다는 원칙에 기반한 앙상블 기반 이상 탐지 알고리즘입니다. 이 방법은 원래 고차원 횡단면 데이터를 위해 설계되었습니다. 그러나 알고리즘에 시간적 특징(temporal features)과 맥락 정보를 통합하여 시계열에 맞게 조정할 수 있습니다.

직관적으로 단순하지만 영리한 이 알고리즘은 무작위 고립 트리의 숲을 만듭니다. 각 트리는 데이터를 무작위로 분할하며 이상치는 일반적으로 격리하기 위해 더 적은 파티션을 필요로 합니다. 이상 점수는 각 관측치를 격리하는 데 필요한 평균 경로 길이(path length)에서 파생됩니다.

# Create features for time-series context
create_features <- function(ts_data, win_wid) {
  n <- length(ts_data)
  X <- matrix(NA, nrow = n - win_wid + 1,
                     ncol = win_wid + 7)
  for (i in win_wid:n) {
    win_data <- ts_data[(i - win_wid + 1):i]
    row_idx <- i - win_wid + 1
    # Window values
    X[row_idx, 1:win_wid] <- win_data
    holtPars <- holt_parameters(win_data)
    # Additional cross Mean, SD, Max and Min respectively
    X[row_idx, win_wid + 1] <- crossing_points(win_data)
    X[row_idx, win_wid + 2] <- entropy(win_data)
    X[row_idx, win_wid + 3] <- holtPars["alpha"]
    X[row_idx, win_wid + 4] <- holtPars["beta"]
    X[row_idx, win_wid + 5] <- lumpiness(win_data)
    X[row_idx, win_wid + 6] <- nonlinearity(win_data)
    X[row_idx, win_wid + 7] <- tsfeatures::stability(win_data)
  }
  # Assign column names to X
  colnames(X) <- c(
    paste0("lag_", (win_wid - 1):0),
    "xpoints", "entropy", "holt_1", "holt_2",
    "lumpiness",  "nonlinearity", "stability")
  return(as.data.frame(X))
}
