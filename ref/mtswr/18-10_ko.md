# 예측의 기본

예측 모델은 관측치의 순서가 중요한 시계열 데이터를 위해 특별히 설계되었습니다. 시계열 모델링에서는 고유한 시간 종속성이 유지되어야 합니다. 교차 단면 데이터에 일반적으로 사용되는 예측 모델은 데이터의 시간 종속성을 존중하고 적절하게 다룰 때 예측에 사용할 수 있습니다. 통계 모델에서 초점은 변수 간의 기존 관계를 얼마나 잘 설명할 수 있는지에 맞춰져 있으며, 이는 추정된 파라미터에 포착됩니다. 이러한 파라미터에 대해 수행된 통계 검정은 모델링 가정의 타당성을 평가하고 식별된 관계의 지속성에 대한 확신을 제공합니다.

대조적으로 머신러닝이나 딥러닝 모델은 특정한 모델링 가정에 의존하지 않습니다. 대신 이러한 모델은 변수 간의 기저 관계를 설명할 필요 없이 정확한 예측을 수행하는 것을 목표로 합니다. 트리 기반 모델과 같은 일부 머신러닝 모델은 어떤 형태의 특성 상호작용과 관계를 포착하긴 합니다.

# 10.2 예측 워크플로우

중앙집중형 워크플로우는 예측 문제에 사용되는 모델링 접근 방식과 방법론의 일관성을 보장합니다. 이는 결과의 통일성을 가져오며 여러 모델을 데이터셋에 적용할 때 쉽게 비교할 수 있게 해줍니다.

비즈니스 예측 문제에 대한 솔루션을 개발할 때는, 프로젝트 시작부터 예측의 모든 측면을 포괄하는 프로세스를 간소화하기 위한 워크플로우를 채택해야 합니다. 예측 워크플로우를 채택함으로써, 협업을 강화하고 효율성을 높이며 일관성을 유지하고 개념 증명에서 프로덕션까지 짧은 시간 안에 모델을 배포할 수 있습니다. 최소한의 예측 워크플로우에는 다음 단계가 포함됩니다. 당면한 문제에 따라 더 세분화된 단계를 추가할 수 있습니다.

1. 데이터 정리 (Tidy data)
2. 시각화
3. 예측 모델 구축
4. 모델 성능 확인
    - 잔차 진단
    - 모델 적합도 평가
5. 예측 생성
6. 예측 정확도 측정
7. 시계열 교차 검증을 통한 예측 일반화 가능성 확인

데이터 클리닝 및 변환, 그리고 전문적인 시각화를 통해 모델링을 위한 정리된 시계열을 생성하는 방법은 <a href="Chapter_5.xhtml#h1_129" class="chapref"> 5장 </a>에서 배웠습니다.

이 장에서는 세 가지 간단한 예측 방법을 논의하면서 앞선 워크플로우의 3~7단계를 반복적으로 시연합니다. 이는 예측 모델을 구축하는 동안 모범 사례를 도입하는 습관을 기르도록 돕기 위함입니다. 모델 적합도 평가는 뒤이은 장들에서 고급 통계 예측 모델을 제시할 때 논의합니다.

당면한 과제에 적합한 도구를 사용하면 효율성과 성공을 보장할 수 있습니다. 종단간 예측 분석을 실행하는 데 도움이 될 두 R 패키지의 함수들을 간단히 살펴보겠습니다.

# 10.3 예측을 위한 fable

fable은 도덕적 교훈을 가르치는 이야기 모음이며, 도덕(moral)이라는 용어는 옳고 그른 행동의 원칙에 해당합니다. 시계열 데이터에서 예측 이야기를 엮어낼 때, 예측 워크플로우를 채택하여 올바른 구조를 고수하는 것이 필수적입니다. 우화(fable)와 유사하게 R 패키지인 `fable`과 `fabletools`는 공유된 예측 원칙과 워크플로우에 기반하여 개발된 함수들의 모음입니다.

`fable` (정리된 시계열을 위한 예측 모델) (O'Hara-Wild et al., 2023)과 `fabletools` (fable 프레임워크 내 패키지들을 위한 핵심 도구) (O'Hara-Wild et al., 2021) 패키지는 단변량 및 다변량 시계열 예측 모델을 위한 중앙 집중식 프로세스와 인터페이스를 제공합니다. `fable` 패키지는 모델을 적합시키는 함수들을 포함하고, `fabletools`는 시계열 모델링 및 분석을 위한 통합 워크플로우를 제공합니다.

이 두 패키지의 함수는 `tidyverse` 워크플로우와 일관된 형식을 따릅니다. 이들은 예측 모델 추정, 비교, 결합, 시각화, 일관된 프레임워크 내에서의 예측 생성을 위한 도구들을 제공합니다.

`fable`의 개별 모델 함수는 전용 섹션에서 논의될 것입니다. 다음은 예측 모델링에서 자주 사용할 `fabletools` 패키지의 주요 함수 목록입니다.

- `model()` : 단일 시계열에 모델을 적합시킵니다. 단일 시계열에 여러 모델을 적용하거나 여러 시계열에 여러 모델을 적용하도록 확장할 수 있습니다.
- `coef()` 또는 `tidy()` : 적합된 모델에서 계수를 추출합니다.
- `glance()` : 잔차 분산, 정보 기준, 표본 내 예측 오차를 포함하여 각 적합된 모델에 대한 한 줄 요약을 제공합니다.
- `report()` : 단일 모델 적합에 대한 상세 정보를 반환합니다.
- `fitted()` : 표본 내 적합값을 반환합니다.
- `residuals()` : 적합된 모델에서 잔차를 반환합니다.
- `augment()` : 적합값과 잔차가 포함된 원본 시계열을 제공합니다.
- `accuracy()` : 적합된 모델에 대한 일반적인 정확도 지표를 반환합니다.
- `forecast()` : 모델 적합에서 직접 점 예측과 예측 분포를 생성합니다.
- `hilo()` : 예측 분포에서 여러 예측 구간을 한 번에 추출합니다.
- `generate()` : 모델에서 시뮬레이션 경로를 생성합니다.
- `equation()` : 모델의 수식을 표시합니다.

다음과 같이 특정 모델에서 지원되며 프로덕션 워크플로우에 더 적합한 함수도 있습니다.

- `refit()` : 새 데이터로 모델을 업데이트합니다.
- `stream()` : 모델을 다시 적합시키는 전체 프로세스를 우회하여 새 데이터를 제공해 모델 적합을 확장합니다.
- `interpolate()` : 시계열의 누락된 값을 보간합니다.
- `components()` : 적합된 모델에서 다양한 성분을 추출합니다.

이러한 함수 대부분은 이 책 전반에 걸쳐 사용됩니다. 예측 워크플로우는 간단한 방법을 사용하여 제시할 때 이해하기 더 쉽습니다. 다음 섹션에서는 단순 예측 기법부터 시작하겠습니다.

# 10.4 단순 예측 기법

단순(Naïve) 기법은 다가올 기간에 대한 예측으로 가장 최근에 관측된 값을 사용합니다. 이 접근법은 시계열의 현재 관측치에 모든 가중치를 할당합니다. 무작위 행보 예측이라고도 불리는 이 방법은 본질적으로 마지막 관측치를 다음 기간의 예측으로 복제합니다. 이는 기저의 데이터 생성 과정에 대한 지식이 거의 없거나 전혀 없을 때 비계절성 시계열에 대해 가장 간단한 방법입니다.

WWWusage 시계열에는 뚜렷한 추세나 계절성이 없습니다. 서버에 합류한 인터넷 사용자 수는 강한 불규칙성을 보이며 일관되지 않았고 <span class="image placeholder" data-original-image-src="../Images/B21040_10_040.png" data-original-image-title="">B21040_10_040.png</span> 번째 분 이후 사용자가 유입되었습니다. 단순 기법은 뚜렷한 추세나 계절성이 없는 데이터나 무작위 행보 패턴을 보이는 데이터에 대해 강력한 기준(baseline) 예측을 제공합니다.

원본 데이터를 모델 개발 및 성능 평가에 각각 사용되는 훈련 세트와 테스트 세트로 나누는 것이 표준 관행입니다. 시계열의 경우 두 가지 방법으로 이를 수행할 수 있습니다.

- 원본 시계열의 일정 비율을 테스트 세트로 따로 남겨둡니다: `rsample` 패키지의 `initial_time_split()` 함수를 이런 분할에 사용할 수 있습니다.
- 특정 시점에서 훈련 세트와 테스트 세트를 분할합니다: `filter()` 또는 `filter_index()` 함수가 이 작업을 수행합니다.

다음 코드를 사용하여 인터넷 사용 데이터에서 관측치의 <span class="image placeholder" data-original-image-src="../Images/B21040_10_041.png" data-original-image-title="">B21040_10_041.png</span> 를 훈련용으로 따로 떼어놓고 나머지 <span class="image placeholder" data-original-image-src="../Images/B21040_10_042.png" data-original-image-title="">B21040_10_042.png</span> 를 테스트 세트로 설정해 봅시다.

netuse_split <- initial_time_split(netuse, prop = 0.95)
netuse_split
