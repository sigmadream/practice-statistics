# 8.1 시계열 특성

추세, 계절성, 주기 및 나머지 성분은 관측된 시계열을 정의하고 근본적인 데이터 생성 과정에 대한 통찰력을 제공합니다. 평균, 분산, 자기상관과 같은 다른 속성은 시계열에서 계산되며 관측된 시스템에 대한 정보를 제공합니다. 두 시계열의 평균과 분산을 비교하여 모집단 분포에 대해 설명할 수 있듯이, 추세의 강도나 타일링 윈도우 분산과 같은 시계열 특성도 비슷한 방식으로 여러 시계열을 비교하는 데 사용될 수 있습니다.

즉, 시계열 특성은 시계열의 특정 값과 무관한 방식으로 시계열의 특징을 정량화하는 데 사용할 수 있습니다. 이를 통해 측정 척도나 단위가 다르더라도 서로 다른 시계열을 비교할 수 있습니다.

예를 들어, 추세 강도 특성을 사용하여 두 판매 시계열을 비교할 수 있습니다. 추세 강도가 높으면 판매가 더 빠르게 증가하거나 감소하고 있음을 의미합니다. 또한 타일링 윈도우 분산 특성을 사용하여 두 시계열의 변동성을 비교할 수도 있습니다. 타일링 윈도우 분산이 높으면 시계열의 값들이 더 넓게 퍼져 있음을 의미합니다.

시계열 특성을 비교함으로써 다양한 시계열 간의 유사점과 차이점을 더 잘 이해할 수 있습니다. 이는 예측, 이상 탐지, 시계열 분류와 같은 다양한 작업에 유용할 수 있습니다.

`feasts`(Feature Extraction and Statistics for Time Series의 약자) 패키지(O’Hara-Wild 등, 2023)는 시계열 데이터에 대한 특성 계산 모음을 제공합니다. 이전 장에서 이미 이 패키지의 `ACF()`, `gg_season()`, `gg_subseries()` 등의 함수를 사용해 본 적이 있을 것입니다.

`feasts` 패키지에서 계산된 특성과 통계는 설명과 사용 목적을 위해 다음과 같은 여러 그룹으로 나눌 수 있습니다.

- 자기상관 기반 특성
- STL 기반 특성
- 타일링 윈도우 특성
- 슬라이딩 윈도우 특성
- 통계적 검정 기반 특성
- 통계적 요약 기반 특성
- 기타 유용한 특성

이 장의 예제에서 대부분의 특성은 기본 매개변수를 사용하여 계산되며 필요한 경우 최적화됩니다. 하지만 이러한 인수들을 테스트하고 데이터와 사용 사례에 맞는 최적의 설정을 찾을 수 있습니다. 중요한 부분은 이러한 특성들이 제공하는 이점이 무엇인지, 어떻게 적절하게 사용할지 이해하는 것입니다.

시계열 데이터에서 특성 집합을 계산하는 방법을 배우는 것과 더불어, 이를 해석하고 적절하게 사용하는 방법도 알고 싶을 것입니다. 이를 위해 GitHub 리포지토리의 `data/data_chap8` 폴더에 있는 `abs_retail` 데이터에서 두 가지 예제 시계열을 사용하겠습니다. 데이터를 R 워크스페이스에 로드하고 두 시계열을 필터링하여 구성해 봅시다.

```
# load data
abs_retail <- read_rds("data/data_chap8/abs_retail.rds")

retail_df <- abs_retail |>
  filter(
    state == "Victoria",
    industry %in% c("Department stores", "Supermarket and grocery stores")
  ) |>
  mutate(
    industry = ifelse(
      industry == "Supermarket and grocery stores",
      "Supermarket stores", industry)
  ) |>
  filter_index("2000 Jan" ~ "2022 Dec") |>
  select(industry, month, turnover)
```

# 8.2 통계적 요약 기반 특성

데이터 분석에서 특성에 대해 이야기할 때 먼저 떠오르는 것은 평균, 분산, 분위수 등과 같은 기술 통계입니다. `feasts` 패키지의 `features()` 함수를 적용하여 이러한 특성을 계산할 수 있습니다.

백화점과 슈퍼마켓/식료품점이라는 두 산업의 관측된 매출액에서 평균과 분산을 계산해 보겠습니다.

```
stat_feat <- retail_df |>
  features(turnover, list(mean=mean, var=var))

stat_feat
```

결과는 다음 출력과 같이 나타납니다.

```
# A tibble: 2 × 3
  industry            mean     var
  <chr>              <dbl>   <dbl>
1 Department stores   356.  11900.
2 Supermarket stores 1751. 305344.
```

분위수 특성은 시계열을 동일한 확률을 가진 연속 구간으로 나누는 절단점을 제공합니다. 다음과 같이 분위수 특성을 계산할 수 있습니다.

```
quant_feat <- retail_df |>
  features(turnover, quantile)

quant_feat
```

분위수 기반 특성은 다음 출력을 생성합니다.

```
# A tibble: 2 × 6

  <chr>              <dbl> <dbl> <dbl> <dbl>  <dbl>
1 Department stores   170.  298.  334.  370.   763.
2 Supermarket stores  886  1266. 1676. 2149.  3278.
```

통계적 요약 기반 특성은 관측된 시계열의 척도 및 분포에 대한 정보를 제공합니다. 슈퍼마켓은 백화점에 비해 훨씬 큰 규모로 운영됩니다. 슈퍼마켓 시계열의 평균 매출액은 상당히 높았고(<span class="image placeholder" data-original-image-src="../Images/B21040_08_001.png" data-original-image-title="">B21040_08_001.png</span> 대 <span class="image placeholder" data-original-image-src="../Images/B21040_08_002.png" data-original-image-title="">B21040_08_002.png</span>), 분산(<span class="image placeholder" data-original-image-src="../Images/B21040_08_003.png" data-original-image-title="">B21040_08_003.png</span>K)은 백화점(<span class="image placeholder" data-original-image-src="../Images/B21040_08_005.png" data-original-image-title="">B21040_08_005.png</span>K)에 비해 <span class="image placeholder" data-original-image-src="../Images/B21040_08_004.png" data-original-image-title="">B21040_08_004.png</span>배 이상 컸습니다. 분위수 특성은 최소 <span class="image placeholder" data-original-image-src="../Images/B21040_08_006.png" data-original-image-title="">B21040_08_006.png</span>%에서 최대 <span class="image placeholder" data-original-image-src="../Images/B21040_08_007.png" data-original-image-title="">B21040_08_007.png</span>%까지 모든 백분위수 수준에서 차이가 일관됨을 강조합니다. 요약하자면, 관측 기간 동안 슈퍼마켓 및 식료품점은 백화점보다 더 높은 판매량을 창출하고 절대적인 변동성이 더 크다는 것을 보여줍니다.

다음으로는 시계열의 의존성 구조에 대한 정보를 제공하는 자기상관 기반 특성에 대해 논의하겠습니다.

# 8.3 자기상관 기반 특성

자기상관 함수(ACF)는 시계열에서 현재 값과 지연된 값 사이의 선형 관계에 대한 장기적인 강도와 방향을 측정합니다. 원본 시계열의 다양한 지연(lag)에서의 자기상관 계수는 추세의 강도와 방향을 나타냅니다. 1차 차분 시계열에서 계산된 ACF는 시간에 따른 평균과 분산이 안정화되었는지 여부를 보여줌으로써 1차 차분의 효과를 나타냅니다. 2차 차분에서 나온 ACF는 이중 차분이 과대 차분으로 인해 원치 않는 의존성 구조를 유도하는지 여부를 나타냅니다. 편자기상관 함수(PACF)는 단기적 관계의 전반적인 강도를 보여줍니다.

표 8.1은 ACF와 PACF 특성에 대한 간단한 설명을 제공합니다. 일반적으로 이들은 원본 시계열의 추세가 얼마나 강한지, 시계열을 정상성으로 만들기 위해 비계절성 및 계절성 차분이 어느 수준까지 필요한지에 대한 통찰을 제공합니다.

| 특징          | 설명                                                                         |
| ------------- | ---------------------------------------------------------------------------- |
| `acf1`        | 원본 시계열의 지연 1에서의 자기상관                                          |
| `acf10`       | 원본 시계열의 지연 1부터 10까지 제곱된 자기상관의 합                         |
| `diff1_acf1`  | 1차 차분된 시계열의 지연 1에서의 자기상관                                    |
| `diff1_acf10` | 1차 차분된 시계열의 지연 1부터 10까지 제곱된 자기상관의 합                   |
| `diff2_acf1`  | 2차 차분된 시계열의 지연 1에서의 자기상관                                    |
| `season_acf1` | 원본 시계열의 첫 번째 계절 지연 1에서의 자기상관(월별 데이터의 경우 지연 12) |
| `pacf5`       | 원본 시계열의 지연 1부터 5까지 제곱된 편자기상관의 합                        |
| `diff1_pacf5` | 비계절성 차분을 한 번 수행한 후 지연 1부터 5까지 제곱된 편자기상관의 합      |
| `diff2_pacf5` | 비계절성 차분을 두 번 수행한 후 지연 1부터 5까지 제곱된 편자기상관의 합      |
| `season_pacf` | 첫 번째 계절 지연에서의 편자기상관(월별 데이터의 경우 지연 12)               |

표 8.1: ACF 및 PACF 기반 특성에 대한 설명

`feat_acf()`와 `feat_pacf()` 함수는 ACF와 PACF 기반 특성을 제공합니다. 매출액 시계열에서 이러한 특성을 계산해 봅시다. 그 값들은 표 8.2에 나열되어 있습니다.

표 8.2: 백화점과 슈퍼마켓 매출액에서 계산된 ACF 및 PACF 특성

계산된 특성을 바탕으로 두 시계열에 대해 다음과 같은 통찰을 도출할 수 있습니다.

- 백화점은 훨씬 낮은 `acf1` 값(<span class="image placeholder" data-original-image-src="../Images/B21040_08_008.png" data-original-image-title="">B21040_08_008.png</span>)을 갖습니다. 여전히 양수이긴 하지만, 의존성 구조가 약하고 더 빨리 감소합니다. 전반적인 의존성 구조가 약하기 때문에 이 시계열은 더 정상성에 가깝게 보입니다(`acf10` = <span class="image placeholder" data-original-image-src="../Images/B21040_08_009.png" data-original-image-title="">B21040_08_009.png</span>). `diff1_acf10`(<span class="image placeholder" data-original-image-src="../Images/B21040_08_010.png" data-original-image-title="">B21040_08_010.png</span>)과 `diff2_acf10`(<span class="image placeholder" data-original-image-src="../Images/B21040_08_011.png" data-original-image-title="">B21040_08_011.png</span>)의 약간 더 높은 값은 첫 번째 및 두 번째 차분된 시계열에서 처음 <span class="image placeholder" data-original-image-src="../Images/B21040_08_012.png" data-original-image-title="">B21040_08_012.png</span> ACF가 증가하는 것을 통해 명백하듯, 비계절성 차분이 원치 않는 의존성 구조를 유도할 가능성이 높음을 시사합니다. 계절성은 높은 `season_acf1` 값(<span class="image placeholder" data-original-image-src="../Images/B21040_08_013.png" data-original-image-title="">B21040_08_013.png</span>)이 보여주듯 꽤 강력하며, 추가 분석이나 예측 모델링 전에 시계열을 정상화하기 위해서는 계절적 의존성을 줄이기 위해 계절성 차분이 필요할 것임을 시사합니다.
- 슈퍼마켓 및 식료품점은 높은 양의 `acf1` 값(<span class="image placeholder" data-original-image-src="../Images/B21040_08_014.png" data-original-image-title="">B21040_08_014.png</span>)과 매우 큰 `acf10` 값(<span class="image placeholder" data-original-image-src="../Images/B21040_08_015.png" data-original-image-title="">B21040_08_015.png</span>)을 갖습니다. 이는 지속적이고 강력한 양의 상승 추세가 있음을 나타냅니다. 훨씬 낮은 `diff1_acf10` 값(<span class="image placeholder" data-original-image-src="../Images/B21040_08_016.png" data-original-image-title="">B21040_08_016.png</span>)은 평균과 분산을 안정화(즉, 정상성)하기 위해 1차 차분이 필요함을 시사합니다. 하지만 비교적 높은 `diff2_acf10` 값(<span class="image placeholder" data-original-image-src="../Images/B21040_08_017.png" data-original-image-title="">B21040_08_017.png</span>)은 2차 차분이 과대 차분으로 인한 원치 않는 의존성을 유도할 것임을 나타냅니다. 이 시계열은 `season_acf1`(<span class="image placeholder" data-original-image-src="../Images/B21040_08_018.png" data-original-image-title="">B21040_08_018.png</span>)로 볼 때 강한 계절성 패턴을 가지고 있습니다. 높은 `pacf5` 값(<span class="image placeholder" data-original-image-src="../Images/B21040_08_019.png" data-original-image-title="">B21040_08_019.png</span>)은 지배적인 비정상적 추세를 나타내며, 이중 차분이 필요하지 않음(`diff2_pacf5`가 `diff1_pacf5`보다 높음)을 나타냅니다. 계절성 PACF가 상대적으로 약해서(`season_pacf` = <span class="image placeholder" data-original-image-src="../Images/B21040_08_020.png" data-original-image-title="">B21040_08_020.png</span>) 계절성 차분이 필요하지 않음을 시사하며, 오히려 계절성 이동 평균(MA)을 포함하는 것이 이 시계열을 더 잘 모델링할 수 있습니다.

지금까지 시계열 성분을 추출하는 데 사용되는 STL 분해에 대해 배웠습니다. 다음 섹션에서는 STL 분해의 결과에서 유용한 특성을 계산하는 방법을 배울 것입니다.

# 8.4 STL 기반 특성

Loess를 사용한 계절성-추세 분해(STL)는 7장의 섹션 7.9에서 논의한 시계열 분해 기법입니다. STL 방식에 기반한 특성은 추정된 성분의 변동성을 비교함으로써 추세 및 계절성 성분의 강도를 정량화합니다.

특성을 어떻게 계산하는지 설명하기 전에 STL이 어떻게 작동하는지 간략히 되짚어보겠습니다. <span class="image placeholder" data-original-image-src="../Images/B21040_08_021.png" data-original-image-title="">B21040_08_021.png</span>를 추세 성분, <span class="image placeholder" data-original-image-src="../Images/B21040_08_022.png" data-original-image-title="">B21040_08_022.png</span>를 계절성 성분, <span class="image placeholder" data-original-image-src="../Images/B21040_08_023.png" data-original-image-title="">B21040_08_023.png</span>를 나머지 성분이라고 할 때, 시간 <span class="image placeholder" data-original-image-src="../Images/B21040_08_024.png" data-original-image-title="">B21040_08_024.png</span>에서의 STL 분해 기반 모델은 다음과 같습니다.

<span class="image placeholder" data-original-image-src="../Images/B21040_08_025.png" data-original-image-title="">B21040_08_025.png</span>

STL을 이용해 관측된 시계열을 그 성분들로 분리한 후, 각 추정 성분의 분산을 다음과 같이 측정할 수 있습니다.

- 계절성 조정된 시계열의 분산: <span class="image placeholder" data-original-image-src="../Images/B21040_08_026.png" data-original-image-title="">B21040_08_026.png</span>
- 추세 조정된 시계열의 분산: <span class="image placeholder" data-original-image-src="../Images/B21040_08_027.png" data-original-image-title="">B21040_08_027.png</span>
- 나머지 항의 분산: <span class="image placeholder" data-original-image-src="../Images/B21040_08_028.png" data-original-image-title="">B21040_08_028.png</span>

계절성 조정된 시계열은 시계열에서 계절성 성분을 제거하여 추세와 나머지 항을 남깁니다. 마찬가지로 추세 조정된 시계열은 추세 성분을 제거하여 분해된 시계열에서 계절성과 나머지 항을 남깁니다. 나머지 시계열에서는 추세와 계절성이 모두 제거됩니다. 이러한 분산들은 추세와 계절성의 상대적인 강도에 관해 어떤 정보를 제공할까요?

계절성 조정된 시계열에서, 추세가 약하거나 없으면 <span class="image placeholder" data-original-image-src="../Images/B21040_08_029.png" data-original-image-title="">B21040_08_029.png</span>와 <span class="image placeholder" data-original-image-src="../Images/B21040_08_030.png" data-original-image-title="">B21040_08_030.png</span>가 비슷한 값을 가져야 합니다. 즉, 추세 성분이 없을 때 추세와 나머지 성분의 변동은 본질적으로 나머지 성분 단독의 변동에 의해 좌우된다는 것을 의미합니다. 따라서 약한 추세의 경우 비율 <span class="image placeholder" data-original-image-src="../Images/B21040_08_031.png" data-original-image-title="">B21040_08_031.png</span>는 <span class="image placeholder" data-original-image-src="../Images/B21040_08_032.png" data-original-image-title="">B21040_08_032.png</span>에 가까워집니다. 반면, 강한 추세를 가진 데이터의 경우 <span class="image placeholder" data-original-image-src="../Images/B21040_08_034.png" data-original-image-title="">B21040_08_034.png</span>가 <span class="image placeholder" data-original-image-src="../Images/B21040_08_035.png" data-original-image-title="">B21040_08_035.png</span>에 비해 작아지므로 동일한 비율이 <span class="image placeholder" data-original-image-src="../Images/B21040_08_033.png" data-original-image-title="">B21040_08_033.png</span>에 가까워집니다.

`trend_strength` 특성 <span class="image placeholder" data-original-image-src="../Images/B21040_08_036.png" data-original-image-title="">B21040_08_036.png</span>는 다음과 같이 정의됩니다.
