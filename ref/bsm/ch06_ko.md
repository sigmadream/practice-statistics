통계적 모델(Statistical model)은 관찰 과정에서의 오차와 편향을 포함하는 시스템의 수학적 표현이며, 따라서 분석에서 가정한 바를 명확히 드러냅니다. 물론 완벽하게 올바른 통계적 모델은 없습니다. 현실에서는 함수 관계가 선형적이지 않고, 오차가 정확히 가우시안 분포(Gaussian)를 따르지 않으며, 잔차(Residuals)가 독립적이지도 않습니다. 그럼에도 불구하고, 적합도(Fit)에서 약간의 편차를 감수하는 것은 중요한 관계를 탐색하고, 과학적 가설을 검정하며 예측을 수행할 수 있게 해주는 단순하고 해석 가능한 현실의 표현을 얻기 위한 작은 대가입니다. 반면 모델의 가정이 명백하게 위반된다면 분석 결과를 신뢰할 수 없습니다. 따라서 모수적 통계 분석(Parametric statistical analysis)에서는 데이터를 합리적으로 잘 설명하면서도 가능한 한 단순한 적절한 모델을 선택하는 것이 핵심 단계입니다.

이 장에서는 베이지안 모델 선택(Bayesian model selection)과 적합도 측도(Goodness-of-fit measures)에 대해 논의합니다. 모델 선택을 위해 유한한 후보 모델 집합이 존재한다고 가정하며 이를 M1,...,MM으로 표기합니다. 예를 들어 가우시안과 스튜던트 t-분포(Student's t-distribution) 모델을 비교하거나,

M1:Yi∼iidNormal(μ,σ2) versus M2:Yi∼iidtν(μ,σ2)(6.1)

또는 공변량(Covariate)의 포함 여부를 비교할 수 있습니다.

M1:Yi∼indepNormal(β1,σ2) versus M2:Yi∼indepNormal(β1+Xiβ2,σ2).(6.2)

우리가 논의하는 방법론들은 일반적이며, 무작위 효과(Random effects) 구조나 연결 함수(Link function) 등을 선택하는 다른 모델 선택 작업에도 사용할 수 있습니다.

[6.1절](./14-chapter6.md#sec6_1)부터 [6.4절](./14-chapter6.md#sec6_4)에서는 통계적 모델을 비교하고 선택하는 기법들을 소개합니다. [6.1절](./14-chapter6.md#sec6_1)은 직관적이고 유연하게 방법론들을 비교할 수 있는 교차 검증(Cross validation)으로 시작합니다. 모델 선택에 대한 더 형식적인 베이지안 접근과 모델 불확실성(Model uncertainty)의 평가를 위해, [6.2절](./14-chapter6.md#sec6_2)에서는 수많은 선형 모델을 고려할 때 베이즈 요인(Bayes factors)을 근사화하는 계산 도구를 제공합니다. 베이즈 요인의 매력적인 특징은 단일 모델을 선택하는 대신 사후 확률(Posterior probabilities)을 사용하여 모델에 대한 불확실성을 포착한다는 점입니다. [6.3절](./14-chapter6.md#sec6_3)에서는 이러한 사후 확률을 사용하여 모델 불확실성을 적절히 평균화하는 예측을 수행합니다. 베이즈 요인이 매력적이긴 하지만, 일반적으로 광범위한 유도나 계산이 필요하고 사전 확률(Prior)에 민감하므로, [6.4절](./14-chapter6.md#sec6_4)에서는 덜 형식적이지만 더 폭넓게 적용할 수 있는 모델 선택 기준을 제공합니다. 거의 모든 분석에서 _M_개의 모델 중 "완벽히 옳은" 것은 없으며, 단지 188\. 가장 "잘" 맞는 것을 찾는 과정일 뿐입니다. 따라서 [6.5절](./14-chapter6.md#sec6_5)에서는 선택된 모델이 데이터의 중요한 특징을 잘 포착했는지 검증하기 위한 적합도 도구(Goodness-of-fit tools)를 제공합니다.

## 6.1 교차 검증(Cross validation)

아마도 모델을 비교하는 가장 직관적인 방법은 표본 외 예측 성능(Out-of-sample prediction performance)을 기반으로 하는 것일 겁니다. 이상적으로는 독립적인 검증 세트(Validation set)를 이용해 성능을 평가하는 것이 좋습니다. 예를 들어 스트리밍 데이터의 경우 분석 시점에 가용한 데이터로 _M_개의 모델을 훈련시키고, 분석 이후 수집된 데이터를 사용해 예측 성능을 측정할 수 있습니다. 그러나 데이터가 순차적으로 수집되지 않는 경우가 많아 이는 종종 불가능하며, 대신 내부 교차 검증(Internal cross validation, CV)이 사용됩니다. _K_-겹 교차 검증(K-fold CV)에서는 각 관측치가 무작위로 _K_개의 폴드(Folds) 중 하나에 할당되며, gi∈{1,...,K}는 관측치 _i_의 그룹 할당을 나타냅니다. 폴드 _k_의 데이터 부분 집합을 Yk\={Yi;gi\=k}로, 그 외 모든 폴드의 데이터를 Y(k)\={Yi;gi≠k}로 표기합니다. 그런 다음 모델을 _K_번 적합시키는데, k번째 모델은 Y(k)를 훈련 데이터로 사용하여 Yk에 대한 예측을 수행합니다. 이와 같은 방식으로 각 관측치에 대해 해당 관측치를 제외한 분석을 사용하여 예측을 수행함으로써, 표본 외 예측 성능을 근사합니다.

베이지안 예측은 훈련 데이터 Y(k)가 주어졌을 때 테스트 세트 관측치 Yk의 사후 예측 분포(Posterior Predictive Distribution, PPD)를 기반으로 합니다([1.5절](./09-chapter1.md#sec1_5)). 이 예측 방법의 장점은 모델 파라미터의 불확실성을 자연스럽게 평균화한다는 것입니다. 파라미터 불확실성을 평균화하여 PPD에서 샘플을 생성하는 것은 MCMC를 사용하면 간단합니다. MCMC 반복 _s_에서 테스트 세트 관측치 _Y_ _i_에 대해 수행된 예측을 Yi(s)라고 하면, Yi(1),...,Yi(S)를 사용하여 PPD를 근사할 수 있습니다. 예를 들어, 몬테카를로(Monte Carlo) 표본 평균 Y^i\=∑s\=1SYi(s)/S, 중앙값 Y\~i, 그리고 _τ_-분위수(Quantile) qi(τ)를 계산하여 각각 사후 예측 평균, 중앙값 및 분위수를 근사할 수 있습니다.

각 모델 예측의 정확도를 요약하기 위해 여러 측정 지표를 사용할 수 있습니다 \[[64](./19-ref01.md#refbib64)\]. 점 예측(Point prediction)의 가장 일반적인 척도는 편향(Bias), 평균 제곱 오차(Mean squared error, MSE), 평균 절대 편차(Mean absolute deviation, MAD)입니다.

BIAS\=1n∑i\=1n(Y^i−Yi)MSE\=1n∑i\=1n(Y^i−Yi)2MAD\=1n∑i\=1n|Y\~i−Yi|,

이 때 _MSE_는 _MAD_보다 큰 오차에 더 민감합니다. _MSE_가 모델들의 자연스러운 순위를 제공하긴 하지만, 데이터의 스케일(Scale)을 알지 못하면 해석하기 어려울 수 있습니다. 예측 성능을 스케일에 구애받지 않고 측정하는 척도로는 _Y_ _i_와 Y\~i 간의 상관계수(Correlation)가 있습니다.

R\=∑i\=1n(Y\~i−M\~)(Yi−M)V\~V

여기서 M\~과 V\~는 Y\~1,...,Y\~n의 평균과 분산이며, _M_과 _V_는 Y1,...,Yn의 평균과 분산입니다. 상관계수의 제곱인 _R_2도 보고될 수 있습니다.

189\. 신뢰 구간(Credible intervals)의 성능은 경험적 포함률(Empirical coverage)과 예측 구간의 평균 너비(Average width)를 사용하여 요약할 수 있습니다.

COV\=1n∑i\=1nI\[qi(α/2)≤Yi≤qi(1−α/2)\]WIDTH\=1n∑i\=1n\[qi(1−α/2)−qi(α/2)\],

여기서 I(A)\=1은 문장 _A_가 참일 때이고, 그렇지 않으면 0입니다. 전체 분포의 적합성을 측정하는 지표로는 로그 점수(Log score)가 있습니다.

LS\=1n∑i\=1nlog\[f(Yi|θ^i)\](./6.3)

여기서 θ^i는 관측치 _i_를 제외한 폴드를 기반으로 추정한 모수입니다. 로그 점수는 훈련 데이터의 파라미터 추정치가 주어졌을 때 테스트 세트 관측치들의 평균 로그 우도(Log likelihood)입니다.

이러한 지표들에 기반하여, _COV_가 명목 수준인 1−α에 훨씬 못 미치는 모델들을 폐기하고, 남은 모델 중에서 _MSE_, _MAD_, _WIDTH_가 작고 _LS_가 큰 모델을 선택할 수 있습니다. 이 평가는 표본 내 적합도(Within-sample fit)가 아닌 표본 외 예측을 기반으로 하는 것이 필수적입니다. 과도하게 복잡한 모델(예: 예측 변수가 너무 많은 선형 모델)은 모델 훈련에 사용된 데이터를 잘 복제할 수 있지만 새로운 조건에서는 예측 성능이 불안정할 수 있습니다.

교차 검증은 정보 이론(Information theory)에 의해 동기를 부여받을 수 있습니다. "진정한(True)" 데이터 생성 모델의 확률 밀도 함수(PDF)가 _f_0여서 현실에서 Yi∼iidf0라고 가정해 봅시다. 당연히 우리는 진짜 모델을 알 수 없으므로 확률 밀도 함수 f1,...,fM를 가지는 _M_개의 모델 중에서 선택합니다. 우리의 목표는 어떤 의미에서 진짜 모델에 가장 가까운 모델을 선택하는 것입니다. 진짜 모델과 가정한 모델 간의 차이를 측정하는 합리적인 척도는 쿨백-라이블러 발산(Kullback–Leibler divergence)입니다.

KL(f0,fj)\=E{log\[fj(Y)f0(Y)\]}\=E{log\[f0(Y)\]}−E{log\[fj(Y)\]},

여기서 기댓값은 참인 모델 Y∼f0에 대해 계산됩니다. 기댓값 E{log\[f0(Y)\]} 항은 모든 j\=1,...,M에 대해 동일하므로, KL(f0,fj)를 기반으로 모델의 순위를 매기는 것은 로그 점수 LSj\=E{log\[fj(Y)\]}를 기반으로 순위를 매기는 것과 동치입니다. 데이터가 _f_0에서 생성되었기 때문에, 식 (6.3)의 교차 검증 로그 점수는 참 로그 점수 LSj의 몬테카를로 추정치입니다. 따라서 교차 검증 로그 점수를 기준으로 모델 순위를 정하는 것은 참 데이터 생성 모델과의 유사성에 기초하여 순위를 매기려는 시도입니다.

## 6.2 확률적 탐색 변수 선택(Stochastic search variable selection)

[5.1절](./13-chapter5.md#sec5_1)에서는 데이터가 두 가설을 지지하는 정도를 요약하기 위해 베이즈 요인(Bayes factors)을 사용했습니다. 이 개념은 다양한 공변량 부분 집합의 포함 여부에 기반한 다수의 모델로 일반화될 수 있습니다. 예를 들어, p\=2인 두 개의 공변량이 있는 선형 회귀 모델 Yi\=β0+X1iβ1+Xi2β2+εi에서 4개의 모델이 존재합니다. M1:β1\=β2\=0, M2:β1\=0,β2≠0, M3:β1≠0,β2\=0 그리고 M4:β1≠0,β2≠0 입니다. 어떤 모델을 선택할지 결정하기 위해 각 모델의 사후 확률을 사용할 수 있습니다. 그러나 많은 응용 분야에서 고려 대상 모델의 수는 거대하며, 모든 모델을 나열하고 각각의 사후 확률을 계산하는 것은 불가능합니다. 예를 들어 _p_개의 파라미터를 갖는 선형 회귀의 경우 190\. 예측 변수의 부분 집합을 포함하여 만들어지는 M\=2p개의 잠재적인 모델이 존재합니다. 만약 p\=30이면 이는 10억 개가 넘는 모델이 됩니다. 공변량들의 모든 조합에 대한 탐색을 극복하기 위한 고전적인 방법은 전진 선택법(Forward selection), 후진 제거법(Backward selection) 또는 단계적 선택법(Stepwise selection)과 같은 체계적인 탐색을 이용하는 것입니다. 이번 절에서는 사후 확률에 따라 모델을 무작위로 방문하는 확률론적 대안(Stochastic alternative)을 논의합니다.

확률적 탐색 변수 선택(Stochastic search variable selection, SSVS; \[[60](./19-ref01.md#refbib60)\])은 MCMC를 사용하여 모델 확률을 근사화합니다. SSVS는 더미 변수(Dummy variables)를 도입해 모델을 인코딩한 다음 더미 변수의 사후 확률을 계산하여 사후 모델 확률을 근사합니다. 예를 들어, 다음의 선형 회귀 모델을 고려해 봅시다.

Yi|β,σ2∼indepNormal(∑j\=1pXijβj,σ2).(6.4)

예측 변수의 부분 집합에 의해 구성되는 M\=2p개의 모델들은 γ\=(γ1,...,γp)로 인코딩될 수 있습니다. 이 때 모델에 공변량 _j_가 포함되면 γj\=1이고 제외되면 γj\=0이 됩니다. 따라서 γ\=c(1,0,1,0,0,...)는 E(Yi)\=Xi1β1+Xi3β3 모델에 해당합니다.

모델에 대한 일반적인 사전 확률(Prior)은 절편(Intercept)에 대해 γ1\=1로 고정하고, j\>1에 대해서는 γj|q∼iid Bernoulli(q)를 부여하는 것입니다. 여기서 _q_는 사전 포함 확률(Prior inclusion probability)입니다. 모델 γ가 주어졌을 때, 모델에 포함된 회귀 계수는 독립적인 정규 분포 사전 확률을 가질 수 있습니다 (다른 사전 확률도 가능함 \[[131](./19-ref01.md#refbib131)\]) βj|γj\=1∼Normal(0,σ2τ2). 포함 확률과 회귀 계수 분산은 고정되거나 q∼Beta(a,b) 및 τ2∼InvGamma(ϵ,ϵ)과 같은 사전 확률을 가질 수 있습니다. 베이즈 요인([5.1절](./13-chapter5.md#sec5_1))의 경우와 마찬가지로, 이 모델의 사후 확률은 사전 확률에 민감할 수 있으므로 민감도를 이해하기 위해 여러 사전 확률을 비교해야 합니다.

이 모델에 의해 유도된 _β_ _j_의 사전 확률은 [그림 6.1](./14-chapter6.md#fig6_1)에 그려져 있습니다. 사전 확률은 두 구성 요소의 혼합(Mixture)입니다. 하나는 공변량 _j_를 제외하는(γj\=βj\=0) 표본에 해당하는 βj\=0에서의 피크(Peak)이고, 다른 하나는 _β_ _j_를 포함하는(γj\=1이므로 βj\=δj) 표본에 해당하는 가우시안 곡선입니다. 이러한 구별되는 모양 때문에 이 사전 확률은 종종 스파이크 앤 슬래브(Spike-and-slab) 사전 확률이라고 불립니다. 191\. 

![스파이크 앤 슬래브 사전 확률을 보여주는 두 개의 그래프입니다. 사전 밀도는 베타가 0일 때의 좁은 스파이크와 영 부근을 중심으로 양과 음의 3을 향해 점점 가늘어지는 넓고 매끄러운 슬래브를 결합합니다. 사전 CDF는 슬래브 영역을 통해 점진적으로 상승하다가, 0에서 스파이크로 인해 급격히 점프한 다음 1을 향해 평평해집니다.](./images/fig6_1.jpg)

그림 6.1 **스파이크 앤 슬래브 사전 확률(Spike and slab prior)**. γ∼Bernoulli(0.5)와 δ∼Normal(0,1)일 때, 스파이크 앤 슬래브 사전 확률 β\=γδ 하에서의 _β_의 PDF(왼쪽)와 CDF. [본문으로 돌아가기.⏎](chapter6)

모든 _M_개의 모델은 동시에 다음과 같은 수퍼모델(Supermodel)로 작성될 수 있습니다.

Yi|β,σ2∼indepNormal(∑j\=1pXijβj,σ2)
βj\=γjδj
γj∼Bernoulli(q)
δj∼Normal(0,τ2σ2).

이 모델로부터 얻은 MCMC 표본들은 공변량의 서로 다른 부분 집합들을 포함합니다. γj\=0인 사후 표본들은 βj\=0을 가지므로 해당 공변량 _j_가 모델에서 배제됩니다. 이 수퍼모델을 단일하게 적합시킴으로써 전체 _M_개의 사후 모델 확률에 대한 근사치를 한 번에 제공받을 수 있습니다. 모델에 대한 탐색이 MCMC 내부에서 이루어지기 때문에 이는 전진 또는 후진 회귀(Forward or backward regression) 같은 체계적인 탐색과는 대조되는 확률적 탐색입니다. 확률적 탐색의 장점은 확률이 낮은 모델은 거의 샘플링되지 않아 더 많은 계산 시간을 높은 확률을 가진 모델에 쏟을 수 있다는 점입니다.

수많은 가능한 모델들이 존재할 때, 단일 모델만이 높은 확률을 가지며 튀어나올 가능성은 적습니다. 따라서 큰 _M_에 대하여 모델 확률을 정확히 추정하기 위해서는 매우 긴 체인(Chains)이 필요할 수 있습니다. 모델 공간을 더 안정적으로 요약해 주는 지표는 주변 포함 확률(Marginal inclusion probabilities)인 MIPj\=E(γj\=1|Y)\=Prob(βj≠0| Y)입니다. MIPj는 모델에 포함된 다른 변수 집합들의 불확실성을 평균화하여 공변량 _j_가 모델에 포함될 확률을 나타내며, 이는 공변량 _j_를 포함하는 모델들과 포함하지 않는 모델들 간의 베이즈 요인을 계산하는 데 활용할 수 있습니다. BFj\=\[MIPj/(1−MIPj)\]/\[q/(1−q)\]. 실제로 \[[13](./19-ref01.md#refbib13)\]에 따르면 예측을 위해 단일 모델이 필요한 경우 가장 높은 확률을 가진 모델보다 MIPj가 0.5보다 큰 공변량들을 포함하는 모델을 선호하는 것이 좋습니다.

**소아 말라리아 사례(Childhood malaria example)**: Diggle 외 \[[44](./19-ref01.md#refbib44)\]는 감비아(Gambia) 지역의 n\=1,332명의 어린이 데이터를 분석했습니다. 이진(Binary) 반응 변수 _Y_ _i_는 어린이 _i_가 말라리아 양성 판정을 받았는지를 나타내는 지시자(Indicator)입니다. 우리는 Xij에 5개의 공변량을 사용합니다.

* Age (나이): 아이의 연령 (일 단위)
* Net use (모기장 사용 여부): 아이가 모기장 아래에서 정기적으로 자는지 여부 (네=1, 아니오=0)
* Treated (약품 처리 여부): 모기장이 약품 처리되었는지 여부 (네=1, 아니오=0)
* Green (녹지도): 마을 바로 주변 식생의 녹지 정도에 대한 위성 측정치 (임의의 단위)
* PCH (보건소 존재 여부): 마을에 보건소가 있는지(1) 없는지(0)를 나타내는 지시 변수

이 5개의 공변량은 평균이 0, 분산이 1이 되도록 표준화되었습니다. 우리는 다음의 로짓 회귀 모델(Logit regression model)을 사용합니다.

logit\[Prob(Yi\=1)\]\=α+∑j\=1pXijβj.(6.5)

_β_ _j_에 대한 스파이크 앤 슬래브 사전 확률은 βj\=γjδj이며, 여기서 γj∼Bernoulli(0.5) 이고 δj∼Normal(0,τ2) 입니다. [코드 6.1](./14-chapter6.md#list6_1)은 이 모델을 적합시키기 위한 JAGS 코드를 보여줍니다.

코드 6.1 SSVS를 위한 JAGS 코드. [본문으로 돌아가기.⏎](chapter6)

`1 for(i in 1:n){`
`2   Y[i]            ˜ dbern(pi[i])`
`3   logit(pi[i])   <- alpha      + X[i,1]*beta[1] +`
`4                       X[i,2]*beta[2]  + X[i,3]*beta[3] +`
`5                       X[i,4]*beta[4]  + X[i,5]*beta[5]`
`6 }`
`7 for(j in 1:5){`
`8    beta[j] <- gamma[j]*delta[j]`
`9    gamma[j] ˜ dbern(0.5)`
`10   delta[j] ˜ dnorm(0,tau)`
`11 }`
`12 alpha ˜ dnorm(0,0.01)`
`13 tau ˜ dgamma(0.1,0.1)`

## 6.3 베이지안 모델 평균화(Bayesian model averaging)

베이지안 접근법의 주된 이점은 통계적 추론과 예측을 할 때 모델 파라미터 내재 불확실성을 적절히 다룰 수 있다는 점입니다. [1.5절](./09-chapter1.md#sec1_5)([그림 1.12](./09-chapter1.md#fig1_12))에서는 파라미터 불확실성을 예측에 반영한 효과를 탐색했습니다. 관측 데이터 **Y**가 주어졌을 때 새로운 관측치 _Y_\*의 사후 예측 분포(Posterior predictive distribution, PPD)는 사후 분포에 따라 파라미터의 불확실성을 평균화한 값입니다.

p(Y∗|Y)\=∫p(Y∗,θ|Y)dθ\=∫p(Y∗|θ, Y)p(θ|Y)dθ.(6.6)

모수적 불확실성(Parametric uncertainty) 외에도, 잠재적 모델들이 무수히 많을 때 오직 하나의 모델만이 실행 가능한 옵션으로 떠오를 가능성은 적으며, 따라서 예측 시 모델 불확실성(Model uncertainty)을 반영하는 것이 중요합니다. 모델 _m_의 사후 확률을 Prob(M\=Mm|Y)\=wm(Y)로 표기하면, 사후 모델 불확실성을 평균화한 _Y_\*의 PPD는 다음과 같습니다.

p(Y∗|Y)\=∑m\=1Mwm(Y)p(Y∗|Y,Mm)(6.7)

194\. 여기서 p(Y∗|Y,Mm)는 모델 Mm에서 계산된 PPD입니다. 이처럼 사후 모델 확률을 사용하여 모델 불확실성을 반영한 추론을 베이지안 모델 평균화(Bayesian model averaging, BMA; \[[80](./19-ref01.md#refbib80)\])라고 합니다.

MCMC를 이용한 SSVS([6.2절](./14-chapter6.md#sec6_2))는 모델 평균화 예측을 수행하는 편리한 방법을 제공합니다. SSVS 모델에서의 추출(Draws)은 여러 모델의 더미 지시자(Dummy indicators)를 미지의 파라미터로 포함하기 때문에, 그들의 사후 확률에 따라 자연스럽게 여러 모델 간의 평균화가 이루어집니다. 따라서, 매 MCMC 반복 단계마다 _Y_\*에 대한 표본을 생성한다면, 그 표본들은 예상대로 베이지안 모델 평균화된 PPD를 따르게 됩니다.

예측뿐만 아니라 BMA는 모든 모델에 공통적으로 포함된 파라미터에 대한 추론에도 사용할 수 있습니다. 예를 들어, 만약 파라미터 _β_ _j_가 모델 Mm 하에서 사후 분포 p(βj|Y,Mm)를 가진다면, BMA 사후 확률은 p(βj|Y)\=∑m\=1Mwm(Y)p(βj| Y,Mm)가 됩니다. 그러나 파라미터의 해석이 모델에 따라 크게 달라질 수 있기 때문에 BMA의 파라미터 결과는 주의 깊게 검토해야 합니다. 즉 여러 모델에 걸친 평균화 결과를 어떻게 해석해야 할지 항상 명확한 것은 아닙니다. 극단적인 사례로 다중공선성(Collinearity)이 있는 회귀 분석에서는 다른 어느 공변량이 모델에 포함되는지에 따라 _β_ _j_의 부호가 달라질 수 있으므로, 여러 모델들의 결과를 단순히 결합해야 하는 것이 분명하지 않습니다.

## 6.4 모델 선택 기준(Model selection criteria)

교차 검증과 베이즈 요인은 대규모 데이터 세트나 복잡한 모델에 대해 계산하기 까다롭습니다. 교차 검증은 각 모델을 _K_번씩 반복해서 적합시켜야 하고, 베이즈 요인은 복잡한 적분(Integration)을 요구합니다. 모델 적합도 기준(Model-fit criteria)은 이에 대한 유용한 대안을 제공합니다. 이 장에서 고려하는 기준들은 파라미터들이 주어졌을 때 데이터의 이탈도(Deviance, 음의 로그 우도에 2를 곱한 값)를 통해 정의됩니다.

D(Y|θ)\=−2log\[f(Y|θ)\].(6.8)

_이 장에서는 이탈도를 각 모델에 걸친 적합도를 비교하는 척도로 사용하기 위해, 오직 이탈도 함수는 동일하지만 파라미터에 대한 모델/사전 확률이 서로 다른 모델들만을 비교합니다._ 일부 모델들의 경우(예를 들어, [4.4절](./12-chapter4.md#sec4_4)의 무작위 효과 모델들은 무작위 효과를 조건부로 할 때와 무작위 효과에 대해 주변화할 때 동등한 표현을 가지는데) 우도와 이탈도의 정의가 유일하게(Unique) 떨어지지 않지만, 독립적인 데이터에 대한 대부분의 모델에 대해 이탈도의 정의는 분명합니다.

베이지안 정보 기준(Bayesian Information Criteria, BIC)이 그러한 기준 중 하나로, 다음과 같이 정의됩니다.

BIC\=D(Y|θ^MLE)+log(n)p(6.9)

여기서 θ^MLE는 최대 우도 추정치(Maximum likelihood estimate)이고, _n_은 표본의 크기이며, _p_는 모델 내의 파라미터 수입니다. _BIC_는 두 항으로 나뉩니다. D(Y|θ^MLE)는 데이터에 잘 맞는 모델일수록 작아지고, log(n)p는 차원이 낮은 단순한 모델일수록 작아집니다. 적합도가 좋으면서도 단순한 모델이 바람직하므로 더 작은 _BIC_를 갖는 모델이 선호됩니다.

_BIC_는 원래 베이즈 요인에 대한 근사치로 동기가 부여되었습니다. 그러나 베이지안 관점에서 _BIC_는 몇 가지 바람직하지 않은 특성을 가집니다. 첫째, MLE를 사용하여 θ를 추정하는 것은 사전 정보를 사용하지 않는 것이며 MCMC 결과에서 이용할 수 없습니다. 둘째, 모델의 복잡성을 파라미터 수 _p_로 수량화하는 것은 정보성 있는 사전 확률(Informative priors)을 설명하지 못합니다. 예를 들어 두 모델의 파라미터 수가 동일하지만, 하나의 모델은 정보성이 매우 높은 사전 확률을 가지고 다른 모델은 그렇지 않다면, 정보성 사전 확률을 갖는 모델의 유효 자유도(Effective degrees of freedom)가 더 적으므로 더 단순한 모델로 간주되어야 합니다.

195\. 이탈도 정보 기준(Deviance Information Criteria, DIC; \[[145](./19-ref01.md#refbib145)\])은 이러한 문제들을 해결합니다. 베이지안 관점에서 이탈도 D(Y|θ)는 확률 변수 θ의 함수이므로 그 자체로 확률 변수(Random variable)입니다. 따라서 D(Y|θ)는 사후 분포를 가지며 그 사후 평균 D¯를 통해 요약할 수 있습니다. 모델의 복잡성은 유효 파라미터 수(Effective number of parameters)를 통해 요약됩니다.

pD\=D¯−D^,(6.10)

여기서 D^\=D(Y|θ^)이고 θ^는 θ의 사후 평균입니다. 아래의 예시에서 볼 수 있듯이, 사전 수축(Prior shrinkage)으로 인하여 부분적인(Partial) 자유도가 발생할 수 있으므로 _p_ _D_는 일반적으로 정수가 아닙니다. D¯와 θ^ 모두 매번의 반복에서 D(Y|θ)와 θ를 계산한 뒤 전체 반복에 대한 평균을 취하여 MCMC 출력으로부터 근사할 수 있습니다. 따라서 _DIC_는 MCMC 출력만 주어지면 직관적으로 계산할 수 있습니다.

그런 다음 기준(Criteria)은 다음과 같습니다.

DIC\=D¯+pD\=D(Y|θ^)+2pD.(6.11)

이 기준은 아카이케 정보 기준(Akaike Information Criterion, AIC) \[[4](./19-ref01.md#refbib4)\] AIC\=D(Y|θ^MLE)+2p 과 유사하지만, MLE 대신 사후 평균을, 총 파라미터 수 대신 유효 자유도를 사용한 꼴입니다. _AIC_ 및 _BIC_와 마찬가지로 기준의 실제 값은 해석하기 어렵지만, 작은 _DIC_를 갖는 모델이 선호되는 모델 순위를 매기는 데 사용될 수 있습니다(대략적인 경험칙으로 값이 5 차이 나면 실질적 차이가 있고 10 차이가 나면 결정적인 것으로 보나, _DIC_를 사용하여 엄격한 통계적 유의성을 설정하기는 어렵습니다). 직관적으로 보면 _DIC_가 작은 모델이 복잡성 면에서 단순하고(작은 _p_ _D_), 데이터에 잘 적합(작은 D¯)된다는 뜻입니다. 사전 확률이 강하게 정보를 부여할수록(Strong prior) 유효 파라미터 수 _p_ _D_는 예상대로 총 파라미터 수 _p_보다 대체로 적게 계산됩니다. 불행히도 일부 병적인(Pathological) 사례에서는 _p_ _D_가 \[0,_p\] 범위를 벗어날 수 있는데, 주로 θ의 사후 평균이 사후 분포에 대한 훌륭한 요약 역할을 못 하는 다봉형(Multimodal) 사전 확률 및 사후 분포를 가진 혼합 모델(Mixture models) 등에서 그렇습니다.

모델 크기의 척도로서의 _p_ _D_가 나온 배경은 다소 복잡하지만, 몇 가지 예시를 통해 직관을 얻을 수 있습니다. 다중 선형 회귀 모형 Y|β∼Normal(Xβ,σ2In)에 젤너 사전 확률(Zellner's prior) β∼Normal(0,cσ2(XTX)−1)을 가정한 경우 유효 파라미터의 수는 pD\=cc+1p가 됩니다. 이 경우 무정보성 사전 확률(c\=∞)일 때 유효 파라미터 수는 _p_에 수렴하고 타이트한(Tight) 사전 확률(c\=0)에 가까워지면 0에서 시작해 증가하게 됩니다. 또한 분산 성분(Variance components) _σ_2 와 _c_가 고정되어 있으며 j\=1,...,p개의 그룹에 속한 i\=1,...,n 반복 측정치들을 이용하는 일원(One-way) 무작위 효과 모델([4.4절](./12-chapter4.md#sec4_4))의 경우,

Yij|μj∼Normal(μj,σ2) 및 μj∼Normal(0,cσ2),(6.12)

유효 파라미터 수는 pd\=cc+1/np이며, 이 역시 사전 분산 _c_에 따라 0에서부터 _p_를 향해 점차 증가합니다.

와타나베-아카이케 정보 기준(Watanabe–Akaike information criteria) 혹은 폭넓게 응용 가능한 정보 기준(Widely applicable information criteria, WAIC; \[[55](./19-ref01.md#refbib55)\])은 _DIC_에 대한 대안입니다. _WAIC_는 _n_-폴드 (즉, 리브원아웃, Leave-one-out) 교차 검증의 근사치로 제안되었습니다. _WAIC_는 이탈도의 사후 평균 대신 우도 및 로그 우도의 사후 평균과 분산을 계산합니다. 기준식은 아래와 같습니다.

WAIC\=−2∑i\=1log{f¯i}+2pW(6.13)

여기서 관측치 _i_의 적합도는 우도의 사후 평균으로 측정되며,

f¯i\=E\[f(Yi|θ)|Y\](./6.14)

모델 복잡성은 다음 식을 통하여

pW\=∑i\=1nVar\[log(f(Yi|θ))|Y\],(6.15)

196\. 로그 우도 함수의 사후 분산 합으로 정의됩니다. 따라서 _BIC_나 _DIC_와 동일하게 작고 단순하면서도 잘 적합되는 _WAIC_를 가진 모델이 더 선호됩니다.

**감비아 데이터에 대한 무작위 효과 모델 선택하기**: [6.2절](./14-chapter6.md#sec6_2)에서와 같이, 이진형(Binary) 반응 변수 _Y_ _i_는 어린이 _i_가 말라리아에 걸렸는지 양성 여부를 지시하며, 우리는 나이, 모기장 사용, 모기장 약품 처리, 녹지도 및 보건소의 공변량들을 고려합니다. 이 분석에서는 추가적으로 같은 마을 출신 아이들 사이의 말라리아 양성 판정 상호 의존성을 설명하기 위해 어린이 _i_가 거주하는 마을 vi∈{1,...,65}을 고려합니다([그림 6.3](./14-chapter6.md#fig6_3)은 표본 수집이 진행된 각 마을의 위치와 샘플로 수집된 어린이의 숫자를 지도로 나타냅니다). 우리는 다음과 같은 무작위 효과 로지스틱 회귀 모델(Random effects logistic regression model)을 사용합니다.

logit\[Prob(Yi\=1)\]\=α+∑j\=1pXijβj+θvi,(6.16)

여기서 _θ_ _v_는 마을 _v_에 대한 무작위 효과입니다. 마을 무작위 효과 모델들을 위한 세 가지 대안을 _DIC_와 _WAIC_를 통해 비교합니다:

1. 무작위 효과 없음(No random effects): θv\=0
2. 가우시안 무작위 효과(Gaussian random 시effects): θv∼Normal(0,τ2)
3. 이중 지수(Double-exponential) 무작위 효과: θv∼DE(0,τ2)

JAGS 안에는 _WAIC_와 같은 유사한 기능을 수행하는 내장 함수가 별도로 존재하지 않기 때문에, 이것은 JAGS 외부에서 계산되어야 합니다. 주 _s_의 카운티에 대해, 우리는 다음 선형 모델을 가정합니다.

Yi\=β0s+∑j\=1pXiβsj+εi,(6.18)

여기서 βjs는 주 _s_에 속하는 공변량 _j_의 효과이며 εi∼iid Normal(0,σ2) 입니다. 우리는 βjs에 대해 세 가지 모델을 비교합니다.

1. 일정한 기울기(Constant slopes): 모든 카운티에 대해 βjs≡βj
2. 변동하는 기울기, 무정보성 사전 확률(Varying slopes, uninformative prior): βjs∼iidNormal(0,102)
3. 변동하는 기울기, 정보성 사전 확률(Varying slopes, informative prior): βjs∼indepNormal(μj,σj2)

모든 모델에서 오차 분산에 대한 사전 확률은 σ2∼InvGamma(0.1,0.1) 입니다. 첫 번째 모델에서 기울기는 무정보성 사전 확률 βj∼Normal(0,102)을 가집니다. 마지막 모델에서, 평균 _μ_ _j_ 와 분산 σj2는 사전 확률 μj∼Normal(0,102) 및 σj2∼InvGamma(0.1,0.1)을 가지며 데이터로부터 추정되므로 사전 확률을 거쳐 주(States) 전체로 정보가 풀링(Pooled) 됩니다. 세 가지 방법론은 일정한 기울기 모델을 위한 [코드 6.3](./14-chapter6.md#list6_3)처럼 DIC와 WAIC를 사용하여 비교됩니다.

**_DIC_ 및 _WAIC_ 성능 평가를 위한 시뮬레이션 연구**: 이 예제에서 _DIC_와 _WAIC_는 유사한 결과를 제공했습니다. 그러나 실제로는 결과가 달라지는 경우가 분명히 존재할 것이며, 사용자는 두 개 중 하나를 선택하고 자신의 선택을 방어해야 합니다. 더구나 실증 데이터에 적용될 때는 위처럼 "올바른" 모델이 알려져 있지 않기 때문에, 두 가지 방법론 중 하나가 반드시 옳은 모델을 선택했다고 단정할 수는 없습니다. 이러한 기준(혹은 어떤 통계적인 기법들)에 대한 신뢰를 구축하는 한 가지 방법은 정확한 모델이 알려진 시뮬레이션 된 데이터에서 이들의 성능을 평가하는 것입니다(시뮬레이션 연구의 자세한 논의에 대해서는 [9.3절](./17-chapter9.md#sec9_3)을 확인하십시오).

이 시뮬레이션 실험을 위한 데이터는 감비아 데이터를 흉내 내어 생성되었습니다. 반응 변수 _Y_ _i_는 이진형(Binary)이며 무작위 효과 로지스틱 회귀 모델에서 생성됩니다.

logit\[Prob(Yi\=1)\]\=α+Xiβ+θvi,

여기서 _v_ _i_는 관측치 _i_의 마을 인덱스(Village index)이고 θv∼Normal(0,σ2)는 마을 _v_의 무작위 효과입니다. 데이터는 10개의 마을에 각각 10개의 관측치가 포함된 n\=100개로 생성되며, α\=0, β\=1, 그리고 Xi∼iidNormal(0,1)입니다. 우리는 무작위 효과 분산 _σ_2을 변화시키며, 모델 선택 기준이 안정적으로 무작위 효과 모델을 선호하려면 무작위 분산이 어느 정도 커야 하는지를 결정합니다.

각각의 _σ_ 값에 대해 N\=100개의 데이터 셋을 생성합니다. 각 시뮬레이션 데이터 셋에 대해 두 모델을 적합시킵니다: (1) 무작위 효과가 없는 모델(즉, θv\=0)과 (2) θv∼Normal(0,σ2)를 가지는 온전한 무작위 효과 모델. 사전 확률은 α,β∼Normal(0,100)와 σ2∼InvGamma(0.1,0.1)입니다. 각 모델과 시뮬레이션 된 각 데이터 셋에 대해 길이 10,000 (1,000번의 번인-Burn-in 이후)의 두 MCMC 체인을 생성하고 _DIC_와 _WAIC_ 양쪽 모두 계산합니다. DICmj와 WAICmj를 j∈{1,...,N}번째 시뮬레이션 데이터 셋에 대한 모델 m∈{1,2}의 기준으로 가정합니다. [그림 6.6](./14-chapter6.md#fig6_6)은 N개의 샘플에 대한 DIC2j−DIC1j (왼쪽)와 WAIC2j−WAIC1j (오른쪽)을 도식화합니다. 이 차이가 음수일 때 무작위 효과 모델이 선택되며, 따라서 음수인 표본들의 비율은 무작위 효과 모델을 선택할 추정 확률입니다. 무작위 효과 모델이 선택된 데이터 셋의 비율은 [그림 6.6](./14-chapter6.md#fig6_6) 안의 각 박스플롯 상단에 표시됩니다.

σ\=0으로 데이터가 생성되었을 때는 무작위 효과가 없는 단순한 모델이 정답입니다. 이 경우, 양쪽 기준 모두 무작위 효과가 도입된 과도하게 복잡한 모델에 더 큰 값을 부여하며 시뮬레이션 된 데이터의 10–20%에서만 무작위 효과 모델을 택합니다. σ\>0 로 데이터가 생성될 경우엔 무작위 효과 모델이 옳은 것이 되며 양쪽 방법 모두 _σ_가 증가할 때마다 모델을 점진적으로 신뢰성 있게 택합니다. 따라서 두 방법 모두 감비아 데이터를 모방하기 위해 생성된 모델에 대해서 신뢰도 있게 옳은 모델을 선택해 냅니다. 이 특정 세팅에서는 _DIC_가 _WAIC_ 보다 올바른 모델 반환 빈도가 약간 높지만 당연히 이를 타 사례로 일반화 시킬 수는 없습니다. 202\. 이 페이지 그림 참조.

## 6.5 203\. 적합도 검사(Goodness-of-fit checks)

지금까지 미리 정해진 모델들의 셋 안에서 어느 것을 고르는 지에 대한 방법론을 의논했습니다. 이러한 모델 선택 과정은 중요하지만 선택된 모델이 실로 데이터에 잘 부합된다는 것을 보장해 주지는 않습니다. 예를 들어, 고려 대상 모델이 모두 가우시안인데 데이터가 가우시안 분포가 아니라면 가장 적합해 보이는 모델일지라도 적절하지 않습니다. 따라서 모델들을 비교하는 일 뿐만 아니라, 모델들이 데이터의 주요한 요소를 잘 포착해 내고 있는지 진단하는(Diagnostics) 작업도 함께 수행되어야 합니다.

표준적인 진단 도구들은 베이지안 분석이건 고전적인 분석이건 공통으로 매우 중요합니다. 예를 들어 선형 회귀에 있어 정규성 (예: 잔차 qq-플롯), 선형성 (예: 추가 변수 플롯), 영향점 (예: 쿡의 거리 Cook's D) 등은 반드시 철저하게 파악되어야 합니다. 수많은 클래식 도구들이 최소 제곱 잔차(Least-squares residuals)에 기초하므로 순수하게 베이지안 적인 것은 아니지만, 비공식적인 적합도 측도(Goodness-of-fit measures)로서 여전히 높은 가치를 지닙니다.

모델을 비평하는 다른 한 가지 방법은 표본 외 예측 성능(Out-of-sample prediction performance)입니다. 데이터를 학습 세트(Training set) **Y**와 테스트 세트(Test set) Y∗\=(Y1∗,...,Ym∗)로 나눈다고 가정해 봅니다. [1.5절](./09-chapter1.md#sec1_5)은 학습 데이터가 주어졌을 때 테스트 세트 관측치 _i_에 관한 사후 예측 분포(Posterior Predictive Distribution, PPD)를 논의하며 이는 fi∗(y|Y)입니다(모델 내 파라미터 불확실성이 모두 평균화 되어 고려된 것입니다). 이 때 테스트 세트 데이터와 PPD를 서로 비교하는 방식이 곧 모델의 부합(Fit) 정도를 확인해 줍니다. 관측된 테스트 관측치 상에서의 PPD 평가 값인

CPOi\=fi∗(Yi∗|Y),(6.19)

이것은 조건부 예측 종좌표(Conditional predictive ordinate, CPO)라고 불립니다 \[[52](./19-ref01.md#refbib52), [122](./19-ref01.md#refbib122)\]. 낮은 CPO 값을 가진 테스트 세트 관측치는 모델에 잘 부합하지 않으며 결과적으로 잠재적인 이상치(Outliers)가 됩니다.

더 해석력 높은 진단 기준은 대략 95%의 테스트 셋의 관측치들이 사후 예측 구간 95% 내에 들어오는 지 확인하는 것입니다. 연속된(Continuous) 데이터의 경우, 확률 적분 변환(Probability Integral Transform, PIT) 통계량 \[[40](./19-ref01.md#refbib40)\]이 테스트 구간 95%를 벗어나 204\. 전체 분포 상의 적합을 알려줍니다. PIT은 해당 테스트 관측치, Yi∗ 아래 영역의 사후 예측 확률입니다.

PITi\=∫−∞Yi∗fi∗(y|Y)dy.(6.20)

이 적분식은 벅차 보이지만 MCMC 샘플 안에서 테스트 표본 값 밑의 부분에 위치하는 비율로 간단하게 근사 계산이 됩니다. 통상적으로 PITi는 각 테스트-세트 관측치에 대해 구해지며, 해당 결과는 통계치로 히스토그램 플롯화가 됩니다. 모델이 적합하면 PIT 값들은 Uniform(0,1) 분포를 따르고, PIT 히스토그램 곡선이 평평해져야만 합니다.

주의해야 할 점으로 진단 척도를 분석할 때 모델이 완벽하게 맞춰진 상태여도 (균일한 PIT를 가진다 할지라도) 그것이 진정한 모델이라고 단정 지을 수 없다는 것입니다(가령 '진정한' 모델 자체가 존재한다면). 예를 들어 데이터가 Y|X∼Normal(X,1) 및 X∼Normal(0,1)로 산출됐을 때 Y∼Normal(0,2) 또한 데이터 적합성에 합격점을 보일 수 있겠지만 _X_를 예측인자로 채택한 모델에 비해 본질적 열등함을 갖는 건 확실합니다. 결론적으로, 모델 선택(Model selection) 및 적합도 판별(Goodness-of-fit testing) 양측 모두 다 중요한 요소가 됩니다.

**사후 예측 점검(Posterior predictive checks)**: 각각의 개별적 테스트 셋의 관측치 결과를 예측하는 것을 초월해, 데이터셋 그 자체를 요약하여 모델 부합 정도를 판단해내는 후행적 방식이 존재합니다(예: \[[58](./19-ref01.md#refbib58)\]). 모델 매개변수의 사후 표본을 θ\~, 그리고 복제 데이터 셋을 Y\~이라 두며 주어진 모델로부터 θ\~을 추출한다고 합시다. 비교 편의 상 복제 데이터의 크기는 기존 관측 데이터 세트 크기와 동일하여야 합니다. 예를 들어, 선형 회귀 모델 Y∼Normal(Xβ,σ2I)의 파라미터는 θ\~\=(β\~,σ\~2)이며

Y\~|θ\~∼Normal(Xβ\~,σ\~2I)(6.21)

다음과 같은 식에 기준 데이터 세트에서 사용했던 **X** 공변량을 대입해 관측하게 됩니다.

MCMC가 _S_ 개의 사후 표본 θ(1),...,θ(S)을 추출해 주고 우리가 Y\~s|θ(s)∼p(y |θ(s)) 인 Y\~1,...,Y\~S 식의 _S_개 복제 데이터 세트를 생성했다고 가정합니다. 만일 해당 모델이 제대로 들어맞는다면, 데이터 모델 **Y**와 Y\~s 양측은 필히 유사한 분포를 보여줘야 하며, 따라서 이를 통해 처음 시도된 데이터 모델링 방침이 정확했는지 판단 내릴 수 있습니다. **Y** 분포 통계와 같은 수많은 다변량 분포 적합성을 모두 단번에 보여주기는 어려운 일이기에 비교 대상 척도는 데이터의 일차원적인 요약 수치인 D(Y)로 제한합니다. 예를 들어, D(Y)는 데이터의 최댓값 혹은 기댓값이 되거나 이 외 여러 기타 흥미로운 관심 척도로 지정이 가능합니다. 이어서 요약 통계량의 예측 범위 D(Y\~1),...,D(Y\~S)를 시각적인 히스토그램 도표로 그려내 관측 값인 D(Y)가 분포상의 정중앙에 위치하는지 판단합니다. 통계 관측 값이 센터에서 크게 벗어나 멀어진 위치에 놓일 시 이 모델의 적합성이 부족하다는 반증이 됩니다.

요약 측도인 _D_의 선택이 가장 중요하다는 것은 명확합니다. 요약 측정 기준들 중 가장 효과가 돋보이는 기준은 애초 해당 모델링의 기초 전제와 부합합니다. 예를 들어, Y∼Normal(μ,σ2)의 예측 분산이나 모델 내 파라미터 수치들로 인하여 데이터 기댓값 및 분산 값은 통상 예측 영역 안에 진입하기 마련입니다. 고로 _D_에 표본 분산이나 표본 평균을 설정하는 것은 정보 제공에 무의미합니다. 한편 정규 분포 기반 모델의 경우 모든 수치가 좌우 대칭이 될 것을 전제하기 때문에 비대칭성을 판단할 어떤 모델도 포함하지 않습니다. 이로 인해 비대칭도(Skewness) 등을 요약 측정 기준으로 잡음으로서 모델의 타당성 체크 단계를 실효적으로 검증하게 됩니다.

베이지안 p-값(Bayesian p-value)은 사후 검증 결과 예측 범주를 더 정식으로 요약해 주는 단위를 지칭합니다. 덧붙여 베이지안 p-값은 동일 관측 통계치의 수치만큼이나 커질 관측 데이터 비율 모델을 뜻하기도 합니다. 기각치 근사는 _S_ 개 분포의 전체 영역인 D(Y\~1),...,D(Y\~S) 내에서 MCMC가 반복되며 D(Y)를 상회할 시 결정됩니다. 이 척도는 주로 영이나 일에 가까워질수록 어긋남의 결함을 알려주게 됩니다.

205\. 베이지안 p-값의 경우 표본 검정 반복 추출에 있어 기존에 관찰된 지표보다 크거나 동일한 데이터를 만날 가능성을 띈다는 측면에서 고전적인 가설 검증 p-값과 통용된 부분을 갖고 있습니다. 다만 기존 모델에서의 반복 표본은 주로 대립되는 귀무가설 기반 추출인 점을 고려해야 하며, 베이지안의 그것은 채택한 모델 안에서의 정식 표본을 가져다 쓴다는 점이 큰 차이가 됩니다. 베이지안 p-값에 대한 또 하나의 차이점은 기존 모델과는 상충되게 확률이 0이나 1과 같은 극점 숫자로 기울면 결함 및 반증의 단초를 포착한 걸로 보는 차이가 있습니다.

**총기 규제 사례(Gun control example):** Kalesan 등(2016) \[[86](./19-ref01.md#refbib86)\]은 각 주의 총기 규제법과 화기 관련 사망률의 상관성을 분석했습니다. 응답 변수 _Y_ _i_는 2010년 해당 _i_ 주에서 총기와 관련된 사망자의 숫자입니다. 이 분석은 5개의 잠재적 교란 요인(Confounders, Zij)을 안고 있습니다: 10,000명 단위 환산 2009년 총기 사고 사망률, 개인 총기 보유 비율 분위, 실직자 분위수 분포도, 비 총기관련 살인 수치율, 그리고 무기류 판매 비율 척도 등입니다. 우리가 집중하려는 데이터 지표가 되는 공변량은 바로 주 별 무기 관리법안 실태입니다. 해당 카운티 규제 법을 Xil으로 표시하고 _i_ 법을 보유하는 것으로 지정합니다. 이 연구에서는 해당 주 관리법 숫자인 Xi\=∑lXil 만을 공변량에 산출 변수로 넣습니다. 상관관계와 그 인과성에 대한 복잡한 문제는 제쳐두고서, 본 연구의 궁극적인 분석 목적은 곧 지역 자치 법규 내 무기류 법안 통과 빈도수와 사망률의 기조를 연관 짓는 것입니다. 이 절차를 시행함에 앞서, 우리가 수행해 나갈 예측 모형 단계는 사후 검정 모델이 제대로 안착했는지 그 부합점을 체크하는 것입니다.

우리는 두 개의 모델의 부합을 점검합니다. 첫 번째는 보편적인 포아송 회귀 모델(Poisson regression model)입니다.

Yi∼Poisson(λi) 여기서 λi\=Niexp(α+∑j\=15Zijβj+Xiβ6)(6.22)

그리고 _N_ _i_는 주의 전체 인구 숫자입니다. 포아송 모델의 근본적인 한계점인 기댓값과 분산이 균등해야 한다는 수치상 결함 때문에 매우 방대한 숫자 집합에는 유연한 통용이 어려울 수 있습니다. 이를 감안해서, 과대 분산 비율 한도치인 오버 디스퍼전 파라미터(Over-dispersion parameter) _m_과 기댓값 _λ_ _i_에 따른 음이항식 모형(Negative binomial model)을 추가로 구상할 수 있습니다.

Yi∼NB(mλi+m,m).(6.23)

고정 효과에 걸맞는 선행 요소인 α,βj∼Normal(0,10) 그리고 음이항 모델 m∼Gamma(0.1,0.1)입니다. 음이항 모델 적용 단계의 코드는 [코드 6.4](./14-chapter6.md#list6_4)에서 열람이 가능합니다.

코드 6.4 과대분산 포아송 회귀 모델에 대한 JAGS 코드. [본문으로 돌아가기.⏎](chapter6)

`1 _# 우도 (Likelihood)_`
`2 for(i in 1:n){`
`3   Y[i]             ˜ dnegbin(q[i],m)`
`4   q[i]            <- m/(m+N[i]*lambda[i])`
`5   log(lambda[i]) <- alpha + inprod(Z[i,],beta[1:5]) + X[i]*beta[6]`
`6 }`
`7 `
`8 _# 사전 확률 (Priors)_`
`9  for(j in 1:6){`
`10     beta[j] ˜ dnorm(0,0.1)`
`11  }`
`12  alpha ˜ dnorm(0,0.1)`
`13  m ˜ dgamma(0.1,0.1)`
`14 `
`15 _# 사후 예측 점검 (Posterior predictive checks)_`
`16 for(i in 1:n){`
`17   Y2[i] ˜ dnegbin(q[i],m)`
`18   rate[i] <- Y2[i]/N[i]`
`19 }`
`20 `
`21 D[1]   <-   min(Yp[])`
`22 D[2]   <-   max(Yp[])`
`23 D[3]   <-   max(Yp[])=min(Yp[])`
`24 D[4]   <-   min(rate[])`
`25 D[5]   <-   max(rate[])`
`26 D[6]   <-   max(rate[])=min(rate[])`

우리는 다음의 6가지 검정 통계량을 갖춘 사후 예측 점검(Posterior predictive checks)을 통해 모델을 파고듭니다:

1. 최소 집계(Minimum count): D1(Y)\=min{Y1,...,Yn}
2. 최대 집계(Maximum count): D2(Y)\=max{Y1,...,Yn}
3. 집계 범위(Range of counts): D3(Y)\=max{Y1,...,Yn}−min{Y1,...,Yn}
4. 최소 비율(Minimum rate): D4(Y)\=min{Y1/N1,...,Yn/Nn}
5. 최대 비율(Maximum rate): D5(Y)\=max{Y1/N1,...,Yn/Nn}
6. 비율 범위(Range of rates): D6(Y)\=max{Y1/N1,...,Yn/Nn}−min{Y1/N1,...,Yn/Nn}

여기서 큰 집계 수를 제대로 설명하는 것이 주된 관건이기 때문에 집계 및 비율의 범위와 관련된 검정 통계량을 사용합니다. [그림 6.7](./14-chapter6.md#fig6_7)은 두 모델 및 여섯 개의 모든 검정 통계량에 대한 PPD를 시각화합니다. 포아송 모델의 PPD는 가장 큰 집계 수나 데이터 세트에서 관측된 집계 수의 범위를 잘 잡아내지 못합니다. 극댓값이나 범위와 관련된 4개의 통계량 모두에서 베이지안 p-값은 0이나 1에 매우 가깝습니다. 예상대로 음이항 모델(Negative-binomial model)은 훨씬 더 넓은 예측 구간을 제공하므로 극단적이지 않은 206\. 207\. 베이지안 p-값을 나타냅니다. 고로 포아송 모델이 이번 분석에는 어울리지 않는 반면 음이항 모델 쪽은 (다소 제한적인) 테스트에 기인하더라도 보다 그럴듯해 보입니다. 그럼에도 양측의 데이터 모델 검토에서 드러난 총기 규제 도입 수(_β_6) 간의 인과 지표는 높은 확률의 마이너스(−)를 보였고 (포아송 분석 내 95% 구간은 (−0.017,− 0.011), 음이항에선 (−0.026, −0.008)을 띄었습니다) 이를 통해 총기 규제의 건수와 사망률과의 상관 구조가 역의 관련성을 띈다는 모델링을 도출할 수 있습니다.

![포아송(Poisson) 및 음이항(Negative Binomial) 모델 내에서 불일치 척도 D의 사후 밀도를 비교하는 6개의 패널입니다. 최소 집계수, 최대 집계수 그리고 집계 범위의 경우, 포아송 밀도는 폭이 좁고 높이가 높은 반면 음이항 분포 밀도는 덜 빽빽합니다. 세로선은 계산된 p값들과 함께 관측 값들을 나타내고 있습니다. 밑면의 화면창에는 최소, 최대, 비율 편차에 동일 방식의 대비를 주었습니다. 즉, 포아송의 경우 데이터 관찰 비율 상에서 사후 분포 극점이 가파른 반면 음이항 분포 사후 척도는 완만하게 표출됨으로써 불일치 요약이 모델 적합 내 편차가 있음을 입증해줍니다.](./images/fig6_7.jpg)

그림 6.7 **총기 규제 사례를 위한 베이지안 p-값**. 밀도 곡선은 포아송 및 음이항(NB) 모델의 6개 검정 통계량 사후 예측 분포를 보여주며, 세로선은 관측된 데이터의 통계량을 뜻합니다. 베이지안 p-값은 범례 안의 괄호에 표기되어 있습니다. [본문으로 돌아가기.⏎](chapter6)
