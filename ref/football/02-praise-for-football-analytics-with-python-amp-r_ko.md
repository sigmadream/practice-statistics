# *Football Analytics with Python & R*에 대한 찬사

> 명확성과 실전 멘토링을 바탕으로, 에릭(Eric)과 리처드(Richard)는 초보자와 실무자 모두를 위해 풋볼 분석을 대중화합니다. 이 기초 가이드는 복잡한 데이터를 누구나 이해할 수 있는 지혜로 바꾸어 주며, 게임을 더 잘 이해하고자 하는 모든 이들의 필독서입니다.
>
> 존 파크(John Park), 댈러스 카우보이스(Dallas Cowboys) 전략적 풋볼 운영(Strategic Football Operations) 디렉터

> 이 책은 풋볼 분석 내에서 적용 가능한 스토리텔링과 활용 사례가 완벽하게 조화를 이룹니다. 구체적인 코딩 예제와 광범위한 코딩 지침을 통해 풋볼 분석 분야 커리어의 기초를 다지기 위한 이상적인 리소스입니다. 누구나 이 책을 집어 들고 풋볼 데이터로 코딩하는 법을 배울 수 있습니다.
>
> 존 타오르미나(John Taormina), 트루미디어(TruMedia) 풋볼 전략 디렉터, 전(前) 애틀랜타 팰컨스(Atlanta Falcons) 풋볼 데이터 및 분석 디렉터

> 사례 연구 중심의 접근 방식을 통해 풋볼 분석에서 흔한 과제에 어떻게 접근해야 하는지 쉽게 이해할 수 있습니다. 이 책이 데이터 과학과 풋볼 지식으로 가득 차 있다는 점이 마음에 듭니다. 풋볼 데이터를 탐구하는 데 관심이 있는 사람이라면 반드시 읽어야 할 책입니다.
>
> 리치 코튼(Richie Cotton), 데이터캠프(DataCamp) 데이터 에반젤리스트(Data Evangelist)

> 풋볼 세계에서 유의미한 분석을 배우고, 구현하며, 통찰력을 생성하기 위한 실용적인 가이드입니다. 스포츠 애호가와 데이터 기반 전문가 모두에게 환상적인 책입니다.
>
> 존 올리버(John Oliver), 데이터 과학자

> 이 책은 데이터 과학이 풋볼 분석에 어떻게 적용되는지 배우기 위한 훌륭한 참고 자료입니다. 예제들은 실제 풋볼 데이터를 사용하여 광범위한 시각화, 데이터 랭글링(Data Wrangling), 모델링 기법을 가르쳐줍니다.
>
> 라이언 데이(Ryan Day), 고급 데이터 과학자

> 업계에서 일하는 데이터 과학 교육자가 쓴 희귀한 책 중 하나입니다. 또한 전체에 걸쳐 Python과 R을 모두 사용한 풋볼 분석을 다룹니다! 훌륭하고 사려 깊은 예제들도 있습니다.
